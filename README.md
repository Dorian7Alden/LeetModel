### 项目介绍

LeetModel（力模），是一款对标 LeetCode 的**数学建模**领域垂直在线实训平台，核心聚焦数学建模赛事全链路能力提升。

平台深耕数学建模赛事实训场景，以体系化训练为根基、AI 智能技术为赋能抓手，完整覆盖主流数学建模赛事全流程实践环节，为建模学习者、参赛团队提供从零基础入门到赛事高阶进阶的一站式成长解决方案。

### 主要功能

- 🎯 分角色专项训练：针对建模手、编程手、论文手提供专属定向训练内容
- 📚 多标签分类题库：支持按模型、题型、行业背景等多维度标签筛选题目
- 🤖 AI 智能辅助：提供 AI 评阅、AI 优化建议、AI 题目解析，AI 查重功能（暂议）
- 💬 经验交流社区：开放建模学习与赛事实战的经验分享、交流互动板块
- 🏆 全真赛事模拟：1:1 还原正式赛事(国赛/美赛)环境，支持全流程限时作答训练
- 📈 个人成长体系：全程记录练习数据，生成能力评价与专属成长头衔
- 🤝 线上组队平台：支持校内、跨校多场景自由组队，快速匹配参赛伙伴
- 👥 团队协同空间（暂议）：提供专属项目空间与实时在线协作功能
