# 数据挖掘与统计类题型特征

## 核心结论

数据题给"大表"数据，问**分类、聚类、识别、关联、异常检测**等开放问题（国赛 C 题、美赛 C 题即此类，2026 美赛 C 题有 1.3 万队参赛，是最热题型）。热门原因：**开放性强无标准答案、对非数学背景友好、编程能力可充分变现**。得分关键是：**数据探索与清洗的可视化（EDA）、特征工程（变量筛选/构造）、方法选择有依据、交叉验证严谨、结果可视化漂亮**。评审反感"上来就跑模型"，喜欢"数据说话"的完整链路。

## 问题形态与识别

- 关键词：分类、聚类、识别、判定、挖掘、分析、关联、画像、异常检测。
- 数据形态：大表格（行=样本、列=特征），常附缺失值/异常值/类别不平衡。
- 常见场景：信用评分（2020 国赛 C 题）、胎儿异常判定（2025 国赛 C 题）、用户画像、图像识别（2019 深圳杯）、文本分类、污染物监测。
- 复合形态：常与评价（分类结果做综合评价）、预测（分类即预测类别）结合。

## 建模路线

1. **探索性数据分析（EDA）**：统计摘要、缺失/异常值处理、相关性热力图、变量分布图——评审从这判断数据功底。
2. **特征工程**：筛选重要特征（相关性/卡方/随机森林重要性）、构造新特征（交互项、离散化）、降维（PCA）。
3. **建模**（按任务）：
   - 分类：逻辑回归（基准）、决策树/随机森林/XGBoost、SVM、KNN；深度方向 CNN/Transformer（图像文本）。
   - 聚类：K-means（+肘部法/轮廓系数选 K）、层次聚类、DBSCAN、GMM。
   - 关联：Apriori、FP-Growth。
   - 异常检测：孤立森林、3σ 法、LOF。
4. **模型验证**：交叉验证（k-fold）、混淆矩阵/精确率召回率 F1、ROC-AUC、聚类轮廓系数——**验证部分是得分核心**。
5. **结果解释**：特征重要性、聚类画像描述（每个簇"是什么人/什么物"）、可视化（散点/雷达/词云/热力）。

## 评审偏好与得分点

1. **数据清洗透明化**：缺失值填充方法、异常值处理理由，一步步交代（数据题评审最先看这里）。
2. **类别不平衡处理**：过采样/欠采样/代价敏感——体现经验。
3. **基准模型 + 提升模型对比**：逻辑回归基线 → XGBoost 提升，报告指标对比表。
4. **可视化全面**：EDA 图 + 模型结果图 + 结论图，数据题最吃图。
5. **结论与业务解释**：模型输出要"翻译"成实际问题答案（如"指标 X 是判定异常的关键因素"）。

## 常见坑

- **数据泄露**：用测试集信息做特征工程/归一化（必须先切分再预处理）——学术硬伤。
- **过拟合表演**：训练集 99% 准确率但验证集掉点，没有正则化/交叉验证交代。
- **忽视数据质量**：缺失值直接删、异常值不处理，样本量骤减结论失真。
- **纯调包不解释**：跑完 sklearn 不给选择依据和结果解释，等于没做。
- **类别不平衡不处理**：98% 负样本时"全预测负"也有 98% 准确率——必须看混淆矩阵/F1。

## 对应素材与示例

- 历年真题示例：2025 国赛 C 题（NIPT 胎儿异常判定）、2020 国赛 C 题（中小微企业信贷策略，数据+评价+优化）、2026 美赛 C 题（Data with the Stars，天文数据挖掘）。
