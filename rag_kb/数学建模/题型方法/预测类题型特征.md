# 预测类题型特征

## 核心结论

预测题问"**未来（或未知时刻）的某个量是多少**"，是竞赛最常出现的题型之一。得分关键不在模型多高级，而在：**数据可用性决定模型路线**（有历史数据→统计/机器学习；数据少→灰色/机理；有过程规律→机理预测）+ **必须做预测结果验证**（回代误差、测试集误差、误差指标 MAE/RMSE/MAPE）+ 多模型对比选优。评审看的是"预测可解释、误差可交代、结论有置信度"，不是"算得准"（因为未来无法验证，准不准靠方法论证）。

## 问题形态与识别

- 关键词：预测、估计、趋势外推、未来 N 年/月/日的取值、需求量/流量/销量/发病率/价格预测。
- 数据形态：给历史时间序列（按年/月/日）；或给相关因素（指标）要求预测目标量。
- 常见场景：人口预测、GDP 预测、交通流量、销量/需求、股票/价格、传染病传播（结合机理）、降雨量、能源消耗。
- 复合形态：常与优化（预测结果作为优化输入）或评价（预测方法对比评价）组合。

## 模型选择路线（按数据条件）

| 数据条件 | 推荐模型 | 说明 |
|---------|---------|------|
| 有较长历史序列（≥15 个点） | ARIMA/SARIMA、指数平滑、回归趋势外推 | 经典统计路线，解释性好，检验完备 |
| 数据点少（<10 个） | 灰色预测 GM(1,1) | 小样本神器，但精度有限，需说明局限 |
| 多因素相关数据 | 多元线性/非线性回归、随机森林/XGBoost、BP 神经网络 | 适合"因素→目标"型预测，注意过拟合与变量筛选 |
| 强过程机理（物理/生化规律） | 微分方程模型 + 参数估计 | 最受评审认可，预测外推有原理支撑 |
| 状态随时间转移 | 马尔可夫链（转移概率预测） | 适合天气、市场状态等离散状态预测 |
| 序列有周期性/趋势 | 时序分解（趋势+季节+残差）+ 分量预测 | 先分解再预测，可视化加分 |

## 评审偏好与得分点

1. **数据预处理交代**：缺失值处理、异常值剔除、平稳性检验（ADF）、差分阶数——展示统计功底。
2. **训练/测试切分**：用前 80% 数据拟合、后 20% 验证，报告测试集误差（MAE/RMSE/MAPE）——这是"预测有效"的最有力证据。
3. **多模型对比表**：2–3 个模型跑同一数据，误差对比表 + 选优理由，比单模型"自说自话"得分高。
4. **置信区间/敏感性**：给出预测区间、说明参数变化对结果的影响。
5. **图形**：历史值+拟合值+预测值一张图，直观展示拟合质量。

## 常见坑

- **只给预测不给验证**：没有回代/测试集验证的预测等于没做——必扣分。
- **灰色预测万能化**：GM(1,1) 适合指数型小样本，数据波动大时结果不可信，须加残差检验。
- **过拟合炫技**：神经网络拟合历史数据漂亮但泛化差（测试集误差高），不如简单的回归+检验。
- **忽略可解释性**：评审需要"为什么这么预测"；纯黑箱模型（深网）要配变量重要性/特征分析。
- **预测区间缺失**：未来不可知，给点估计不给区间显得不严谨。
