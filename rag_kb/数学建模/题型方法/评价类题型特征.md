# 评价类题型特征

## 核心结论

评价题问"**多个方案/对象中哪个最优、怎么排序、综合得分多少**"，是**新手最友好**的题型：套路成熟、对编程要求低、容易写完整。核心三步：**建指标体系 → 定权重 → 综合评分**。得分关键在于：指标体系是否覆盖题意（二级指标展开）、权重是否有据可依（主观 AHP 或客观熵权，最好主客观结合）、结果是否做了稳健性检验（换权重/换方法排序变化）。库内已有完整示例：[[评价类建模示例-队员选拔]]（AHP + RSR 双模型对比）。

## 问题形态与识别

- 关键词：评价、排序、优选、综合评分、评级、评估、甄选、评选。
- 数据形态：多个对象 × 多个指标的表（对象少指标多）。
- 常见场景：方案比选、队员/人才选拔、城市/地区综合评价、企业绩效、污染评价、课程评估、风险评价。
- 复合形态：评价常作为其他题型的一部分（如优化后对方案做综合评价；预测模型用评价法对比选优）。

## 方法路线（赋权与综合两维）

| 环节 | 常用方法 | 说明 |
|------|---------|------|
| 指标预处理 | 极差归一化、Z-score 标准化、正向化 | 指标方向/量纲统一，是评价的前提 |
| 主观赋权 | 层次分析法（AHP） | 判断矩阵+一致性检验，可解释性强，评审常见 |
| 客观赋权 | 熵权法、CRITIC、变异系数 | 基于数据信息量赋权，客观性强 |
| 主客观结合 | 组合权重（AHP×熵权线性加权） | 稳健性最佳，是加分项 |
| 综合评分 | 加权求和、TOPSIS（优劣解距离）、RSR（秩和比）、模糊综合评价、主成分降维+评分 | 加权求和最基础；TOPSIS 最常用；模糊综合处理定性指标；PCA 处理高维指标 |

**方法组合建议**：AHP/熵权赋权 + TOPSIS/加权求综合评价，是评价题"标准套餐"；数据量大时 PCA 降维 + 聚类分组展示。

## 评审偏好与得分点

1. **指标体系的"完整性论证"**：为什么选这些指标、为什么不选另一些——评审最看重这一步（指标漏项=模型不完整）。
2. **权重的可解释性**：主观权重要说明专家依据；客观权重要说明信息量含义；组合权重给出分配理由。
3. **稳健性/灵敏度**：改变权重分配，排序是否稳定（相关性检验/序次对比）——这是评价题拉开差距的加分点。
4. **可视化**：雷达图、热力图、排序条形图、TOPSIS 距离图，直观且出效果。
5. **结论落地**：给出最终推荐/排名，并解释结果合理性（与常识对照）。

## 常见坑

- **指标方向不统一**：效益型/成本型指标混在一起直接加权，结果失真——必须先正向化。
- **AHP 一致性不过关**：判断矩阵 CR>0.1 仍继续用，属于基础错误。
- **指标体系照抄模板**：与题目场景脱节的通用指标，评审一眼看穿。
- **只排序不解释**：排完名就结束，没有对结果的分析与合理性讨论。
- **权重拍脑袋**：主观权重无依据、客观权重无解释，评分像黑箱。
