# 优化类题型特征

## 核心结论

优化题问"**在约束下使目标最优**"（成本最小/收益最大/时间最短/最省），是竞赛中占比最高、最能体现"建模能力"的题型。建模三要素缺一不可：**决策变量、目标函数、约束条件**。得分关键是：模型写成规范的标准形式（线性/整数/非线性清晰标注）、选用合适求解器（Lingo/Gurobi/Python 库）并报告求解细节、对结果做**合理性验证与灵敏度分析**（改参数结论是否稳定）。库内已有全景分类：[[优化模型与算法分类]]。

## 问题形态与识别

- 关键词：最优、最省、最大/最小、调度、安排、分配、选址、排班、配给、路线规划。
- 数据形态：需求/供给/成本/时间表等参数表 + 明确的目标与约束描述。
- 常见场景：生产计划、物流配送（车辆路径 VRP）、排班（人员/机器）、库存管理、投资组合、选址（中心/覆盖）、网络流量分配、装载问题。
- 复合形态：常与预测（预测需求后优化）或评价（多方案选优）结合；国赛 B 题几乎年年带优化成分。

## 模型选择路线（按决策变量与约束性质）

| 模型类型 | 适用条件 | 求解工具 |
|---------|---------|---------|
| 线性规划 LP | 目标与约束均线性、变量连续 | Lingo、scipy.optimize.linprog、Gurobi |
| 整数规划 ILP / 0-1 规划 | 决策变量取整数（如"是否建设""车辆数"） | Lingo、pulp、Gurobi |
| 非线性规划 NLP | 目标或约束非线性 | scipy、Gurobi、启发式 |
| 动态规划 DP | 多阶段决策（路径、库存分期） | 手写递推/记忆化 |
| 多目标规划 | 多个目标权衡（成本 vs 服务） | 加权法、ε-约束、NSGA-II |
| 图论优化 | 路径/网络（最短路径、最大流、最小生成树） | networkx、Dijkstra/Floyd、最大流算法 |
| 组合爆炸问题（NP-hard） | 大规模 VRP、TSP、调度 | 贪心、模拟退火、遗传算法、粒子群（启发式） |

## 评审偏好与得分点

1. **三要素清晰**：决策变量/目标/约束分开列出，变量有物理含义解释——评审按此框架读模型。
2. **模型规模适中**：能用解析/精确算法就不用启发式；大规模问题用启发式时说明为什么精确法不可行（复杂度分析）。
3. **求解过程完整**：写出求解器/算法、参数设置、迭代/运行信息；启发式要画收敛曲线。
4. **结果合理性检验**：将最优解代回约束验证可行；与简单策略（贪心/人工方案）对比说明改进量。
5. **灵敏度分析**：成本/需求参数 ±10%–20% 时最优解变化——优化题最重要的加分点（见 [[第二次评讲B题-笔记]]）。
6. **实用建议**：把数学最优解翻译成可执行的方案建议（排班表、路线图），贴近实际。

## 常见坑

- **约束漏项**：少写约束导致"最优解"现实中不可行——检查每一条题干条件是否都进了模型。
- **模型与求解器错配**：非线性问题用 LP 求解器报错/乱结果；整数变量忘声明。
- **无解却不交代**：模型不可行时没有松弛/调整分析，直接放弃。
- **大而全的优化但无验证**：堆了复杂启发式却没有与简单方法的对比，说服力不足。
- **忽略整数性**：人员/车辆数必须整数，连续化处理要说明取整方法。
