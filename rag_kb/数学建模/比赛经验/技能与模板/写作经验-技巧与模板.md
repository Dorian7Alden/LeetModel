# 写作经验：技巧与模板

## 核心结论

竞赛写作的第一原则：**论文是唯一的交付物，写作不是最后一步而是与建模并行的工程**。高效打法是"**骨架先行**"：发题当晚就搭好全文目录与各节要点，建模/求解每完成一步立即写入对应章节，最后集中 3–5 小时打磨摘要、语言与图表。写作质量的核心是**"结论先行 + 数字说话 + 逻辑自洽"**——每一节第一段给出结论，每个结论都有数字支撑，前后文数字一致（详见 [[评审维度与板块拆解]]）。

## 写作流程（72 小时时间线中的写作安排）

| 时间点 | 写作动作 |
|--------|---------|
| 第 1–2 小时 | 定题后立即建论文骨架：目录 + 每节预留要点（标题先写，内容后填） |
| 同步进行 | 建模者边建模边写"模型建立"节；求解者跑完一问答一节的"求解与结果" |
| 第 2 天 | 完成 60% 正文初稿：假设、符号、模型、结果表格 |
| 第 3 天上午 | 完成检验/灵敏度/评价推广；开始统一图表风格 |
| 最后 8 小时 | 摘要精修（30% 时间）、全文数字一致性核对、排版、附录代码整理 |
| 最后 2 小时 | 格式规范核对 + 提交材料打包（见 [[提交规范与检查清单]]） |

## 摘要写法（五要素模板）

> 针对**问题**，本文基于**方法**，构建了**模型**（模型名+变量+公式一句），利用**求解工具**得到**关键结果数字**（每问一两个最有说服力的数），并对结果进行了**检验**（误差/灵敏度结论）。结果表明：**最终结论**。

- 每问都要有对应的一句话结果；出现具体数字（模型名、精度、误差、优化值）是摘要"有货"的标志。
- 中文摘要 ≤1 页（国赛），美赛附英文摘要；模板示例见 [[解题思路与论文写作模板]]。
- 摘要的每句都要能指回正文——评审会抽查一致性。

## 各板块高效写作技巧

| 板块 | 技巧 |
|------|------|
| 问题重述 | 用自己的话压缩提炼，附"问题分析"（每问难点+思路），不抄题目原文 |
| 模型假设 | 3–5 条足够，每条假设后括号标注"为简化 X 而设"，与模型一一呼应 |
| 符号说明 | 表格：符号/含义/单位；全文字体统一（LaTeX 用公式环境） |
| 模型建立 | 先写"思路"再写"数学化"：变量→目标→约束/方程→求解方法；公式编号 (1)(2)… 且文中引用 |
| 求解与结果 | 算法步骤 + 参数表 + 结果表；**结果表是核心**，宁可多表不写长段文字 |
| 模型检验 | 三件套：模型检验（误差/回代）+ 灵敏度（±10% 参数）+ 与实测/常识对比（见 [[第二次评讲B题-笔记]]） |
| 评价与推广 | 优缺点各 2–3 条，客观真实；推广给具体应用场景而非空话 |

## 排版与图表规范（表达清晰性）

- **图**：统一字体大小与配色、坐标轴有标签和单位、有标题编号（图 1 语义化标题）、分辨率足够；折线/散点/热力按需选型。
- **表**：三线表风格、表头单位、数字对齐、保留位数全篇统一（如 4 位小数）。
- **公式**：编号右对齐；变量首次出现给出定义与单位；向量/矩阵用粗体。
- **结构**：目录、章节编号清晰；页眉页脚不含身份信息（见 [[论文格式规范-官方2023修订稿]]）。
- 绘图工具：matplotlib（统一样式函数）、Origin、Visio/draw.io（示意图）（见 [[工具推荐-写作与绘图]]）。

## 语言风格自查

- 结论先行：每节开头一句给结论，正文支撑论证。
- 用数字说话："准确率达到 92.3%""较基准方案成本降低 18.6%"，而不是"效果很好"。
- 避免口语与主观词（"我觉得""大概"）；避免空话套话（"具有重要意义"）。
- 全文逻辑链：假设→模型→求解→检验→结论，前后呼应；摘要↔正文↔附录数字一致。
