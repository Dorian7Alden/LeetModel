# 学科竞赛之路-数学建模经验谈

数学建模参赛经验谈（源自学生竞赛分享）：**参赛越早越好**——一般大一下或大二下即可参赛，与年级段无关、实力是王道；早参赛的好处是参赛经验多、参赛机会多，弊端是微积分、概率论、线性代数等基础数学知识欠缺。

- **如何准备**：基础知识（数学工具：微积分、概率论、线性代数）＋专项知识（建模：熟悉基本建模方法和常用模型；编程计算：熟悉常用软件操作与求解算法；撰写论文：熟悉论文结构、提高排版和搜索能力）＋组队。
- **好队友标准**：负责任（保质保量按时完成份内任务）、有主见（会思考、提出自己的观点，没有大神也能赢）、讲合作（懂倾听、不固执己见）、共奋斗（有共同的长期目标）。
- **参赛过程**：以国赛为例，每年 9 月中旬某周末周五 8:00 至下周一 8:00 连续 72 小时，按节奏推进（查阅/选题 → 逐问建模求解 → 建模完工赶论文 → 排版/摘要）；选题要三思而后行、不要频繁换题、总结自己队伍擅长的领域；论文按标准结构完成（标题/摘要/关键词/重述/分析/假设/符号/建模/求解/结果分析/评价改进/参考文献）。
- **研习优秀论文是王道**：摘要看"用什么方法解决什么问题"；问题分析保持起码的层次感和极强的问题性、层层递进；建模思路与求解方法按"问题归类—对应解决—相似启发"学习；结果讨论关注完备性、严谨性、精确性、敏感度、优先性。
- **评奖标准**：评阅四原则（假设合理性/建模创造性/结果合理性/表述清晰度）；完整解答全部问题；**摘要决定能否得奖**；对关键假设进行分析决定能否得奖；对结论做敏感性分析、验证解的精度。

成长路径：好室友 → 公开承诺 → 好队友 → 锻炼自己 → 想拿奖 → 尽全力。一次参赛，受益终身。
