# 提交规范与检查清单

## 提交材料组成

- MD5 码（参赛论文 pdf 与支撑材料 zip 的 md5，提交后勿再改动压缩包）；
- 参赛论文（电子版）；
- 支撑材料（压缩包）；
- 纸质论文（有些赛区要求自己打印、有些赛区组委会代打印——提前搞清楚）。

## 参赛论文检查项

- 论文中**不能包含承诺书和编号专用页**（电子版）；
- 格式只能用 **PDF 或 Word**；
- 不得出现任何与参赛队伍有关的信息（文件路径、文件属性）；
- 源程序应作为**附录**在论文中呈现；
- 压缩之后禁止再修改压缩包，压缩包只能添加、不能修改或删除或移动；
- 内容应包含：模型的假设、建立和求解、计算方法的设计和计算机实现、结果的分析和检验、模型的改进等。

## 支撑材料检查项

- 源程序代码、查阅并使用的数据、运行结果；
- 压缩为 ZIP 或 RAR，文件大小最大支持 20M；
- 不得出现任何与参赛队伍有关的信息。

## 文件命名规范

格式：**问题序号 + 文件内容标题**。示例：

- 代码程序：`q1-模型求解`、`q1-可视化-图1`、`q1-可视化-曲线图`
- 图表：`q1-图1-饼图`、`q2-图1-流程图`、`全局流程图`
- 论文：`v1.pdf`、`v2.pdf`

## 赛前准备

- 熟悉工具：LaTeX 模板（签名/封面/编号页、公式/表格、附录代码）、代码环境测试、交流工具、画图工具、笔记工具、AI 提示词备用、文件管理；
- 实战助力：搜集可能用到的参考文献（可直接参考优秀论文中的文献）、润色论文的 AI 提示词、想清楚每个论文板块怎么写、精读优秀论文。

## 比赛中流程

1. 审题 → 判断题型（优化类/机理分析/数据分析）；
2. 分析题目的关键信息（关键条件、问题要求的输出类型）；
3. 模型选型（大类）；
4. 查找资料（背景论文、模型实现过程、顺便找参考文献）；
5. 求解（简化版本）——公式第一、公式解释说明、画图分析结果（趋势/转折点/特殊点/幅度/周期/斜率）、模型的必要检验、画图画表；
6. 整理（字母表、假设、公式图表、文件命名）；
7. 写论文（问题重述/分析/假设/符号说明 → 求解部分打磨语言 → 评价推广 → 摘要关键词题目 → 代码附录）；
8. 查漏、精读论文。

## 代码规范

- 一个代码程序只做一件事：数据处理 / 模型求解 / 画一张图；
- 变量名：字面意思、英文不用拼音、尽量不缩写、Python 用下划线风格；
- 注释只为「代码块」添加（不是每行），通过变量名能看懂的不用注释；
- 求解思路在 main 函数里呈现，只修改函数实现，不改 main（除非建模错了）；
- 可视化代码与求解代码分开，先求解再画图；记得记录每次运行的结果，保证代码至少有一个解。

## 绘图统一配置（matplotlib）

```python
import matplotlib
import matplotlib.pyplot as plt

matplotlib.use('TkAgg')
plt.rcParams['font.sans-serif'] = ['SimHei']  # 支持中文显示
plt.rcParams['axes.unicode_minus'] = False  # 解决负号显示问题
plt.rcParams.update({
    'font.size': 12,
    'axes.labelsize': 14,
    'axes.titlesize': 16,
    'xtick.labelsize': 12,
    'ytick.labelsize': 12,
    'legend.fontsize': 12,
})
plt.figure(figsize=(12, 6))
```
