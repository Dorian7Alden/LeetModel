# 常用模型速查：优化类

## 核心结论

优化建模三要素：**决策变量（要决策什么）→ 目标函数（优化什么）→ 约束条件（限制什么）**。选型看变量类型与规模：连续线性 → LP；整数/0-1 → ILP；非线性 → NLP（scipy）；多阶段 → DP；大规模 NP-hard → 启发式。**优先精确解，启发式做兜底并说明复杂度**。求解后必做：可行性验证 + 灵敏度分析（见 [[优化类题型特征]] 与 [[优化模型与算法分类]]）。

## 模型速查表

| 模型 | 适用条件 | 标准形式要点 | 求解工具 |
|------|---------|-------------|---------|
| 线性规划 LP | 目标/约束全线性、变量连续 | max/min cᵀx, s.t. Ax≤b, x≥0 | Lingo、scipy.optimize.linprog、Gurobi |
| 整数规划 ILP | 变量需取整数 | LP + x∈Z（0-1 变量用于"是否"决策） | Lingo、pulp、Gurobi、ortools |
| 非线性规划 NLP | 目标或约束非线性 | 注意局部最优，多初值尝试 | scipy.optimize.minimize、Gurobi、MATLAB fmincon |
| 动态规划 DP | 多阶段决策（路径/分期/分配） | 状态转移方程 + 边界条件，自底向上递推 | 手写（numpy） |
| 多目标规划 | 多目标权衡 | 加权法（定权重）/ ε-约束（转单目标）/ Pareto 前沿 | pymoo（NSGA-II） |
| 图论优化 | 网络问题 | 最短路径 Dijkstra/Floyd、最大流、最小生成树 Kruskal/Prim、TSP | networkx |
| 模拟退火 SA | NP-hard 组合优化 | 温度下降 + Metropolis 接受准则，随机邻域搜索 | 手写（约 30 行） |
| 遗传算法 GA | 组合/连续优化大空间 | 编码 → 选择/交叉/变异 → 迭代；画收敛曲线 | DEAP、手写 |
| 粒子群 PSO | 连续优化 | 速度-位置更新，全局最优引导 | pyswarm、手写 |

## 标准步骤

1. **读懂约束**：把题干每个条件翻译成数学约束，**逐条对照题干检查无遗漏**。
2. **写标准形式**：决策变量（含范围与整数性）→ 目标 → 约束，标注模型类型。
3. **求解析/精确解**：LP/ILP 用求解器（Lingo 一行式求解，写清楚目标与约束代码）。
4. **大问题转启发式**：给出问题规模、精确法不可行的理由（NP-hard），启发式参数设置 + 收敛曲线 + 与贪心解对比。
5. **结果验证**：最优解代回约束全部可行；结果合理性分析（对照简单策略的改进量）。
6. **灵敏度分析**：关键参数 ±10%/±20% 重求解，结论是否稳健；列灵敏度表。
7. **落地建议**：把解翻译为排班表/路线图/配置方案，附图示。

## 常见错误

- 约束漏项（最优解现实中不可行）；整数变量未声明；非线性当线性解；启发式无收敛曲线与对比；只给解不给验证与灵敏度。
