# 常用模型速查：评价类

## 核心结论

评价建模三件套：**① 指标标准化（正向化+无量纲化）→ ② 赋权（主观 AHP / 客观熵权 / 组合）→ ③ 综合评分（加权求和 / TOPSIS / 模糊 / RSR）**。竞赛标准套餐：熵权法或 AHP 赋权 + TOPSIS 排序，配雷达图/热力图可视化，加权重敏感性分析（见 [[评价类题型特征]]、库内示例 [[评价类建模示例-队员选拔]]）。

## 模型速查表

| 模型 | 角色 | 核心思想/步骤 | 实现 | 适用 |
|------|------|--------------|------|------|
| 层次分析法 AHP | 主观赋权 | 指标两两比较打分（1–9 标度）→ 判断矩阵 → 特征向量法求权 → 一致性检验 CR<0.1 | 手写/numpy（10 行内） | 指标少、专家判断可依据 |
| 熵权法 | 客观赋权 | 熵=信息量：pᵢⱼ 归一化 → eⱼ=−kΣp ln p → 权重 wⱼ=(1−eⱼ)/Σ(1−eⱼ) | 手写/numpy | 数据有区分度时客观定权 |
| CRITIC | 客观赋权 | 标准差×相关系数衡量信息量 | 手写 | 指标相关性高时 |
| TOPSIS | 综合排序 | 正向化+归一化 → 正理想解 Z⁺/负理想解 Z⁻ → 贴近度 Cᵢ=D⁻/(D⁺+D⁻) 排序 | 手写/numpy | 最常用排序法，几何意义清晰 |
| 加权求和法 | 综合评分 | Sᵢ=Σwⱼxᵢⱼ 直接加权 | 一行公式 | 最基础，指标少时 |
| 模糊综合评价 | 定性指标评价 | 因素集+评语集 → 隶属度矩阵 R → 权重 W → B=W∘R（取大取小） | 手写 | 评价等级（优/良/差）类 |
| RSR 秩和比法 | 排序（免赋权） | 指标排秩 → RSR=Σ秩/(mn) → 线性拟合分档 | 手写 | 样本多、免赋权场景 |
| 主成分 PCA | 降维+权重 | 协方差特征分解 → 主成分得分加权（方差贡献率） | sklearn.decomposition | 指标多且相关时 |

## 标准步骤（TOPSIS 路线）

1. **指标正向化**：成本型取倒数或 1−x；中间型/区间型映射到 [0,1]。
2. **归一化**：极差法 x'=(x−min)/(max−min) 或 Z-score。
3. **赋权**：熵权法算客观权重（可再与 AHP 组合：w = αwᵃʰᵖ + (1−α)wᵉⁿᵗʳᵒᵖʸ，α 说明理由）。
4. **TOPSIS**：加权归一化矩阵 → 正负理想解 → 贴近度排序。
5. **稳健性**：换 α / 换赋权方法，对比排序稳定性（Spearman 相关）。
6. **可视化与结论**：排序条形图、TOPSIS 距离图、雷达图；结论与常识对照解释。

## 常见错误

- 成本型/效益型指标未统一直接加权；AHP 一致性 CR>0.1 未处理；归一化用了全局 min/max 导致新样本失效（数据题）；只排序不解释。
