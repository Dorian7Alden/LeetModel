## 暴力入门法：看论文效率胜过一切（国一选手经验）

时间紧（一个月甚至一周）还想获奖的最优路径，不是看书看视频，而是**直接啃论文**——这和期末考试复习做往年真题一个道理：

1. **看什么**：往届获奖论文，**好的和薄弱的都要看**——好论文学写法，薄弱论文能看出"阅卷按什么套路打分"（哪些板块草率会被扣、哪些是得分重点）。
2. **怎么用**：读 5–10 篇后对照自己写一篇完整论文；重点观察：摘要怎么组织、模型建立与求解怎么呈现、**最后一问怎么收尾**（国一选手原话："最后一问是拉开国一和国二差距的最后一道防线"）。
3. **为什么有效**：比赛考的不是数学深度而是"答卷能力"，论文质量直接决定奖项；看书容易"读几页就懵逼"，看论文是"直接看标准答案"。
4. **来源**：[[开源资料仓库汇总]] 的获奖论文合集（MCM-ICM O奖等）、中国大学生在线论文展示、各赛区优秀论文。

> 来源：知乎《数学建模竞赛的一些心得体会（阅读参赛论文的好处）》3942 赞（国一选手）。

## 官方与权威渠道

- **国赛官网** www.mcm.edu.cn：历年赛题、规则、格式规范、获奖名单（2026 规则要点见 [[国赛CUMCM详解]]）。
- **美赛官网** www.comap.org / contest.comap.com：规则原文、O 奖论文下载、结果公布（见 [[美赛MCM-ICM详解]]）。
- **中国大学生在线**（dxs.moe.gov.cn）：官方赛题讲评视频与论文展示——**赛后讲评是最好的一手学习材料**（库内 [[改卷注意点-2024讲评]] 即源自此）。
- **数学中国**（madio.net）：论坛经验帖与培训信息（老牌社区，内容杂需甄别）。
- **赛氪**（saikr.com）：各商业赛事报名与资料聚合。
