# 工具推荐：写作与绘图

## 核心结论

写作工具链选型的核心是**模板先行、团队统一**：论文排版用 **LaTeX（国赛官方适配模板 CUMCMThesis）或 Word+Mathtype 二选一**，队内必须同一套；绘图统一用 **matplotlib（代码可复现）或 Origin（数据图）**，示意图用 Visio/draw.io；公式用 LaTeX 语法（Word 里用 Mathtype/Aurora）。**工具提前一周装好跑通，比赛时不换工具**（见 [[编码经验-代码技巧]]）。

## 写作与排版工具

| 工具 | 用途 | 推荐理由 | 备注 |
|------|------|---------|------|
| **LaTeX + CUMCMThesis 模板** | 国赛论文排版 | 官方格式适配到 2023 年，自动编号/图表/公式，导出 PDF 规范 | GitHub: latexstudio/CUMCMThesis（980⭐）；美赛用对应英文模板（见 [[开源资料仓库汇总]]） |
| **Overleaf** | 在线 LaTeX | 免安装、多人实时协作、模板市场丰富 | 竞赛期间在线协作方便 |
| **Word + Mathtype** | 备选排版方案 | 上手门槛低，多数人熟悉 | 注意图表锚定与编号一致性；按官方格式规范设置页边距/字体 |
| Aurora / 自带公式 | Word 内公式 | 公式美观 | Mathtype 替代品 |
| Typora/VS Code | Markdown 草稿 | 摘要与文字初稿快速产出 | 最终必须转成规范格式 |

## 绘图工具

| 工具 | 用途 | 推荐理由 |
|------|------|---------|
| **matplotlib（Python）** | 数据图：折线/散点/热力/柱状 | 代码生成=可复现，与数据处理无缝；提前封装统一样式函数（中文/字号/配色） |
| **Origin** | 科学数据图 | 模板化出图快，期刊级质感；适合快速改参数 |
| **Visio / draw.io** | 流程图/示意图/模型架构图 | 模型流程图、算法框图、系统示意图必备 |
| **亿图图示（Edraw）** | 中文友好流程图 | 模板丰富，上手快 |
| **GeoGebra** | 几何/函数可视化 | 数学图形讲解图、轨迹图 |
| 3D 可视化（plotly/mayavi） | 三维曲面/散点 | 机理题展示三维模型时加分 |

## 其他效率工具

- **思维导图**：XMind/MindMaster——读题定框架、建模思路梳理、分工表。
- **文献管理**：Zotero/知网研学——参考文献格式统一，引用不丢（评审查引用规范）。
- **截图与标注**：Snipaste/微信截图——快速抓图标注；注意图片清晰度与元数据（无身份信息）。
- **OCR**：PandaOCR/天若 OCR——纸质赛题/图片数据转文字。
- **云协作**：腾讯文档/Notion——三人共享选题记录、决策日志、进度表（见 [[时间管理与团队分工]]）。

## 分工建议

- 写作队友主用 LaTeX/Word 与思维导图；编程队友负责 matplotlib 出图（统一样式）；建模队友出流程图与模型示意图（Visio/draw.io）。
- **图注规范**：每张图要有"图 N 标题"，坐标轴有标签单位——写进绘图函数默认样式，省去最后补注。
