# 第一次评讲A题-笔记

- 题目设计要吸引人（创新的点：混合算法？特殊处理的点）。突出主要的方法（重点模型）。

- 摘要部分的内容主要描述流程，结果，原因，不要把细节描述（结果是...，题目的要求，...）添加上去。
- 摘要是一个整体的大纲，要精简。一般 4-5 句话一个段落。固有的模式。

- 读起来顺畅，有逻辑，不能突兀地直接给出具体的东西。（建立了xxx，采用了xxx模型/算法，得出了xxx的结论）





# 问题重述与分析

- 精简精简再精简。这种很死的东西，写多了容易提高查重率。（大家都会写，而且基本上大差不差）

- 后面求解的时候可能也会再介绍题目中的特殊点的处理方式。精简精简。但也不要一句话的描述。尽量自然语言，成小段的分析。





# 假设

- 以模型的求解为基础，用到了再写，不要强行编造，硬塞。

- 假设的准确性。是否与要求冲突。
- 可能会影响模型的因素才做假设。

- 控制数量，太多了会导致模型太过简化，或者阅读人难以接收太多信息。精简

# 模型的建立与求解

- 非常成熟的东西（经典算法）可以不用介绍。因为别人会介绍。（直接引用算法讲解相关论文，文章）
- 介绍一些不知道的内容，与题目结合起来介绍，经典部分直接引用论文或者算法详解



- 每一步操作都讲解一下有什么作用。得到了什么效果，怎样推进了模型的建立，说明了什么问题。

- 伪代码的介绍，仅描述核心部分的内容。（有助于模型的理解）

- 非主要的部分内容，模型讲解直接简单概括即可。

- 模型的建立中，有一些变量是临时介绍的，一边建模，一边描述过程，一边介绍符号，一边建立公式。





# 模型检验

- 前面的求解建立过程可视化图太少的话，可以在后面部分将灵敏度分析的可视化图弄上去，避免阅卷疲劳。（平衡论文结构）

- 分析的时候得**有效证明**，这个东西是好的

- 检验，有必要才做。什么重要检验什么。（优化类模型需要检验什么才能增加说服力）





# 评价

- 尽量突出自己论文的优点。
- （我的心得体会）
- 不要介绍模型存在的缺点，错误或者可能错误的内容。
- 不足部分介绍没涉及的内容，没考虑到哪些东西
- 改进方面再描述具体改进的做法





# 细节

- 表的展示需要过渡介绍。不要不相关的图连着图

- 规避对自己论文不好的东西。尽管有缺陷。留给别人去迭代，修改，调整。（不必要的内容，不影响结果的东西）（减少扣分）

- 针对 A 题，应该多一点机理分析图（题型的风格要求，才能方便读者理解）（适配题型，中国特色社会主义）

- 公式的写法注意规范（评奖过程中，我一看就知道那个人的公式就是word编辑的...）

- 表格都建议用三线表。直接 table 太老了

- 可视化图非常有必要。丰富多样





# 阅卷

- 模型的使用上一定得要非常正确
- 避免一些技术性失分。技术上的错误。（自相矛盾之类的）

- 少扣分就是加分。改卷是扣分制，不是加分制。（跟高中写作文一样）抓住扣分点就能保障分数

- 建模过程中精简的表达。太详细的介绍有风险提高查重率。
- 论文不要让读者有疑问（可能引起扣分）

- 数模是科技论文。科技风格。解决实际问题的论文。注意写作方面的文字描述。（AI加限制就好了，语言风格限制一下）

- 篇幅 20 页只是建议。内容有必要就留着。（阅卷的是纸质卷，论文轻飘飘的，手感不好）（阅卷的时候可能不会打印附录！！！）

- 针对问题的提问，需要有明确的表述进行回答。凸显最终的结果（评判标准会明确给出标准答案：值的求解范围，...）（紧扣准确性，有问必答）

  - 何种策略 --> 采用了... 的策略

  - 何种姿势 --> 保持深蹲...

  - ...



# AI总结



### 数学建模模拟赛 A 题评讲笔记

#### **一、A 题核心评阅要求** 

1. **目标明确性**：需紧扣题目要求，明确回答关键问题（如 “何种姿势获得最大起跳速度”“如何控制飞行效果”“着陆平衡策略” 等），必须给出具体结果（如角度、速度等参数），否则说服力不足。A 题评阅注重结果准确性，答案越接近参考答案，得分越高。
2. **机理分析为主**：以物理机理（如受力分析、动力学模型）为核心，需清晰呈现物理背景和理论推导，算法仅为求解工具，不能替代模型分析。优秀论文通常包含较多力学分析示意图。

#### **二、论文结构与写作规范** 

1. **摘要**：
   - 需精简且包含核心要素：问题、模型、方法、结果。
   - 避免两种极端：过于繁琐（堆砌细节）或过于简略（信息不全）。
   - 突出重点，让阅卷老师快速抓住 “用什么方法解决了什么问题，得到了什么结果”。
2. **问题重述与分析**：
   - 用自己的语言简述，避免抄袭题目原文（查重严格，超过 25% 将失去获奖资格）。
   - 无需过度展开，以 “支撑模型建立” 为目的，避免冗长。
3. **假设**：
   - 数量控制在 3-5 个，过多易出现矛盾。
   - 假设需与后续模型一致，避免冲突（如假设 “坡面光滑” 却又考虑摩擦，假设 “运动员视为质点” 却分析姿态）。
   - 假设占 5 分，需严谨，避免让阅卷老师  质疑模型合理性。
4. **符号说明**：
   - 简洁规范，避免过多或混乱，数学符号需清晰（如下标、大小写区分），避免英文字母堆砌。

#### **三、模型与求解** 

1. **模型建立**：
   - 需展示推导过程，体现建模思路（如从受力分析到微分方程的推导）。
   - 避免忽略关键因素（如 A 题需考虑空气阻力、姿态角对受力的影响），模型需符合物理规律。
2. **算法应用**：
   - 成熟算法（如遗传算法、NSGA-II）无需详细介绍，仅需说明与问题的结合点。
   - 伪代码突出核心步骤，避免过长（易查重），体现算法与问题的适配性。
3. **结果呈现**：
   - 关键参数（如角度、速度）需明确，结果需合理（如避免物理上不连续的骤变）。
   - 灵敏度分析可放在每问后（若前文图表少），通过参数变化展示结果稳定性。

#### **四、图表规范** 

1. **图表与内容结合**：
   - 图表需有解释说明，避免连续放图 / 表（需过渡语句），明确图表如何支撑问题求解。
   - 图注、表注用中文（避免因软件问题过多使用英文），标注清晰（如 “俯视图”“侧视图”）。
2. **图表美观性**：
   - 受力分析图、轨迹图等需规范，避免模糊；表格采用三线表，避免拥挤或格式混乱。
   - 避免展示与预期矛盾的图（如近似线性却不符合物理规律的速度变化图）。

#### **五、其他注意事项** 

1. **查重**：严格控制重复率在 25% 以内，避免大段抄袭题目、算法介绍等，多用原创语言。
2. **篇幅**：虽建议 20 页，但优秀论文多超过，以 “内容丰富” 为优先，单面打印更显充实。
3. **参考优秀论文**：学习结构、写法（如科技论文的段落逻辑），避免零碎点列（如用 “黑点” 分述），提升专业性。

#### **总结** 

A 题得分关键在于 “模型准确、结果明确、表达规范”。需避免非技术性失分（如假设矛盾、图表混乱、查重超标），多通过优秀论文打磨写作与建模思路，突出机理分析与结果合理性。
