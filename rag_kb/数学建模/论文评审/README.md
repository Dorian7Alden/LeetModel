# 论文评审
> 评审数学建模论文的参考资料：评审总览与阅卷人视角、九大板块评审要点、华数杯阅卷标准、官方格式规范与历届讲评。
> 本文件夹适合：评审/评阅论文、对照板块得分点检查论文、了解阅卷偏好等任务。
> 默认风格：清单式

## 子文件夹

| 子文件夹 | 说明 |
|---------|------|
| 评审板块 | 论文各板块（摘要/重述/假设/建模/求解/检验/敏感性/评价推广）的独立评审要点 |
| 阅卷标准 | 各届华数杯赛题的官方评阅标准（得分点与参考答案）与提炼启示 |
| 官方规范与讲评 | 官方论文格式规范与历届赛题讲评（格式红线、评阅标准、常见问题） |
| 评审视角 | 评审总览与阅卷人视角：四维度拆解、失分点排行、心理模型、高分共性 |
