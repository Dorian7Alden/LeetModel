# 敏感性分析评审要点

## 核心结论

敏感性分析是**拉开论文档次的关键加分板块**：它回答评审的终极疑问——"你的结论换个参数还成立吗？"评审认可的敏感性分析 = **关键参数 ±10%/±20% 扰动 → 重求解 → 结论稳定性说明**。它与模型检验互补：检验验证"模型对不对"，敏感性验证"结论稳不稳"。官方讲评与评阅标准多次点名（[[第二次评讲B题-笔记]]、[[评阅标准启示-华数杯]]），缺敏感性 = 结论的可信度缺一块。

## 评审怎么看

1. **有无敏感性分析**：很多论文完全没有——有就领先一档。
2. **参数选择是否关键**：扰动的是影响结论的核心参数（成本/需求/权重/速率），而非无关参数。
3. **扰动幅度是否合理**：±10%/−20% 量级的现实扰动区间，不是 ±1% 或 ±200% 的敷衍。
4. **结论是否解读**：扰动后结论稳定 → 声明稳健；结论翻转 → 诚实说明与边界讨论——**只列数字不解读 = 形式主义**。

## 得分点

1. **表格化呈现**：参数扰动表（参数 | 原值 | ±10% | ±20% | 对应结果变化），一眼看清稳健性。
2. **可视化**：敏感性曲线/条形图（结果随参数变化）比表格更直观。
3. **与检验联动**：检验 + 敏感性组成完整的"结果可信度论证"（见 [[模型检验评审要点]]）。
4. **边界分析**：找出结论翻转的临界参数值，给出模型适用边界——这是最高级的敏感性分析。
5. **覆盖关键决策**：优化题的权重/成本、评价题的权重分配、预测题的关键外生变量。

## 失分点

| 失分点 | 表现 | 后果 |
|--------|------|------|
| 完全缺失 | 全文无敏感性分析 | 结论稳健性无证据 |
| 形式主义 | 扰动 ±1% 或只列表不解读 | 评审一眼看穿是凑篇幅 |
| 参数不关键 | 扰动无关紧要的参数 | 无效分析 |
| 结论翻转不交代 | 参数变化后结论变了却不讨论 | 不诚实，可信度崩塌 |
| 幅度不现实 | ±200% 扰动（现实不可能） | 没有实际意义 |

## 写法要点

- **模板**："为检验结论对____的稳健性，将该参数在 ±10%、±20% 范围内扰动，重新求解得表 N。结果显示结论____（稳定/翻转于临界值 X），表明模型在现实参数波动范围内可靠。"
- **时机**：与模型检验一起放在主体建模完成后（[[时间管理与团队分工]] 冲刺期），至少留 2–3 小时。
- **优先级**：优化类（成本/需求参数）、评价类（权重）、预测类（外生变量）优先做；机理类（物理参数）不可少。
