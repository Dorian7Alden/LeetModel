# 评审板块
> 论文各板块的评审要点拆解：评审怎么看每一块、得分点、失分点与写法要点——按板块独立成篇。
> 本文件夹适合：写某板块时对照评审要求自查、了解评审对各板块的权重与偏好等任务。
> 默认风格：清单式

## 子文件夹

| 子文件夹 | 说明 |
|---------|------|
| （无） |

## 文档

| 文档 | 说明 |
|------|------|
| 摘要评审要点.md | 评审怎么看摘要（鉴别阶段生死线/占分最高）、五要素、得分点与失分点（含美赛S奖案例） |
| 问题重述与分析评审要点.md | 重述与分析是"摘要的详细版"：提炼题意、问题分析的写法与失分点 |
| 模型假设评审要点.md | 假设合理性是官方第一评审维度：数量、必要性、与模型的呼应 |
| 模型建立评审要点.md | 核心评分点：数学化表达、推导链条、创新点；分题型的评审差异 |
| 模型求解评审要点.md | 结果正确性的证据：求解交代、可复现性、结果表规范 |
| 模型检验评审要点.md | 区分度最高的板块：检验三件套（回代/残差/误差）与 B 题铁律 |
| 敏感性分析评审要点.md | 结论稳健性的证据：参数扰动方法、呈现方式与常见走过场 |
| 模型评价与推广评审要点.md | 严谨性与视野：优缺点客观、推广具体可落地 |
