# 模型评价与推广评审要点

## 核心结论

模型评价与推广是论文的收尾板块，评审用它判断**这队是否具备科研严谨性与扩展视野**。理想状态：优缺点各 2–3 条、客观真实（缺点也说）、推广到具体可落地的场景。失分重灾区是空话套话——"本文模型推广价值大"式句子评审已经看吐了（[[阅卷人视角-常见失分点]]）。这块写得好是"加分收尾"，写不好是"整篇掉价"。

## 评审怎么看

1. **优点是否真实**：优点要与前文呼应（"机理推导完整（第 3 节）"），而非笼统"模型先进"。
2. **缺点是否诚实**：有无缺点比缺点本身更重要——只说优点 = 不严谨；缺点 + 改进方向 = 严谨。
3. **推广是否具体**：推广给谁用、解决什么问题、需做什么适配——空泛的"广泛应用"等于没说。
4. **篇幅是否克制**：评价+推广一般 0.5–1 页，写 3 页像注水。

## 得分点

1. **优缺点各 2–3 条，每条有依据**："优点：模型基于物理机理推导（3.2 节），参数少解释性强；缺点：假设风速恒定，强风场景误差增大（敏感性分析见 5.2 节）"。
2. **缺点带改进方向**："针对 X 不足，可采用 Y 方法改进"——展示科研思维。
3. **推广落地**："本模型可迁移至____场景（同类问题描述），需调整____参数即可"——给出可操作的迁移路径。
4. **与全文呼应**：评价内容引用前文章节号，体现整体自洽（评审喜欢的"闭环感"）。

## 失分点

| 失分点 | 表现 | 后果 |
|--------|------|------|
| 空话套话 | "本模型具有重要推广价值"（无场景无路径） | 评审阅读疲劳，直接跳过 |
| 只写优点 | 3 条优点 0 条缺点 | 不严谨信号 |
| 优点不真实 | "模型精度极高"但前文检验误差大 | 自相矛盾，可信度崩 |
| 推广空泛 | "可应用于各行各业" | 等于没说 |
| 篇幅失控 | 评价推广写 2 页以上 | 注水（[[阅卷人视角-常见失分点]]） |

## 写法要点

- **模板**：
  - 优点：从"机理/创新/检验/可视化"中选真实项，各 1 句 + 章节引用；
  - 缺点：从"假设局限/数据限制/计算成本"中选真实项，各 1 句 + 改进方向；
  - 推广：1 个具体场景 + 迁移所需调整。
- **评价节顺序**：优点 → 缺点 → 改进 → 推广，逻辑递进。
