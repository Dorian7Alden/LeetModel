# 模型假设评审要点

## 核心结论

"**假设的合理性**"是官方评审标准四维度之首（见 [[改卷注意点-2024讲评]]），但也是最容易被敷衍的板块。评审看假设只看一件事：**每条假设是否支撑后面的模型**——假设不是装饰品，而是模型的合法性来源。理想状态 3–5 条：每条假设对应一处简化，每处简化在后文有交代（何时失效、影响多大）。机理题（A 题）假设尤其重要：假设错 = 模型全错。

## 评审怎么看

1. **数量与质量**：3–5 条最佳；10 条以上且大半用不上 = 充数。
2. **与模型呼应**：评审会回查——假设里说的简化，模型里是否真的用了；模型里隐含的简化，假设里是否交代了。
3. **合理性辩护**：每处简化是否有理由（"为简化计算""数据支撑""误差可接受"），是否说明失效场景。
4. **机理题加重**：物理/工程题的假设（忽略摩擦、理想气体、均匀性等）直接决定方程形式，评审会逐条审（[[第一次评讲A题-笔记]]：假设 3–5 条是官方建议）。

## 得分点

1. **每条假设标注理由**：括号或注记"为简化 X 而设，误差方向为 Y"——比裸列假设高一个档次。
2. **关键假设不回避**：明知有误差也要写明，并说明影响（评审欣赏诚实与严谨）。
3. **假设即模型边界**：假设同时给出模型的适用边界（"在风速 ≤5m/s 时模型有效"）——这是加分项。
4. **与符号表呼应**：假设中引入的新变量进入符号说明表。

## 失分点

| 失分点 | 表现 | 后果 |
|--------|------|------|
| 假设过多过空 | 10+ 条通用废话（"假设数据真实""假设天气晴朗"） | 充数信号，评审反感 |
| 与模型无关 | 假设里说的在后文从未使用 | 形式主义，扣"假设合理性" |
| 漏关键假设 | 模型隐含了强假设却未声明 | 评审按此假设检验模型时发现模型站不住 |
| 假设过强 | 为了简单把关键因素全忽略（如机理题忽略核心物理量） | 模型与实际问题脱节 |
| 假设后文矛盾 | 假设 A 但模型用了非 A 的设定 | 逻辑不自洽 |

## 写法要点

- **建模过程中随手记**：国一选手经验——"写论文的同学需要在讨论题目的时候记得写下来，很容易忘记"（建模时每做一次简化就记一条）。
- **模板句式**："为简化____，假设____（依据/误差说明）"。
- **机理题专项**：方程推导前的每条假设要写清物理意义与适用范围（见 [[机理分析类题型特征]]）。
