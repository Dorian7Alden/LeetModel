# 模型检验评审要点

## 核心结论

模型检验是**获奖与陪跑的最大分水岭**：官方讲评反复强调"必须模型检验"（[[第二次评讲B题-笔记]]），大量论文倒在"模型建完直接给结论"上。评审看检验板块时只问：**结果能不能信**——检验三件套：① 模型检验（回代误差/残差分析/误差指标）② 与实测或常识对比 ③ 检验结论是否诚实。B 题铁律：**每一问都必须有检验**；数据类题：训练/测试切分验证是底线。

## 评审怎么看

1. **有无检验**：这是第一道分界线——完全没有检验的论文直接告别高奖级（2024 讲评与多次评讲都点名）。
2. **检验方法是否匹配**：预测类看误差指标（MAE/RMSE/MAPE）与测试集验证；拟合类看 R² 与残差分布；优化类看结果代回约束可行性；机理类看模型曲线 vs 实测散点（各题型见 [[常用模型速查-统计与机理类]]）。
3. **检验是否诚实**：检验结果不理想时的处理——诚实讨论 vs 掩盖，评审一目了然。
4. **与正文一致性**：检验结论与摘要/结果是否呼应。

## 得分点

1. **检验三件套**：
   - 模型检验：回代误差、残差图、误差指标表；
   - 对比验证：与实测数据/简单基准/常识对照；
   - 结论交代：检验通过/部分通过及原因。
2. **训练/测试切分**：数据类题用前 80% 拟合、后 20% 验证，报告测试集误差——"预测有效"的最有力证据（[[预测类题型特征]]）。
3. **可视化检验**：模型曲线 vs 实测散点图 + 残差图，比文字有说服力。
4. **每问必检**：每个小问的求解结果都跟一个检验小节（B 题完整性铁律）。

## 失分点

| 失分点 | 表现 | 后果 |
|--------|------|------|
| 完全无检验 | 求解完直接进入下一问 | 最大失分点，自动告别高奖级 |
| 走过场 | "经检验模型合理"——无方法无数字 | 等同没检验 |
| 检验方法错配 | 预测问题不做误差指标、优化问题不验证可行性 | 检验无效 |
| 数据泄露 | 用测试集信息做特征工程/归一化 | 检验结果虚假（学术硬伤） |
| 检验与结果矛盾 | 检验说误差大，正文仍宣称"模型准确" | 不诚实，评审降档 |

## 各题型检验方法速查

| 题型 | 标准检验 | 加分检验 |
|------|---------|---------|
| 预测类 | 训练/测试切分 + MAE/RMSE/MAPE | 预测区间、多模型误差对比 |
| 拟合/机理类 | 模型曲线 vs 实测散点 + 残差分析 | 参数灵敏度、另一组数据验证 |
| 优化类 | 最优解代回全部约束验证可行 | 与贪心/人工方案对比改进量 |
| 评价类 | 权重稳健性（换权重排序变化） | 多方法交叉验证（AHP vs 熵权） |
| 数据挖掘类 | 交叉验证 + 混淆矩阵/F1/ROC | 类别不平衡处理说明 |

## 写法要点

- **检验小节模板**："为验证模型有效性，将____数据代入模型，得到____（误差/残差），与____对比偏差____%，表明模型____。"
- **预留时间**：检验与灵敏度放在主体建模完成后的 8–10 小时做，不要拖到最后（[[时间管理与团队分工]] 冲刺期）。
- **诚实讨论**：误差偏大时说明原因（数据质量/假设局限）并提出改进方向——评审欣赏严谨。
