# 国赛 vs 美赛对比

## 核心结论

**国赛重"做对"（机理严谨、结果可靠、完整性），美赛重"做好"（想法新颖、表达清晰、过程完整）**。国赛免费、中文、查重极严、获奖率低但含金量高（国内升学硬通货）；美赛付费、英文、获奖面宽、国际化认可。备赛性价比最高的路径是：**先国赛后美赛**——用国赛练建模与写作基本功，用美赛练英文表达与开放题思路；两赛技能高度复用，主要增量成本是英文写作。

## 多维对比表

| 维度 | 国赛（CUMCM） | 美赛（MCM/ICM） |
|------|--------------|----------------|
| 时间 | 每年 9 月中旬，72 小时 | 每年 1 月底–2 月初，96 小时 |
| 语言 | 中文论文 | 全英文论文 |
| 费用 | 免费 | 100 美元/队 |
| 赛题 | 5 道（本科 A/B/C，专科 D/E），选 1 题 | 6 道（MCM A/B/C + ICM D/E/F），选 1 题 |
| 题型侧重 | A 机理/物理、B 综合优化、C 数据统计 | A 连续、B 离散、C 数据挖掘、D 运筹网络、E 环境、F 政策 |
| 论文要求 | 摘要 ≤1 页 + 正文 ≤30 页 + 附录；中文 | 全文 ≤25 页（含摘要/参考文献/附录/代码）；英文 |
| 查重 | **极严**：赛区+全国查重，重复率超标直接取消资格（一般红线约 20–25%） | 相对宽松，但抄袭同样取消资格 |
| 评审重点 | 摘要、假设合理性、建模创造性、**结果正确性**、模型检验、表达（得分点拆解见 [[评审维度与板块拆解]]） | 摘要、建模、求解、**表达与想法新颖性**、政策建议（ICM）；对"标准答案"要求弱 |
| 奖项结构 | 省奖约 ≤1/3 队；国一约 0.5%、国二约 2%（2025 年） | O 约 0.1%、F 约 0.3%、M 约 7%、H 约 18%（各年浮动） |
| 获奖面 | 窄（国奖尤其稀缺） | 宽（H 以上约 25%） |
| 认可度 | 国内升学/就业认可度最高（教育部学科竞赛名录） | 国际化亮点；国内认可度略低于国赛但仍是强加分 |
| AI 政策 | 允许使用，须遵守《AI 工具使用规定》，负全部责任 | 允许使用，**必须披露**（有官方 AI 使用报告模板） |
| 纪律 | 严禁队外交流、严禁社交平台讨论赛题（官网明列贴吧/QQ/知乎/CSDN/GitHub 等） | 同样严禁队外交流与分享任何赛题内容 |
| 评审流程 | 赛区评阅（省奖）→ 全国评阅（国奖） | 初审 → 正式评审 → 终审，决定为最终 |
| 适合人群 | 新手首选（中文、免费、流程规范） | 有国赛经验者、英语写作能力强者、想冲国际奖项者 |

## 评审侧重差异（阅卷视角）

- **国赛更"踩点"**：评阅按得分点给分（尤其 A 题类有参考答案的题），模型公式、求解结果、检验步骤都对得上才有高分——完整性>花哨（见 [[A_B题备赛要点]]、[[评阅标准启示-华数杯]]）。
- **美赛更"看整体"**：评审强调论文读起来像一份完整的研究报告；ICM 题明确要"policy memo"式论证；O 奖论文往往是"讲了一个好故事 + 严谨过程 + 清晰表达"。
- 两者共同点：**摘要都是第一道生死线**；**模型检验与灵敏度分析都是评分重点**（见 [[论文写作注意事项-培训记录]]）。

## AI 政策差异与选手应对

| 维度 | 国赛 | 美赛 |
|------|------|------|
| 政策文件 | 《AI 工具使用规定》（以当年发布为准） | 官方规则 + COMAP AI 使用报告模板 |
| 披露义务 | 不强制披露，但负全部责任 | 必须披露，不披露视为违规 |
| 评审核查 | 查重严格 + 模板化识别、数字一致性 | 核查 AI 报告真实性与结果可复现性 |
| 违规后果 | 取消评奖资格 | 取消资格 |
| 应对重点 | "自证清白"：合规自查、防模板化 | "主动交代"：填报告、保可复现 |

政策差异导致合规工作重心不同，但共同底线是**辅助不代写**；AI 时代两赛的题型/评审变化与选手策略总览见 [[AI影响下的赛事特点与选手策略]]。

## 关于美赛的争议（理性视角）

- 参赛者批评声音客观存在：美赛被部分参赛者视为"商业比赛"（100 美元报名费、美国本土参赛人数逐年下降而中国参赛队激增）；**获奖存在偶然性**——有人反馈身边省三水平队伍拿了 M 奖，S 奖里也可能有强队。
- 认可度争议：美赛奖项在国内升学就业中的认可度**不如国赛**（有参赛者明确认为"国二含金量高于美赛 M 奖"）；国际申请场景中美赛认可度也有限（见 [[美赛MCM-ICM详解]] O 奖冷静视角）。
- 客观结论：美赛 M/H 奖覆盖面宽、作为"国际化经历"与英文论文训练仍值得参加，但**不要把美赛奖项当作国内升学的主力筹码**——主次关系：国赛 > 美赛。

## 参赛策略建议

| 情况 | 建议 |
|------|------|
| 大一/零基础 | 先打五一杯/电工杯/华数杯热身，再上国赛 C 题 |
| 大二/有基础 | 主攻国赛（目标省一以上），寒假顺带冲美赛 M/H |
| 大三/保研冲刺 | 国赛冲国奖 + 美赛冲 M 以上，双线并进 |
| 英文弱 | 只打国赛；美赛留到英文基础补上后 |
| 工科机理强 | 国赛 A 题 / 美赛 A、B 题 |
| 数据/统计强 | 国赛 C 题 / 美赛 C 题（数据题人多竞争大，但发挥空间也大） |
| 社科/管理背景 | 美赛 E/F 题（政策类）竞争相对小，国赛 C 题 |
