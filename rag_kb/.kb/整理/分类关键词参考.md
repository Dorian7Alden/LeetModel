# 分类关键词参考

> 用途：整理任务中快速完成归位与 tags 决策的预置参考。
> 定位：**参考非穷尽**——未覆盖的关键词/场景时，询问用户，不随机生成。

## 1. 通用关键词池（按类别预置）

| 类别 | 关键词示例 |
|------|-----------|
| 内容形态 | 教程、原理、经验、清单、报告、指南、模板、心得、案例、综述、范文 |
| 任务 | 学习、备赛、准备、复盘、研究、写作、开发、面试、述职 |
| 领域 | 数学、编程、写作、实习、工作、竞赛、读书、外语 |
| 对象 | 概念、方法、流程、工具、模型、算法、制度、规范 |

## 2. 常见场景分类结构（建议归位 + tags）

| 场景 | 建议结构 | 常用 tags 示例 |
|------|---------|---------------|
| 读书笔记 | 书名/主题分文件夹，每章或主题一笔记 | `读书笔记, <书名>, <主题>` |
| 工作报告 | 按时间或项目分，一份报告一笔记 | `工作报告, <项目名>, <周期>` |
| 计算机学习 | 按语言/主题分文件夹，概念原子化 | `编程, <语言>, <概念>` |
| 实习准备 | 按公司/岗位/材料类型分 | `实习, <岗位>, 简历/面试/笔试` |
| 竞赛备考 | 按科目/环节分（数学建模库已示范） | `竞赛, <比赛名>, <环节>` |
| 范文收藏 | 领域 → 资源类型 → 赛事/题号 → 篇目文件夹（章节拆为笔记，示例见 `01-知识库组成机制.md` §4） | `范文, <赛事>, <年份>, <题号>` |

## 3. 使用规则

1. 归位匹配：素材关键词命中场景/类别 → 建议对应文件夹与 tags。
2. 无匹配：**询问用户**，不随机生成；新关键词可补入本参考（按 04 维护工作流）。
3. 多命中：按任务属性优先级取最贴合场景；仍不确定 → 询问。
