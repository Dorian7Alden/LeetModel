# 整理规范总入口

> 这份目录定义「素材 → 规整文档」的整理规范。
> 使用时机：把非结构化素材（PPT/PDF/网页/聊天/旧笔记…）整理成知识库笔记、或重构已有文档时，**必须**按本目录工作流执行。

## 子文件夹

| 子文件夹 | 说明 |
|---------|------|
| 风格/ | 文档风格目录：每个风格一个文件，统一五节结构 |

| 文档 | 说明 |
