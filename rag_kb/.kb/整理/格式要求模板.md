# 格式要求模板

> 用途：整理任务中用户对格式的可选覆盖项。未填的维度用所选风格自带的「默认格式要求」。
> 使用方式：整理请求时逐维度说明，或直接说「按 XX 风格默认格式」。
> 风格文件的「默认格式要求」节必须与本模板同维度、同取值域。

## 格式维度

| 维度 | 可选值 | 说明 |
|------|--------|------|
| 标题层级深度 | 无（平铺）/ 一级 / 两级 / 三级 | 原子笔记默认「无」——标题 + 平铺正文、不分节；一级/两级/三级仅在用户显式覆盖时使用（一级 = 仅 H2 分节） |
| 表格使用 | 是 / 否 / 仅对比数据时 | 表格的允许范围 |
| 列表与段落比例 | 条目化 / 叙事为主 / 混合 | 文档主体的组织方式 |
| 示例/代码/公式 | 必带 / 可选 / 不要 | 示例材料的要求 |
| 详略程度 | 极简 / 适中 / 详尽 | 内容的展开深度 |
| 语气 | 客观书面 / 第一人称 | 行文人称与风格 |
| 篇幅上限 | 不限 / 300 字 / 1000 字 / <自定义> | 正文字数上限 |
| 来源标注 | 保留素材出处 / 不保留 | 是否在文末标注素材来源 |

## 使用示例

- 「格式要求：标题两级、表格仅对比数据、适中、不保留来源」
- 「格式要求：按教程式默认，但篇幅上限 1000 字」
