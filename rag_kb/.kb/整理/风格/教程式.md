# 教程式

> 循序渐进学会做事，带步骤与示例，面向学习掌握。

## 适用场景

- 素材含操作步骤、过程、示例（工具使用、方法教学、流程学习）。
- 读者目的是「学会怎么做」。

## 结构模板

1. 目标：学完能做什么
2. 前置要求：需要先具备什么
3. 步骤：可照做的编号步骤，每步给结果
4. 示例：完整可复现的例子
5. 常见问题：易错点与处理

## 行文规则

- 步骤可照做：每步一个动作 + 预期结果。
- 示例具体：给输入、操作、输出。
- 不写纯概念铺陈：概念放到步骤里带出。

## 默认格式要求

| 维度 | 默认值 |
|------|--------|
| 标题层级深度 | 两级 |
| 表格使用 | 仅对比数据时 |
| 列表与段落比例 | 混合 |
| 示例/代码/公式 | 必带 |
| 详略程度 | 适中 |
| 语气 | 客观书面 |
| 篇幅上限 | 不限 |
| 来源标注 | 保留素材出处 |

## 示例骨架

```markdown
# <学会做的事>
> 目标：<学完能做什么>

## 前置要求
- <条件>

## 步骤
1. <动作> → <结果>
2. …

## 示例
<完整示例>

## 常见问题
- <问题>：<处理>
```
