# 风格目录说明

> 本目录存放文档风格定义：每个风格一个文件，统一五节结构（适用场景 / 结构模板 / 行文规则 / 默认格式要求 / 示例骨架）。

## 文档

| 文档 | 说明 |
|------|------|
| 教程式.md | 循序渐进学会做事，带步骤与示例 |
| 手册式.md | 条目化速查，每条独立自含 |
| 经验总结式.md | 心得与教训，允许第一人称 |
| 分析报告式.md | 结论先行 + 依据论证 |
| 清单式.md | 可执行的核对项 |

## 扩展规则

- 新增风格：新建 `<风格名>.md`（五节结构齐全）→ `整理/README.md` 风格索引表加行 → 本清单加行。
- 子库覆盖：子库（如 `数学建模/.kb/`）可建自己的 `整理/风格/`，同名文件覆盖父库风格，父库其余风格仍可用。
- 删除风格：删文件 → 两处 README 清单同步移除。
