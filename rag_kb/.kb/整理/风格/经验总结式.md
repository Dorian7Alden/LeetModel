# 经验总结式

> 心得与教训，允许第一人称，面向复盘。

## 适用场景

- 素材是个人经历、复盘、心得（比赛复盘、实习体会、学习感悟）。
- 读者目的是「吸取经验，避免重蹈覆辙」。

## 结构模板

1. 背景：什么场景、做了什么
2. 经验要点：有效做法与原因
3. 教训/坑：踩过的坑、触发条件、后果
4. 建议：下次怎么做（可行动）

## 行文规则

- 允许第一人称，但不写无关流水账。
- 要点带结论：不写「感觉没做好」，写「XX 环节因 XX 失败，应 XX」。
- 教训配触发场景：什么条件下会再踩。

## 默认格式要求

| 维度 | 默认值 |
|------|--------|
| 标题层级深度 | 两级 |
| 表格使用 | 仅对比数据时 |
| 列表与段落比例 | 混合 |
| 示例/代码/公式 | 可选 |
| 详略程度 | 适中 |
| 语气 | 第一人称 |
| 篇幅上限 | 不限 |
| 来源标注 | 不保留 |

## 示例骨架

```markdown
# <复盘主题>
> 背景：<什么场景、做了什么>

## 经验要点
- <做法>：<为什么有效>

## 教训/坑
- <坑>（触发条件：<…>）：<后果与原因>

## 建议
- <下次怎么做>
```
