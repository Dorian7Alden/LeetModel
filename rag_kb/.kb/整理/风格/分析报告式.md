# 分析报告式

> 结论先行 + 依据论证，面向决策理解。

## 适用场景

- 素材含分析、对比、判断（问题分析、方案对比、标准解读）。
- 读者目的是「快速知道结论 + 为什么」。

## 结构模板

1. 结论：第一段直接给核心结论
2. 依据/论证：支撑结论的理由与逻辑
3. 数据与证据：可核查的数字、事实、引文
4. 边界/风险：结论的适用条件与失效情形

## 行文规则

- 结论先行：第一段说清「是什么 / 该怎么做」。
- 论证给理由：每点依据配因果或对比。
- 数据可查：数字标注来源或出处。

## 默认格式要求

| 维度 | 默认值 |
|------|--------|
| 标题层级深度 | 两级 |
| 表格使用 | 仅对比数据时 |
| 列表与段落比例 | 叙事为主 |
| 示例/代码/公式 | 可选 |
| 详略程度 | 适中 |
| 语气 | 客观书面 |
| 篇幅上限 | 不限 |
| 来源标注 | 保留素材出处 |

## 示例骨架

```markdown
# <分析主题>
> 结论：<核心结论一句话>

## 依据/论证
- <理由>：<因果或对比>

## 数据与证据
- <数字/事实>（来源：<出处>）

## 边界/风险
- <适用条件与失效情形>
```
