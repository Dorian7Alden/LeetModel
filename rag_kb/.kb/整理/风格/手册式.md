# 手册式

> 条目化速查，每条独立自含，面向检索。

## 适用场景

- 素材是定义、参数、命令、规则等条目性内容（API、配置、术语表、规范条目）。
- 读者目的是「快速查到某一条」。

## 结构模板

1. 条目列表：按逻辑分组；每条包含定义 → 要点 → 边界/注意。
2. 条目形式：编号列表，或「术语/说明」两列表格。

## 行文规则

- 每条独立自含：单读一条能懂，不依赖上下文。
- 定义先行：先下定义/给值，再展开。
- 边界明确：适用范围、限制、常见误用。

## 默认格式要求

| 维度 | 默认值 |
|------|--------|
| 标题层级深度 | 两级 |
| 表格使用 | 是 |
| 列表与段落比例 | 条目化 |
| 示例/代码/公式 | 可选 |
| 详略程度 | 极简 |
| 语气 | 客观书面 |
| 篇幅上限 | 不限 |
| 来源标注 | 保留素材出处 |

## 示例骨架

```markdown
# <条目主题>
> 速查：<本手册覆盖什么>

## <分组名>
- <条目>：<定义>。要点：<…>。注意：<边界或误用>。
```
