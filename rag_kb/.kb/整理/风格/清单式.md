# 清单式

> 可执行的核对项，面向执行前检查。

## 适用场景

- 素材是待办、检查项、流程要求（提交前检查、评分点、准备工作）。
- 读者目的是「按清单执行/核对」。

## 结构模板

1. 条目清单：编号列表，每条含触发条件与完成标准。
2. 分组（可选）：按环节/类别分组。

## 行文规则

- 每条可独立勾选：动词开头、标准可判（对/不对）。
- 触发条件明确：什么情况下执行这条。
- 不做展开论述：背景说明放到条目外。

## 默认格式要求

| 维度 | 默认值 |
|------|--------|
| 标题层级深度 | 一级 |
| 表格使用 | 否 |
| 列表与段落比例 | 条目化 |
| 示例/代码/公式 | 不要 |
| 详略程度 | 极简 |
| 语气 | 客观书面 |
| 篇幅上限 | 不限 |
| 来源标注 | 不保留 |

## 示例骨架

```markdown
# <清单主题>
> 使用时机：<什么时候按此清单执行>

## <分组名（可选）>
- [ ] <动作>：<完成标准>（触发条件：<…>）
```
