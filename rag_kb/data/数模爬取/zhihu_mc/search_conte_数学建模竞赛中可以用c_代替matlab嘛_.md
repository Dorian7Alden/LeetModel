# 数学建模竞赛中可以用c++代替matlab嘛？
作者: B***n | 链接: https://www.zhihu.com/question/434020830/answer/1633517524 | 赞同: 184 | 来源关键词: 数学建模竞赛

完全可以。如果你只是想得个奖而已，用什么都无所谓。但如果你的目标是国一，使用C++进行建模编程会有几个优势，也会有几个小问题。先说优势，Matlab其实更适合矩阵运算，对逻辑比较复杂的时候，效率会很低(比如沙漠掘金这种)。C++的面相对象的特性会更容易组织数据结构。Matlab的parafor限制太多，并行开销大，C++更适合并行计算，方便将程序提交集群用大量算力解决问题。Matlab集群太难配置(反正我一直没配好）。说实话，大部分人使用Matlab的编程能力太差，只是用Matlab完成编程，而不是在写Matlab程序，很难发挥Matlab的优势。再说c++的劣势：1. 相比Matlab调试程序不方便。2. 如果只用C++就还需要单独处理数据输出和做图的问题。C++将结果输出到文本是方便的，但还需要再用Matlab或者Phython画图脚本读入数据进行画图。4. c++编程可能需要某些单独的库(比如boost)，到答辩时，如果让你运行程序，但运行环境有问题就尴尬了。5. 用c++编程是不是等同于放弃了Matlab杯的评奖资格？还是会把更好的高教社杯给你？更新一下吧。我23年指导的学生用c++拿了国一了，做的太阳能发电站那个题。
