# 到底什么是“数学建模”？如何准备数模比赛？
作者: <***M | 链接: https://zhuanlan.zhihu.com/p/2032607392307917649 | 赞同: 8 | 来源关键词: 数学建模经验

hi~我是北海，最近数模比赛比较多，又一批新手参(入)赛(坑)。新手常见疑惑：到底什么是“数学建模”？参加比赛该如何准备？其实你早就做过数学建模初学者往往对数学建模感到陌生，实际上我们从小就接触过数学建模问题，那就是所谓的“数学应用题”：已知足球的半径为11 cm，需要多少面积的原材料？一辆车保持匀速60 km/h行驶，多久能跑完300 km的路程？太简单？稍微增加点难度：航天器速度达到多少能够脱离地心引力？具有三对相对性状的小白鼠，想要得到理想性状该如何设计杂交实验？一件100欧元的商品，欧元对人民币汇率下降20%后购买能少支付多少钱？类似的数学题以及涉及物理等其他学科的问题，想必中学生都做过很多，而当你求解这些问题时无意中就用到了数学建模。没错，各行各业的实际问题，其在数学上的理论描述与求解过程，就是数学建模！在数学建模竞赛中，题目更是涵盖了经济、管理、环境、资源、生态、工程技术等多个领域。例如往年各项竞赛题目出现过浴缸设计、市场菜价、人口变化预测、潜水艇定为和部署、小行星采矿、网球比赛分析、野生动物保护策略等。这些题目都是现实世界中遇到的问题，需要我们运用数学知识去解决再看一些难度更大的问题：如何设定实验温度和催化剂，来优化化学反应条件以提高产品收率？电动汽车越来越普及，一个城市该怎样部署充电站最合理？大学评奖学金，该如何制定评价标准从而对学生进行综合评选？不同地区耕地资源差异大，该如何根据气候、市场、亩产量、成本等因素，制定农作物的种植策略，使得每年收益尽可能大？事实上数学建模早已深度融入各行各业。无论是简单的数学题还是复杂的工程问题，都可以归纳为一系列步骤来解决：问题理解：通过研究背景资料（查文献、书籍资料等），将实际问题转化为数学语言（确定研究的对象，在数学上定义变量）。模型建立：基于专业理论知识构建数学模型，描述变量之间的关系（方程组、函数表达式等）。模型求解：利用编程和软件（如MATLAB、Python）求解模型，得到数学上的解（数值或矩阵、图表等形式）。结果呈现：撰写论文，清晰、完整地展示模型、思路和结果。对于大学生来说，所接触的具有代表性的例子就是《大学物理》课本：其中的每一章节几乎都是一个数学建模的案例，从理论基础到推导过程，再到结果展示，其理论研究的过程，实际是就是在数学建模。简而言之，数学建模所做的，就是把现实问题“翻译”成数学语言，并加以求解，最后在理论上对问题给出解决方案——直观来看，一组数学公式 + 对公式和变量的定义与解释 = 一个数学模型。以牛顿第二定律为例，其本身是个物理定律：物体速度的变化（加速度）与其受到的合力成正比，与其质量成反比。为了定量且精确地表述这个客观定律，建立相应的数学模型：  F为物体受到的合力（单位牛顿，N）m为物体的质量（单位千克，kg）a为物体的加速度（单位米/二次方秒，m/s2）这一简单的数学模型，就能描述力、质量和加速度三者之间的关系。相应的模型假设：研究对象为有质量且可忽略大小与形状的理想物体，在惯性参考系中进行常规运动（接近光速时或对于微观粒子，牛顿力学会失效）。例如对于一个受到10 N 合力的质量为2 kg 的物体，由公式可知其加速度为 ，可得弹簧振子模型：该模型是一个微分方程的形式，核心理论还是牛顿第二定律。因此，数学模型不是一个枯燥的公式，而是一个“公式+解释+应用”的整体。该怎么准备数模竞赛？报名了比赛，不知道该怎么准备；或是看网上资料很多，不知道从哪下手。数模相关的资料往往几十章节、上百页，实际上并不需要全都学完再比赛的，见文章：想参加数学建模比赛，但什么都不会，该怎么学呢？对于新手来说，走好这几步即可：1、基础的数学知识。只需要基础掌握高数、线代就可以了。高数会微积分，线代了解基本的矩阵运算。记住，数模是在实战中学习的，而不是学好了再去实战！2、入门编程MATLAB或Python都可以。不会编程也没什么，模型思路确定好后，查阅资料、问AI，现学现用即可。3、用好Word排版这一点是很重要的！也经常是被新手忽略的。想想从小学到高中，语文老师讲写作文时跟你强调过什么？字迹工整！如果你写的字都龙飞凤舞，阅卷老师哪有心情欣赏你的文采？同理，数模论文也是篇文章，如果你的文章排版都乱七八糟，老师哪有心情欣赏你的“大作”？一篇文章入眼，首先就是整体页面、图表、文字排版。好比一个人去相亲，如果穿的邋里邋遢，即使其他各方面都符合你的期望，你觉得你会心动么？4、可靠的队友数模是三人组队的战斗。不怕队友不会，就怕队友放弃。遇到不会的大家冷静讨论，讨论不出来就分配任务，每个人都去啃硬骨头，失败了也不相互埋怨，这样的队伍才能有始有终地做完比赛。否则一言不合就窝里斗，一遇到困难就有人退出，那这比赛压根没法做了。如果这次发现队友不行，下次就不找他了。多做几次竞赛，总能遇到靠谱的队友，组建长期的队伍。5、心态开始几次比赛都没拿到奖，很多人就开始放弃数模了。却不知参加数模的从大一到大四的都有，每个人最开始几次参加基本都拿不到奖。比赛期间一定要以为获奖而拼的态度去做，而赛后一定要认识到自己能力不足、拿不到奖也是正常的。在参加几次比赛后就会发现适合自己的“套路”，之后就能斩获国赛美赛等大奖了。6、正确使用AI如今AI功能很强了，但仍摆脱不了其本质：工具。在没有AI的时候，比赛遇到问题都是去百度；现如今遇到问题都是去AI，两者本质上没区别，都是工具罢了。如果你连数学建模常见的各种专业名词都不知道，又能憋出什么提示词去问AI呢？有怎么能看的明白AI的回答呢？说白了，AI无论是用来想思路还是编程等等，用好了都能事半功倍，但用不好被AI耍了都不知道（明明是2024年的数据，AI偏嘴硬说是2025年的；还有一道求纬度的题求出北纬200度……）大家对AI使用方面有什么疑惑或看法？可以在评论区讨论，后面我也可能出一些讲解课程~【往期文章】数学建模AI知识库
