# 怎样准备全国大学生数学建模竞赛？
作者: s***y | 链接: https://www.zhihu.com/question/21398636/answer/2041566013808972847 | 赞同: 3 | 来源关键词: 数学建模竞赛

下面按知识点主线整理，不按题号硬抄。填空题知识点整理一、增长与传播模型1. Logistic 模型标准形式：[ \frac{dx}{dt}=rx\left(1-\frac{x}{K}\right) ]其中：[ K=\text{环境容量} ]核心结论：[ \lim_{t\to+\infty}x(t)=K ]增长速度最大时：[ x=\frac{K}{2} ]通解常用形式：[ x(t)=\frac{K}{1+Ce^{-rt}} ]用初值 (x(0)) 求 ©。2. SIR 模型[ S=\text{易感者} ][ I=\text{感染者} ][ R=\text{恢复者/移除者} ]感染人数变化一般看：[ \frac{dI}{dt}=\beta SI-\gamma I =I(\beta S-\gamma) ]若 (I(0)&gt;0)，疾病初期蔓延条件为：[ \beta S(0)-\gamma&gt;0 ]即：[ \boxed{S(0)&gt;\frac{\gamma}{\beta}} ]3. Volterra 捕食模型设：[ x=\text{食饵数量},\qquad y=\text{捕食者数量} ]周期平均值通常由非零平衡点决定，做法是令：[ \frac{dx}{dt}=0,\qquad \frac{dy}{dt}=0 ]若捕捞强度增大，一般结论是：[ \boxed{\text{对食饵有利，对捕食者不利}} ]因为捕食者被捕捞后，食饵被捕食压力减小。二、泛函与差分方程1. 最简泛函与欧拉方程泛函：[ J[x]=\int_{t_1}^{t_2}F(t,x,x’)dt ]如果 (F) 只含：[ t,\ x,\ x’ ]不含 (x”) 等高阶导数，则是最简泛函。取极值的必要条件是欧拉方程：[ \boxed{\frac{\partial F}{\partial x}\frac{d}{dt}\left(\frac{\partial F}{\partial x’}\right)=0 } ]例如：[ J[x]=\int_0^1\left[(x’)^2+2tx\right]dt ]有：[ F=(x’)^2+2tx ][ \frac{\partial F}{\partial x}=2t ][ \frac{\partial F}{\partial x’}=2x’ ]所以：[ 2t-\frac{d}{dt}(2x’)=0 ][ \boxed{x”=t} ]2. 差分方程平衡点差分方程：[ x_{n+1}=f(x_n) ]平衡点满足：[ \boxed{x^=f(x^)} ]稳定性判断：[ |f’(x^*)| ]则平衡点稳定。简单理解： 稳定就是偏离一点还能回去；不稳定就是偏离一点就越跑越远。三、层次分析法与 Leslie 模型1. 成对比较矩阵基本性质：[ a_{ij}&gt;0 ][ a_{ii}=1 ][ a{ij}=\frac{1}{a{ji}} ]一致矩阵进一步满足：[ \boxed{a{ij}a{jk}=a_{ik}} ]若 (n) 阶判断矩阵完全一致：[ \lambda_{\max}=n ]所以：[ CI=\frac{\lambda_{\max}-n}{n-1}=0 ]一般一致性检验：[ CR=\frac{CI}{RI} ]若：[ CR&lt;0.1 ]则一致性可以接受。2. Leslie 年龄结构模型Leslie 矩阵结构：[ L= \begin{pmatrix} b_1&amp;b_2&amp;\cdots&amp;b_ns_1&amp;0&amp;\cdots&amp;00&amp;s_2&amp;\cdots&amp;0\vdots&amp;\vdots&amp;\ddots&amp;\vdots \end{pmatrix} ]其中：[ b_i=\text{各年龄组生育率} ][ s_i=\text{进入下一年龄组的存活率} ]递推公式：[ \boxed{x_{k+1}=Lx_k} ]长期趋势：[ \lambda&gt;1：\text{种群增长} ][ \lambda=1：\text{种群稳定} ][ \lambda：\text{种群减少} ]稳定年龄结构由：[ \boxed{\text{主特征值对应的特征向量}} ]决定。四、数值算法、抢渡模型与量纲分析1. 常微分方程数值算法向前欧拉法：[ \boxed{y_{n+1}=y_n+h f(t_n,y_n)} ]特点：[ \boxed{\text{一阶，显式}} ]梯形法：[ y_{n+1}=y_n+\frac h2\left[f(t_n,yn)+f(t{n+1},y_{n+1})\right] ]因为右边含有未知的 (y_{n+1})，所以是：[ \boxed{\text{隐式算法}} ]2. 抢渡长江模型设：江宽 (H)终点在对岸下游 (L)水流速度 (v)用时 (T)则人自身游泳速度满足：[ \boxed{ u= \sqrt{ \left(\frac{H}{T}\right)^2+ \left(\frac{L}{T}-v\right)^2 } } ]其中：[ \frac{H}{T} ]是横渡方向速度；[ \frac{L}{T}-v ]是人相对水流在下游方向需要提供的速度。3. 量纲分析法基本依据：[ \boxed{\text{量纲齐次性原理}} ]一般步骤：[ \boxed{ 选变量 \rightarrow 写量纲 \rightarrow 设幂函数关系 \rightarrow 比较指数 \rightarrow 得关系式 } ]注意： 量纲分析通常只能得到变量组合关系，不一定能唯一确定完整函数表达式。最后总主线这部分填空题主要考：[ \boxed{ 模型识别 \rightarrow 公式套用 \rightarrow 平衡/极限/稳定性判断 } ]最核心要记住：[ \boxed{\text{Logistic 看 }K} ][ \boxed{\text{SIR 看 }\frac{\gamma}{\beta}} ][ \boxed{\text{差分看 }x^=f(x^)} ][ \boxed{\text{Leslie 看主特征值和特征向量}} ][ \boxed{\text{量纲分析看量纲齐次}} ]
