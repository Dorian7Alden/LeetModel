# 如何看待西电自 2019 年起不再认可野队美赛的成绩？
作者: f***p | 链接: https://www.zhihu.com/question/307047116/answer/560645227 | 赞同: 20 | 来源关键词: 美赛

预测成真。学校大幅增加数模保研难度。----------先说我的结论，这句话主要在于劝退，学校真这么操作的概率比较小。美赛这个东西，水分大。然而学校又不得不承认。每年美赛保研的占全部竞赛保研的比例太大了。想要一口气取消美赛保研，怎么说，积重难返。且不说学生教师的反响，单单每年的保研名单拿出来也不好看。然而每年美赛人数又不断增多，竞赛保研是只看奖项，不看人数。那竞赛保研人数逐渐挤压正常成绩保研人数，也妨碍了大部分学生利益啊。（就我所知，今年关于美赛保研的斯逼就不少，甚至还有写校长信箱的）。提高美赛保研难度，f奖才能保？那和直接取消美赛也差不多了。为了追求平衡，劝退大多数野队，不失为一个正常操作。至于野队们，其实也不用担心，有奖的话，还是会一样对待的。到时候应该会有统计，多关注一下群就行了。-----利益相关：大四老狗，国二 + 美一另：美赛的重要性逐渐降低，说不准哪一年就直接取消保研了。还望学弟学妹们多留后路，毕竟学校出通知的尿性大家还是懂的。
