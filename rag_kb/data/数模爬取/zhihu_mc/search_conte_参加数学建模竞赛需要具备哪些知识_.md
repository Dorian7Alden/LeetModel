# 参加数学建模竞赛需要具备哪些知识？
作者: 大***头 | 链接: https://www.zhihu.com/question/451206410/answer/1814660746 | 赞同: 179 | 来源关键词: 数学建模竞赛

我觉得比赛中最重要的有几点札实的数学基础，包括高数，线代种概率。所以我一般不建议大一的同学参加比赛，尽管靠运气有时也能获奖。大一的学生就该好好学习基础课。精通一门编程语言，首选 python 和matlab。&#34;精通&#34;的意思包括两个层面: 1掌握最基本和最常见的模型和算法的程序实现。2建模有了方案时，能够短时间内用程序实现。一套擅长的排版系统。word和latex二选一即可。latex 并不适合大部分人，不要跟风和被老师误导。排版只要过得去即可，切勿浪费太多时间。快速获取和学习新知识的能力。包括阅读外文文献，快速检索和科学上网的能力。赛前准备的模型算法很多情况下都用不上，更多的是要比赛当中现学。如果真要赛前学习一些模型，那就学一些最常用的，例如规划，图论，排队论等。持久不倒的体力，特别是男孩子。每一个数模人都经历过熬夜，特别是数模新手。怜香惜玉的我一般是不允许队中的女孩子熬夜的。经验。赛前模拟和赛后复盘很重要。
