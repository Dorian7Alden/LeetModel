# 我开源了一套数学建模skills！
作者: z***. | 链接: https://www.xiaohongshu.com/explore/6a071180000000000702fa6e | 点赞: 

我们整理开发了一套完整流程的数模skills，将整个流程拆分成为24个skill，大致流程如下：
题目解析 → 题型分类 → 文献分析 → 候选方法池生成 → 统一符号表构建
→ 统一假设文档 → 数据清洗审计 → 代码结构规划 → 代码生成(Python/MATLAB双轨)
→ 代码审查 → 多方法实验报告生成 → 稳健性与敏感性分析 → 最终方法详解
→ 图表规划与生成 → 论文材料包整合 → 论文写作 → 论文润色
→ 参考文献核查 → 终稿质量审查

大概覆盖了基本的流程，其中图表部分参考了 nature-skills 的 figure contract 思路，论文润色部分借鉴了其12步润色检查流程

目前支持Claude Code和Codex两大主流工具，欢迎大家使用和提出建议！

https:// github .com/zhnnky329/MathModeling-skills
