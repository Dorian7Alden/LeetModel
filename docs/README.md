# LeetModel 开发文档 (Docs)

这里是 LeetModel 项目的开发文档目录。本目录存放了项目的核心架构设计、业务调研报告、开发规范以及各项技术分析资料。

## 📁 目录结构与文件说明

### 核心文件
| 文件名 | 作用描述 |
| ------ | -------- |
| [**`standard.md`**](standard.md) | **项目全局开发与文档规范**（必读）。包含：后端统一异常处理规约、响应状态码分段设计标准，以及 Markdown 文档的强制撰写格式要求。 |
| [**`memo.md`**](memo.md) | **项目备忘录**。存放开发过程中的随手记、灵感、待办或尚未体系化的笔记。 |
| [**`LeetModelStarUML.mdj`**](LeetModelStarUML.mdj) | **UML 模型源文件**。使用 StarUML 绘制的流程图、状态图、系统交互用例图等建模工程与模型。 |
| [**`README.md`**](README.md) | **文档目录导航**（本文档）。 |

### 子目录说明

#### 1. [`/dev-report`](dev-report)
**系统各核心业务模块的详细设计方案与分析报告：**
- `01-标签系统设计.md`：题目和赛事使用的多级标签分类体系设计。
- `02-响应码.md`：API 交互中自定义响应状态码的演变和梳理说明（新规范已升至 standard.md）。
- `03-赛事管理.md`：竞赛模块相关的设计构思及数据结构分析。
- `04-题目管理.md`：题库管理、判题机交互及题目 CRUD 细节。
- `05-oss管理.md`：文件存储及图片/资源上传组件（OSS）对接文档。
- `06-权限管理.md`：登录链路及各角色（学生、普通用户、管理员）的访问权限管控策略。
- `/AI评审机制研究/`：探索引入大模型作为智能辅助系统（如自动生成题目、智能代码评审、学习反馈）时的核心方案研究，内置多种 `提示词-*` 设定与 `测试集`。

#### 2. [`/system-design`](system-design)
**项目的总体架构文档区：**
- `系统设计-v1.md`：项目 v1.0 版本的全览性技术架构、模块划分与核心架构选型说明。
