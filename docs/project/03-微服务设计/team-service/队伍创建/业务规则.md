## 业务规则

### 数据与规则归属

- team-service 拥有队伍、固定容量和队长成员关系，并负责在一个事务内完成创建。
- problem-service 拥有题目及发布状态。team-service 通过内部契约校验题目可用于练习，不直接读取题目数据库。
- team-service 只保存题目唯一 ID 和完成练习所必需的快照，不复制题目主数据。

### 创建约束

- 只有登录用户可以创建队伍。
- 练习题目、队伍名称不能为空，队伍简介可以为空。
- 创建时绑定的题目必须存在、已发布且可用于练习。
- 所有队伍固定最多三人，创建接口不允许调用方决定容量。
- 创建者固定成为队长，并计入三人容量。
- 队长身份不可转让，也不能降为普通成员。
- 同一用户在同一道题目下已经参加未结束队伍时，不能再次创建队伍。
- 队伍记录与队长成员关系必须同时成功或同时失败，不能产生没有队长成员关系的队伍。

### 异常结果

- 未登录、题目不可用、表单信息不合法或重复参加同题目练习时，创建失败且不产生队伍数据。
- problem-service 校验不可用时，不能把未知状态当作题目有效；创建失败并返回明确的依赖不可用结果。
- 创建失败不触发页面跳转，用户仍停留在发起创建的页面。
