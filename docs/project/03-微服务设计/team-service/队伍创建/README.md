## 队伍创建

### 功能目标

让登录用户从题目详情页或“我的队伍”页完成最少信息填写，创建一支绑定已发布题目的练习队伍，并自动成为队长。

### 范围

- 两个创建入口复用同一个弹窗。
- 选择一道已发布题目。
- 填写队伍名称和队伍简介。
- 创建固定最多三人的队伍并建立队长成员关系。
- 创建成功后跳转到“我的队伍”页。

### 非目标

- 不在创建阶段配置人数上限、招募开关、成员或成员职责。
- 不在创建阶段开始练习。
- 不允许通过创建弹窗新建或修改题目。
- 不允许浏览全部题目后翻页选择；“我的队伍”入口必须先输入标题关键词检索。
