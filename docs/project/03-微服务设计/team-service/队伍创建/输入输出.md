## 输入输出

### 创建信息

创建队伍只接收以下业务信息：

| 信息 | 必填 | 说明 |
|------|------|------|
| 练习题目 | 是 | 提交题目唯一 ID；界面同时展示题号和标题 |
| 队伍名称 | 是 | 用于识别队伍 |
| 队伍简介 | 否 | 用于说明队伍目标或特点 |

人数上限不是用户输入。队伍容量固定为三人，客户端不展示该字段，team-service 也不信任或接收调用方提供的容量值。

### 题目选择

- 题号是 problem-service 所拥有的题目唯一 ID，在界面中以“题号”命名，不额外建立可重复或需要同步的编号字段。
- 题目标题只用于展示和关键词检索，不能作为队伍与题目的关联标识。
- 题目详情入口携带当前题目的题号和标题初始化弹窗。
- “我的队伍”入口通过公开题库关键词查询选择题目，查询范围只包含已发布题目。
- 题号可能超过 JavaScript 安全整数范围，跨服务和前端传递时必须保持原值，不能发生数值精度截断。

### 创建结果

创建成功后返回新队伍信息，至少能够支持“我的队伍”页立即识别新队伍、当前用户的队长身份以及绑定题目。完整响应字段以当前 VO 和接口定义为准，不在设计文档复制字段结构。
