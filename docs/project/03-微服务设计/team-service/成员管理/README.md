## 成员管理

### 功能目标

维护队长与普通成员关系，在队伍组建阶段保证固定三人容量、成员唯一性和专业职责覆盖。

### 范围

- 创建者建立为不可转让的队长。
- 组建中添加、移除和退出成员。
- 分配建模、编程和论文专业职责。
- 维护成员作品提交权限。

### 非目标

- 不支持转让队长。
- 不允许练习开始后增减成员。
- 不将用户昵称和头像保存为成员事实。
