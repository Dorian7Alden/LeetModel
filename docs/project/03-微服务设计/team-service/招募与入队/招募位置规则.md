# 招募位置规则

- 一条招募信息代表一个待加入的成员位置，只能最终接纳一名成员。
- 招募位置保存独立的发布时间。队伍广场与详情展示该位置的创建时间，不以队伍成立时间代替。
- 每条招募至少选择建模、编程、论文中的一个职位，允许多选。
- 每条招募可以附带最多 512 个字符的 Markdown 说明，用于描述练习目标、协作方式和队友期待。服务端保存原始 Markdown，前端展示时解析并进行 HTML 安全净化；编辑弹窗提供实时预览。
- 发布和编辑招募均通过弹窗完成。只有组建中的队长可以发布、编辑或关闭开放招募位置；编辑可以修改职位组合和文字说明，但不能改变招募位置标识、发布时间或状态。
- 成员数与开放招募位置数之和不能超过固定人数上限三人。队长创建队伍时已经占用一个成员位置，因此最多同时发布两个开放招募位置。
- 组建中，队伍详情和组队广场展示开放招募位置；开始练习、练习结束和已解散状态均不展示招募内容。
- 开始练习或解散时，team-service 自动关闭全部开放招募位置和待处理申请。
