## 招募与入队

### 功能目标

允许组建中的队长按成员位置发布招募信息，申请人针对具体位置申请，并由队长在固定容量内审核成员加入。

### 范围

- 独立招募位置及其建模、编程、论文职责需求。
- 入队申请的提交、取消、审核和关闭。
- 审核通过时的并发容量校验。

### 非目标

- 不允许练习开始后继续招募或审核申请。
- 不根据成员现有职责自动推断招募需求。
- 不允许客户端绕过申请审核直接成为成员。
- 不实现队长主动邀请或按用户标识直接添加成员。
