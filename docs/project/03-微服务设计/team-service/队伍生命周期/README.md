## 队伍生命周期

### 功能目标

用互斥且可解释的业务状态约束队伍从创建、组建、练习到结束的全过程，并保证页面展示和可执行操作与状态一致。

### 范围

- 组建中、练习中、练习结束和已解散四种状态。
- 开始练习、提前结束、到期自动结束和组建期解散。
- 队长、普通成员在不同状态下的操作权限。
- 普通成员作品提交权限的授予、撤销和上传校验。
- “我的队伍”列表的状态分组。

### 非目标

- 不把作品提交状态或 AI 评审状态作为队伍生命周期状态。
- 不支持转让队长。
- 不支持练习结束后恢复练习。
- 不在当前队伍列表展示已解散历史。
