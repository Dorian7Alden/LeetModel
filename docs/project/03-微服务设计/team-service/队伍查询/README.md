## 队伍查询

### 功能目标

为队伍广场、我的队伍和队伍详情提供符合使用者关系与生命周期状态的查询结果。队伍广场允许用户分别从缺人队伍、练习题目和开放招募职位三个入口发现可参与的练习队伍。

### 范围

- 公共队伍分页查询与招募条件筛选。
- 公共队伍中的题目摘要和成员公开摘要聚合。
- 队伍广场三类发现视图、即时筛选和导航状态恢复。
- 当前用户参与队伍的查询。
- 队伍详情、成员公开摘要和当前用户关系。

### 非目标

- 不复制 user-service 的用户资料。
- 不将公开队伍与我的队伍合并为同一查询语义。
- 不在当前队伍列表展示已解散历史。
