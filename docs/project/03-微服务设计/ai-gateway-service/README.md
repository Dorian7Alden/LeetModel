# AI 网关服务

> AI 网关是业务服务访问外部模型供应商的唯一出口。

`ai-gateway-service` 是已确定但尚未创建代码目录的目标微服务。文档目录名与后续的后端模块名保持一致。

## 职责边界

### 负责

- 统一接入模型供应商并屏蔽供应商协议差异。
- 维护供应商、模型、场景路由、价格和非敏感配置。
- 安全读取和使用模型密钥，防止密钥进入业务服务和日志。
- 执行超时、有界重试、限流、熔断和主备模型切换。
- 记录单次模型调用、Token、价格快照、成本、耗时和失败原因。
- 向管理后台提供用量、成本和稳定性统计能力。

### 不负责

- 不定义论文评审、AI 裁判、改进建议或题目推荐的业务 Prompt。
- 不编排业务工作流，不解释业务结果。
- 不判断 AI 业务结果是否正确，不定义质量指标。
- 不保存论文、评审结果、对话或其他完整业务内容。

## 数据与协作边界

AI 网关独占 `lm_ai` 数据库，拥有供应商、模型、场景路由、价格规则和调用记录。业务服务通过 `common-ai` 调用 AI 网关，只传递场景、业务标识、Prompt 和必要追踪信息。管理后台通过内部接口查询统计，不直连 `lm_ai`。

## 功能清单

| 功能 | 功能说明 |
|------|----------|
| 供应商管理 | 维护可用模型供应商和必要配置 |
| 模型管理 | 维护模型能力、状态和可用场景 |
| 场景路由 | 根据业务场景选择主模型、备用模型和调用参数 |
| 统一 AI 调用 | 屏蔽不同供应商协议差异并返回统一结果 |
| 文本与多模态输入 | 向业务服务提供文本、图像和 PDF 等模型输入能力 |
| 稳定性治理 | 处理超时、有界重试、限流、熔断和主备切换 |
| 调用记录 | 记录调用场景、模型、状态、Token、耗时和失败信息 |
| 价格与成本 | 维护价格口径并计算单次调用成本 |
| 调用追踪 | 将业务任务、工作流程步骤和单次模型调用关联 |
| 用量与稳定性统计 | 按模型、场景和时间聚合用量、成本、耗时和成功率 |
