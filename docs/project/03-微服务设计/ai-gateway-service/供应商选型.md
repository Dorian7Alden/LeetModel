## 供应商选型

### 选型结论

首版优先接入 DeepSeek 官方 API，作为文本推理和评审的主要供应商。第二个接入阿里云百炼与通义千问，用于验证多供应商架构并补齐图像、文件和更广的多模态能力。第三个只在需要故障切换实践或模型横评时，从智谱 GLM 或火山方舟豆包中选择一个。

当前不建议同时接入四个供应商。本项目的目标是验证抽象、路由、计量和对账，不是维护一个模型市场。

### 对比

| 供应商 | 适合本项目的能力 | 计费与治理特点 | 建议定位 |
|----------|--------------------|--------------------|----------|
| DeepSeek | 文本生成、思考模式、Json 输出和工具调用，适合论文评审和裁判，当前不承担 PDF 多模态理解 | 输入区分缓存命中和未命中，输出单独计价 | 文本主供应商 |
| 阿里云百炼 | 千问文本、视觉、Omni、长文本和批处理模型选择丰富 | 存在地域、输入长度阶梯、缓存、批处理和多模态分项价格 | 多模态与备用供应商 |
| 智谱 GLM | 中文、推理、工具调用和视觉模型，国内开发者平台完整 | Token 模型与部分按次模型并存，资源包和现金扣减口径不同 | 可选的横评供应商 |
| 火山方舟豆包 | 文本、深度思考、视觉理解和丰富媒体能力 | 模型服务、插件、按次和 Token 计量可组合出现 | 可选的多模态横评供应商 |

比较表只用于确定接入价值和治理复杂度。模型质量不依赖宣传语或通用榜单定结论，最终通过本项目的固定评测集、重复运行和 AI 质量评价服务对比。

### DeepSeek 价格基线

以 2026 年 8 月 24 日官方价格页为基线，DeepSeek 官方 API 按百万 Token 计价。`deepseek-v4-flash` 的缓存命中输入为 ¥0.02，未命中输入为 ¥1，输出为 ¥2。`deepseek-v4-pro` 的对应价格为 ¥0.025、¥3 和 ¥6。

该数字只是选型时的可追溯基线，不是运行时常量。DeepSeek 官方已明确保留调价权利，系统仍必须使用版本化价格规则和账单对账。

### 实施顺序

1. 先用 DeepSeek 打通文本同步、流式、用量分项、价格快照和幂等。
2. 接入千问文本模型，验证第二供应商、主备切换和差异化用量解析。
3. 接入一个千问视觉模型，验证内容块、多模态能力过滤和模态计量。
4. 导入至少一个供应商账单样本，验证预估成本和结算成本的差异。
5. 只在上述抽象稳定后，再选择智谱 GLM 或豆包做第三供应商实践。
