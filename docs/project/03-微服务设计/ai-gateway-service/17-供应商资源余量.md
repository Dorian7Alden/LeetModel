## 供应商资源余量

> 设计状态：已由 new-api 取代。供应商余额、Token 余量和渠道资源状态不属于 LeetModel，后续不得在 `ai-gateway-service` 恢复该能力。确需观察时使用 new-api 管理能力；LeetModel 只保存与自身调用关联的 usage 和费用事实。

### 设计目标

统一展示供应商账号可查询的余额、Token 余量或其他剩余资源，为管理员观察账号资源状态提供参考。

### 已确认边界

- 供应商支持查询时，AI 网关可以调用其资源查询接口并归一化结果。
- 并非所有供应商都提供余额或 Token 余量接口，统一结果中的相关字段必须允许为空。
- 余额与 Token 余量是供应商资源状态，不属于单次调用运行时成本，也不扩展为账单对账。
- 当前不使用查询结果执行项目成本封顶或余额不足阻断。

### 待逐项确认

- 供应商是否支持资源查询的能力声明和适配器接口。
- 账号余额、币种、Token 余量、资源类型和供应商原始单位的统一结构。
- 不支持查询、查询失败、权限不足和供应商返回空值的状态区分。
- 查询频率、缓存时间、最近成功时间和数据新鲜度展示。
- 多账号结果是分别展示还是提供只作参考的聚合视图。
- 查询接口失败是否触发账号健康变化，以及怎样避免误伤正常模型调用。
- 管理端权限、日志脱敏和供应商接口调用频率限制。

### 与主流程的关系

资源余量查询由管理查询模块独立触发，不进入每次模型调用的必经链路，也不阻塞原子调用任务消费。
