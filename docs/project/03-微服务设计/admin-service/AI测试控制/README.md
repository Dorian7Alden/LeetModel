## AI 测试控制

AI 测试控制是管理员维护固定样本集、启动 AI 功能版本实验并查看原始指标与版本选择指数的管理端入口。后端代理和页面已覆盖 REVIEW 与 ASSISTANT 的功能定义、规模预估、任务控制、版本化权重、追加重算、原始指标、权重贡献、版本比较与调用追踪。

页面版本字段遵守 [AI版本标识.md](../../../02-架构设计/AI版本标识.md)：候选“功能版本”展示 `workflowVersion` 的名称与稳定标识，配置摘要分别展示 Prompt、模型执行配置和适用的 RAG 索引版本；API 路径版本不得出现在候选业务版本中。

admin-service 只负责鉴权后的操作入口、命令转发和跨服务展示，不拥有评价数据，不计算指标、归一化或权重结果。
