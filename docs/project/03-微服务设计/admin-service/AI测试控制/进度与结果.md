## 进度与结果

进度页展示整体状态、各评审版本进度、各测试用例结果，以及已完成、执行中和失败的运行数量。管理员可以离开页面，之后通过 `查看详情` 返回。

部分运行失败时，页面展示原因和影响范围。管理员点击 `重试失败项` 只重新执行失败组合，不重复运行成功项。

实验完成后，管理员查看各版本在每个样本上的评分序列、平均分、方差、标准差、极差，以及成功率、耗时和失败分类。点击版本或测试用例的明细可以继续查看单次结果和失败信息。

页面不再把 `[0,100]` 的旧 `overallScore` 展示为综合质量分，也不展示没有标准答案或人工标注支撑的语义正确性。通用平台落地后，可以在原始指标之后展示带评价目标、权重方案和口径版本的“版本选择指数”；它不得解释为准确率或客观质量。当前页面仍展示旧字段属于待 S8、S9 调整的实现差异。
