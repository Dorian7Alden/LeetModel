## 进度与结果

任务列表展示功能、工作流版本、状态、终态槽位/总槽位进度、版本选择指数和创建时间。数据来自服务端，每次页面加载或完成写操作后重新读取；浏览器不以本地状态伪造任务进度。管理员可以离开或刷新页面，之后通过 `详情` 返回。

等待或运行中的任务可以暂停；暂停任务可以恢复；等待、运行、暂停或失败任务可以取消，取消前明确说明历史结果仍保留；失败任务可以重试，后端只重新执行允许重试的失败组合，不重复运行成功项。每次控制成功后页面重新拉取列表。

详情展示功能、工作流版本、模型执行配置、适用的 RAG 索引、权重方案、进度、重试次数、版本选择指数、成功率、平均耗时、最近操作及各运行槽位。迁移前的 REVIEW 任务仍可打开：缺失功能按 REVIEW 展示，未锁定权重明确标为“历史任务未锁定”，缺失版本选择指数显示“不可用”。

任务列表和详情不再把旧 `overallScore` 称为综合质量分，只展示带评价目标、权重方案和口径版本的“版本选择指数”，并将缺失明确显示为不可用。版本对比页暂时保留旧口径分仅用于迁移兼容；原始指标、贡献、调用追踪及新版比较视图由 S8-07 继续收口，任何位置都不得把版本选择指数解释为准确率或客观质量。
