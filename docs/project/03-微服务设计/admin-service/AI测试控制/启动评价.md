## 启动评价实验

管理员从评价任务列表新建实验。页面只允许选择功能目录返回的 `REVIEW` 或 `ASSISTANT`、与功能匹配的不可变数据集、状态为 `ENABLED` 的 `workflowVersion` 以及状态为 `ACTIVE` 的同功能权重方案；不再接受任意版本文本。

页面展示输入/输出口径、固定模型执行配置和兼容说明。`ASSISTANT_RAG_V1` 额外要求填写已经构建并锁定的 `ragIndexVersion`；无 RAG 版本和 REVIEW 不发送伪造的索引版本。重复次数为 1 至 20，任务配置最终由评价服务再次校验并快照。

创建前必须调用规模预估接口。页面展示样本数、重复次数、总槽位、预计模型调用次数，以及费用金额或无法可靠估算的原因；超过后端限制时不得创建。管理员先确认完整配置和预估，预计调用数达到 20 或可追溯预计费用达到 1 时，还必须通过独立的“高成本任务二次确认”。取消任一确认都不会创建任务。

确认后页面提交数据集、工作流版本、模型执行配置、适用的 RAG 索引版本、权重方案、重复次数和一次性幂等键。系统锁定这些配置并异步运行；页面不把创建前缺少价格快照的费用伪装为零。
