## 测试集操作

管理员进入 `质量评价` 页面，在测试集列表点击 `新建测试集`，填写名称、用途说明并选择评价功能。测试集创建后形成不可变的 `datasetVersion` 和样本口径版本，后续任务只引用该版本，页面不提供就地修改样本的入口。

`REVIEW` 测试集从管理员可见的提交记录中选择一个或多个 PDF 提交，提交列表每次最多读取接口允许的 100 条。PDF 与题目不对应、文件不存在或不可读时，下游服务拒绝保存。

`ASSISTANT` 测试集按行录入彼此独立的问题，空行会被忽略。页面把每行问题保存为 `QUESTION` 样本及 `ASSISTANT_QUESTION_V1` 载荷，不把问题正文写入日志或文档。

管理员点击 `创建` 完成操作。没有名称、没有有效 REVIEW 提交或没有有效 ASSISTANT 问题时，页面在提交前给出明确提示；服务端继续承担功能与样本口径的最终校验。
