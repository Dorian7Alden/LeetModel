## 服务协作

| 页面操作 | 后台职责 |
|----------|----------|
| 添加测试用例 | ai-evaluation-service 校验并保存测试集定义 |
| 确认启动实验 | ai-evaluation-service 锁定配置并创建稳定性实验任务 |
| 查看实验进度 | admin-service 聚合任务状态和实验评审状态 |
| 重试失败项 | ai-evaluation-service 重新组织失败运行 |
| 查看对比结果 | admin-service 聚合展示原始指标、口径信息和适用时的版本选择指数，不执行计算 |

AI 业务服务产生隔离实验结果，ai-gateway-service 记录模型调用资源事实，ai-evaluation-service 计算指标、归一化和版本选择指数。实验不修改用户正式结果；没有标准答案或人工标注时，不调用另一个 AI 的自由判断冒充质量真值。
