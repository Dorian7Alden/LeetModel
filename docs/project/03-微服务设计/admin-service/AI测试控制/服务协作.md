## 服务协作

| 页面操作 | 后台职责 |
|----------|----------|
| 添加测试用例 | ai-evaluation-service 校验并保存测试集定义 |
| 确认启动评价 | ai-evaluation-service 锁定配置并创建评价任务 |
| 查看评价进度 | admin-service 聚合评价状态和实验评审状态 |
| 重试失败项 | ai-evaluation-service 重新组织失败运行 |
| 查看对比结果 | admin-service 聚合指标、资源数据和综合得分 |

ai-review-service 产生实验评审结果，ai-gateway-service 记录模型调用资源数据。实验评价不修改用户正式评审结果。
