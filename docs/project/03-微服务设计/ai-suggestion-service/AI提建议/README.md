## AI 提建议

AI 提建议面向已经完成任意版本 AI 评审的每一个论文版本，由有权用户手动发起。系统结合题面、版本化 PDF 解析产物、可用的评审反馈和知识检索来源，生成可定位、可执行、可验收的数学建模论文改善报告。

历史论文不会因为它只有 `BASIC_REVIEW_V1` 而被排除：系统会在建议任务的准备阶段补齐解析，并将历史结构化评语投影为不可变的评审依据快照。如果某条历史评审确实只有分数、没有任何可用说明，系统创建新的 `EVIDENCE_REVIEW_V2` 评审任务，不覆盖旧评审。

### 范围

- 同一论文版本允许多次手动生成独立建议报告。
- 每项建议同时保留论文、评审和知识三段依据。
- 从数学建模完整过程和论文表达两个层面给出建议。
- 对页码、评审发现和知识引用执行确定性校验。
- 对历史已完成评审提供解析补齐和评审依据兼容准备，不改写原评审。

### 非目标

- 不自动随评审完成生成建议。
- 不修改原论文或生成可以直接提交的代写论文。
- 不重新评分，不覆盖 AI 评审结果。
- 不在缺少可靠参考资料时自由补造建议。

### 当前版本

S12 已发布 `GROUNDED_SUGGESTION_V2`，并保留现有 `IMPROVEMENT_V1` 的代码、数据与历史读取。公共创建入口只创建 V2；同一论文版本和所选已完成评审可以使用新的 `clientRequestId` 多次创建独立报告，相同标识的网络重试返回原任务。

V2 正式链路锁定 `VECTOR_RAG_V1`。`AI_DIRECTORY_V1` 与 `HYBRID_RETRIEVAL_V1` 虽已在独立服务完成受控实现和安全校验，但在固定对比实验达到既有门槛前不允许由用户入口选择；未来启用必须发布新的建议工作流版本，不改变 V2 历史语义。
