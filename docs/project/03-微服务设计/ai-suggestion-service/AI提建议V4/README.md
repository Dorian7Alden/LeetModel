## AI 提建议 V4

> 设计状态：已确认设计，尚未实现。
> 确认日期：2026 年 9 月 16 日。

`GROUNDED_SUGGESTION_V4` 将建议从“具体药方和高分升华”调整为专业、克制、有依据的方向指引。
它明确区分确定性补缺、完整性增强和可选探索，避免把主观建模选择描述为唯一正确路径。


### 设计原则

1. 确定性错误可以明确修复，主观建模选择只能提供方向和取舍。
2. 每条建议独立说明当前事实、为什么值得处理、可以补充什么方面和如何验收。
3. 原文证据由服务端从解析块生成，模型不得自行复制为原文。
4. 每条建议至少具有论文依据和知识依据；确定性修复还必须引用评审问题。
5. 报告按优先级排序，但不使用夸张的“照做即可获奖”叙述。
6. 长说明使用 Markdown，前端统一通过 `MarkdownView` 渲染。
