## 评价指标

稳定性评价使用可从重复实验直接计算的指标：

| 指标 | 含义 |
|------|------|
| 评分方差 | 同一样本多次总分相对平均分的平方偏差，越小表示波动越小 |
| 评分标准差 | 方差的平方根，与论文评分单位一致，是主要展示指标 |
| 评分极差 | 同一样本最高分与最低分之差，用于补充观察最大波动 |
| 输出成功率 | 所有预定运行中产生合法结构化评分的比例，用于判断统计数据是否完整 |
| 响应时间 | 从开始执行到产生结果的耗时，只作为性能和异常诊断信息 |

当前没有客观标准答案，也不引入 AI 裁判真值，因此不评价相关性、依据充分性、语义正确性或用户满意度。即使方差很小，也只说明输出可重复，不能说明多次输出都正确。价格和 Token 可以作为运行成本信息展示，但不进入稳定性计算。

后续若增加质量指标，必须先按 [评价指标与版本选择指数.md](../评价指标与版本选择指数.md) 锁定标准答案、确定性校验器或人工标注证据；不能仅把指标改名后从现有稳定性数据推导质量结论。
