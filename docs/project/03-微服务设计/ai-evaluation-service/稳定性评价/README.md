## 稳定性评价

稳定性评价使用固定样本集重复执行同一 AI 评审版本，观察同一样本评分的方差、标准差和波动范围。输出成功率和响应时间用于诊断运行可靠性，不作为主观内容质量分。

本功能不调用另一个 AI 对日志、Prompt、回答或评审结果进行二次评价。数学建模论文评审具有主观性，不同使用者对同一结果可能有不同感受，也缺少统一标准答案。增加 AI 裁判会继续引入随机性和成本，无法提供与投入相称的可信结论。

稳定性只能说明同一功能在固定条件下输出波动较小，因而具有一定参考价值；不能证明评审正确、公平，也不能代表所有用户满意。
