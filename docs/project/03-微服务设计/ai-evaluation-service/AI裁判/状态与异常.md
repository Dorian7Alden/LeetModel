## 状态与异常

评价任务经过 `PENDING`、`RUNNING`、`COMPLETED` 或 `FAILED`。每个样本与重复轮次拥有独立运行槽位，每次尝试都留存，不覆盖历史失败。

- 测试集为空、题目不可读、PDF 不可用或题目与 PDF 不对应时，不创建评价任务。
- 候选评审版本不存在或不可执行时，不开始评价。
- `OUTPUT` 失败表示工作流未产生合法结构化输出，它计入版本有效性和成功率，任务仍可完成并对比。
- `ENVIRONMENT` 或 `CONFIGURATION` 失败表示评价环境或配置故障，不计为版本质量，任务标记失败且不生成综合得分。
- 管理员只能重试上述环境/配置失败；重试会创建新尝试。服务也会恢复超时停留在 `RUNNING` 的尝试。
