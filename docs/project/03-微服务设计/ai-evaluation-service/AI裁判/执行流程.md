## 执行流程

```mermaid
flowchart LR
    A[选择测试集和版本] --> B[校验并锁定配置]
    B --> C[重复执行实验评审]
    C --> D[保存结果耗时和失败分类]
    D --> E[计算评价指标]
    E --> F[归一化并计算综合得分]
    F --> G[生成版本对比结果]
```

管理员确定测试集、候选版本和重复次数后创建评价任务。ai-evaluation-service 校验输入并锁定本次配置，然后按测试用例、评审版本和重复轮次组织实验评审。

实验评审与用户正式评审隔离。运行结束后，系统保存评审得分、耗时、模型和失败分类，完成固定规则与统计计算。MVP 不收集价格成本，也不调用额外裁判模型。
