## 评价指标

MVP 使用四类可从实验评审直接得到的指标：

| 指标 | 含义 |
|------|------|
| 输出有效性 | 固定样本和重复运行中产生合法结构化评分的比例 |
| 重复评审稳定性 | 同一版本重复评审同一 PDF 时，总分区间是否接近 |
| 响应时间 | 评审从开始执行到产生最终结果的耗时 |
| 评审成功率 | 所有预定运行槽位中完成并产生分数的比例；MVP 与输出有效性数值相同，单独返回是为后续区分技术成功与业务有效性 |

结构完整性和数值范围等内容由 ai-review-service 的输出契约保证。当前没有人工标签或独立裁判真值，因此不把相关性、依据充分性和语义正确性写成已实现指标。价格成本也要等 ai-gateway-service 的持久化调用记录提供稳定关联后再加入。
