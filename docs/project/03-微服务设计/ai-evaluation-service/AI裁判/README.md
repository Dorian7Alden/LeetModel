## AI 裁判

AI 裁判使用固定测试集评价不同 AI 评审工作流版本。MVP 已实现输出有效性、重复分数稳定性、成功率和响应时间的固定计分；语义质量裁判和价格成本尚未实现，页面与文档不得把它们展示为已测指标。

当前只维护一套 MVP 评价口径，不预先建立通用裁判版本。未来若增加人工标签、AI 裁判或成本数据，必须显式版本化口径，不与现有结果混比。
