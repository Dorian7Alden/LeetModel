## AI 裁判

AI 裁判使用固定测试集评价不同 AI 评审版本，将质量、稳定性、成本、响应时间和成功率汇总为 `[0,100]` 的版本综合得分。

当前只设计第一版评价机制。后续优化可以调整具体口径，但不预先划分裁判版本。
