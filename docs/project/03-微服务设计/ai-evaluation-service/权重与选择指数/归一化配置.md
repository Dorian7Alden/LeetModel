## 归一化配置

归一化只把不同量纲的原始指标转换为 `[0,100]` 的决策输入，不生成新的业务事实，也不表示准确率或客观质量。S8-01 只定义版本化配置与纯计算规则；权重方案、持久化和版本选择指数由后续任务完成。

### 配置快照

每条配置固定保存以下参数：

- `normalizationVersion`、`metricCode`、`metricVersion` 和原始 `unit`。
- `method`、`clippingPolicy` 和 `missingPolicy`。
- 外部容忍边界 `lowerBound`、`upperBound`；目标区间方法还保存 `targetLowerBound`、`targetUpperBound`。
- `boundarySource`、`boundaryReference` 和 `applicableFeatures`。

合法边界来源只有已经确认的 `BUSINESS_THRESHOLD` 和可追溯的 `VERSIONED_BASELINE`。当前任务批次的最小值、最大值或其他即时统计量不是合法来源，因此候选集合变化和常量样本都不会改变同一原始值的归一化结果。不可归一化指标使用 `NOT_APPLICABLE`，不保存数值边界。

当前唯一截断策略为 `CLAMP_0_100`。缺失策略只有 `MARK_UNAVAILABLE` 和 `MARK_NOT_EVALUATED`，不存在零填充策略；不可用结果的 `normalizedValue` 必须为空。

### 计算规则

设原始值为 `x`，外部边界为 `L < U`，最终结果统一截断到 `[0,100]`：

- 越高越好：`(x - L) / (U - L) * 100`。
- 越低越好：`(U - x) / (U - L) * 100`。
- 目标区间：在 `[TL,TU]` 内为 `100`；在 `(L,TL)` 从 `0` 线性增加至 `100`；在 `(TU,U)` 从 `100` 线性降低至 `0`；外部为 `0`。
- 不可归一化：返回 `NOT_NORMALIZABLE`，不返回数值。

目标区间必须满足 `L < TL <= TU < U`。线性方法不能携带目标边界；所有可计算配置必须有非空边界引用。计算精度为小数点后六位、`HALF_UP`，展示层可以另行格式化但不能改变快照值。

### 缺失与异常边界

- 原始值缺失时按配置返回 `UNAVAILABLE` 或 `NOT_EVALUATED`，不能返回 `0`。
- 越界值按固定边界截断；它不参与重新估计边界。
- 上下界相等、目标区间位于外部边界之外、缺少版本/单位/功能/来源等配置在创建时直接拒绝。
- 指标方向、口径版本和功能适用性与注册表的兼容校验属于权重方案创建门禁，在 S8-02 落地。

### 验收基线

`EvaluationNormalizationServiceTest` 确定性覆盖正向、反向、目标区间、不可归一化、边界、越界、常量样本、缺失值和非法配置。2026-08-29 执行 `mvn -pl ai-evaluation-service -am test` 通过，评价模块 65 项测试零失败。
