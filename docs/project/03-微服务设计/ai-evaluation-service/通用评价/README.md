## 通用评价

通用评价把现有论文评审稳定性运行扩展为按 AI 功能、工作流版本和版本化数据集组织的隔离实验平台。评价服务拥有实验编排与评价事实，被评价服务仍拥有工作流执行和业务结果语义。

### 范围

- 统一描述功能、候选版本、不可变数据集版本、任务、槽位和运行尝试。
- 兼容迁移现有 REVIEW 数据，不丢失历史任务和运行结果。
- 为后续指标注册、Runner、控制命令和同口径比较提供稳定边界。

### 非目标

- 不复制 PDF、正式评审、客服会话或模型供应商配置。
- 不在领域模型设计阶段删除旧字段或把旧 `overallScore` 重命名为版本选择指数。
- 不提前接入尚无隔离实验入口的 SUGGESTION。
