# 客服与 RAG 可验证指标

## 证据边界

客服评价只计算能够由锁定实验输出、版本化样本或人工标注明确证明的维度。运行成功、低延迟、低费用和低波动都不能替代语义质量证据。没有证据的指标返回 `NOT_EVALUATED`，不填零分，也不参与质量结论。

隔离实验仍不保存完整回答或知识正文。`ai-assistant-service` 仅向评价链路返回：

- 回答（只在本次同步调用中供确定性规则计算，评价库最终仅保存 SHA-256 和长度）；
- 锁定物理索引的检索片段数；
- 去重后的知识库相对来源路径。

这些检索元数据用于复算，不包含片段内容。

## 样本证据

`ASSISTANT_QUESTION_V1` 在保持旧样本兼容的前提下支持以下可选证据字段：

| 字段 | 用途 | 缺失语义 |
|------|------|----------|
| `expectedSources` | 与实际检索来源精确匹配，计算标准来源覆盖率 | `NOT_EVALUATED` |
| `formatRules` | 执行固定、版本化的确定性格式规则 | `NOT_EVALUATED` |
| `expectedPoints` | 对标准要点做规范化文本包含检查 | `NOT_EVALUATED` |

允许的格式规则只有 `ANSWER_NON_BLANK`、`ANSWER_MAX_2000`、`NO_MARKDOWN_CODE_FENCE` 和 `REQUIRES_SOURCE_MARKER`。未知规则直接拒绝，不能把自由提示词或另一个模型的判断混入确定性规则。

## 指标定义

| 指标 | 计算条件 | 计算方式 | 不能推出的结论 |
|------|----------|----------|----------------|
| `RETRIEVAL_HIT_RATE` | RAG 版本且 owner 明确返回检索条数 | 条数大于 0 为 100%，否则 0% | 检索内容正确或回答正确 |
| `SOURCE_COVERAGE_RATE` | 样本有标准来源且 owner 返回来源数组 | 命中标准来源数 / 去重标准来源数 | 来源内容支持回答主张 |
| `FORMAT_RULE_PASS_RATE` | 样本有固定规则 | 通过规则数 / 规则总数 | 语义正确或主观质量高 |
| `EXPECTED_POINT_COVERAGE_RATE` | 样本有标准要点 | 规范化后被回答文本包含的要点数 / 标准要点数 | 同义改写下的完整语义正确性 |
| `HUMAN_QUALITY_SCORE` | 有版本化人工量表与标注 | 后续人工标注链路提供 | 当前始终 `NOT_EVALUATED` |

`EXPECTED_POINT_COVERAGE_RATE` 是保守的确定性文本覆盖指标，不命名为语义正确率。真正的语义正确性只有在后续接入可追溯标准答案判定程序或版本化人工评分后才能定义。

## 聚合与展示

每个指标保存 `evaluatedCount / eligibleCount`：全部成功槽位有证据为 `AVAILABLE`，部分有证据为 `PARTIAL`，没有证据为 `NOT_EVALUATED`；无 RAG 版本的检索命中为 `NOT_APPLICABLE`。聚合值只对已有证据的槽位取算术平均，页面必须同时展示证据覆盖数，不能隐藏缺失样本。

历史 owner 结果可能没有检索轨迹。此时检索命中和来源覆盖保持未评价；只有明确返回零条检索时才记录 0%。

## 验收基线

- RAG 用例锁定索引版本，验证检索命中、标准来源、格式规则和标准要点均可确定性复算。
- 无证据用例验证人工评分为 `NOT_EVALUATED`，值保持 `null`。
- 历史无检索轨迹结果不被误算成 0%。
- 自由文本或模型裁判规则被样本校验拒绝。
- 客服及公共依赖 63 项测试通过（8 个需外部环境的 smoke 测试显式跳过），评价及公共依赖 56 项测试通过，管理端生产构建通过。
