## 接口约定

### 筛选项

`GET /api/public/problems/filter-options` 无需登录，聚合返回全部预置赛事和标签。标签包含类型，调用方据此将标签分为背景领域、题目类型、模型与算法三组。

### 分页查询

`GET /api/public/problems` 无需登录。分页参数为 `page` 和 `pageSize`，可选条件包括 `contestId`、`year`、`statementLanguage`、`difficulty`、`tagIds`、`minAverageScore`、`maxAverageScore`、`keyword`、`sortBy` 和 `sortOrder`。

- 未传条件时查询全部已发布题目。
- `tagIds` 最多包含一个背景领域、一个题目类型和多个模型算法标签。多个模型算法标签按 AND 匹配；背景领域或题目类型重复选择返回业务错误。
- 分数上下限均为包含边界，取值范围为 0 至 100；最低分大于最高分时返回业务错误。
- 空白关键词不参与查询。
- `sortBy` 只支持 `year`、`difficulty`、`averageScore`，`sortOrder` 支持 `asc`、`desc`；未指定排序字段时按创建时间倒序。
- 调用方传入的题目状态不能改变公开接口只返回已发布题目的约束。
- 响应分页字段为 `total`、`page`、`size` 和 `rows`。列表行返回题目唯一 ID、题目摘要、赛事信息与标签名称，不返回 Markdown 题面和附件。
- 公开题库列表只展示当前页序号和题目标题，不展示具体题号；进入题目详情后，将题目唯一 ID 标注为“题号”。创建队伍的题目检索结果仍同时展示题号和标题，以区分重名题目。题号直接使用 `ProblemVO.id`，不新增另一套业务编号；客户端必须按无精度损失的形式接收、保存和提交该值。

### 题目详情

`GET /api/public/problems/{id}` 无需登录，只能读取已发布题目。详情返回可为空的 Markdown 题面以及零个或多个附件；不存在和未发布统一按题目不存在处理。
