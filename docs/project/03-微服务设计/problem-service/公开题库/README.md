## 公开题库

### 功能目标

使调用方获取公开筛选条件，分页查询已发布题目，并进入题目详情查看可渲染题面和可选附件。

### 范围

- 预置赛事和可用标签的公开查询。
- 已发布题目的分页查询和条件筛选。
- 标题与题面的关键词分词检索，以及检索不可用时的数据库降级。
- 题库列表展示当前页序号和题目标题，题目详情展示唯一题号。
- 已发布题目详情的公开访问。
- 未发布题目的隔离。

### 非目标

- 不实现 AI 题目推荐。
- 不实现向量语义检索；向量召回由知识库与 AI 客服链路单独负责。
- 不实现背景领域的同类多选和用户自定义排序；题目类型与模型算法允许多选。
