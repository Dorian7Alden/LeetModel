## 公开题库

### 功能目标

使调用方获取公开筛选条件，分页查询已发布题目，并进入题目详情查看可渲染题面和可选附件。

### 范围

- 预置赛事和可用标签的公开查询。
- 已发布题目的分页查询和条件筛选。
- 已发布题目详情的公开访问。
- 未发布题目的隔离。

### 非目标

- 不实现 Elasticsearch 全文搜索。
- 不实现 AI 题目推荐。
- 不实现背景领域、题目类型的同类多选和用户自定义排序；模型算法允许多选。
