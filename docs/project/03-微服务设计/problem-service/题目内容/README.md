## 题目内容

### 功能目标

使题目详情只依赖标题、可直接渲染的 Markdown 题面和可选附件，不让前端识别多种题面格式。

### 范围

- 题目标题和可为空的 Markdown 题面。
- 一道题目的零个或多个附件。
- 附件说明、展示顺序与下载。
- 题目与附件在 MySQL 和 MinIO 之间的一致性边界。

### 非目标

- 不自动将 PDF 或其他格式转换为 Markdown。
- 不将 PDF、HTML 或富文本作为并行题面格式。
- 不提供附件在线预览、版本管理和跨题复用。
