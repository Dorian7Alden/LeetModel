## 题面规则

### 输入

管理员维护题目时提交题目标题和可选的 Markdown 原文。Markdown 原文直接作为题目数据持久化，不先上传为题面文件。

### 格式边界

- Markdown 是唯一支持的可渲染题面格式。
- Markdown 题面允许为空。题面为空不阻止题目保存或发布。
- 原始题面为 PDF 或其他格式时，管理员在入库前完成 Markdown 转换。
- 原始题面需要保留时，按普通附件处理，不建立第二套题面模型。

### 输出

题目列表只返回题目摘要，不返回 Markdown 原文，避免分页响应夹带大段题面。题目详情返回 Markdown 原文，前端直接将其作为 Markdown 渲染。

前端的题目详情只渲染题目标题、Markdown 题面和附件信息。
