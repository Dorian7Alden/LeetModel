## 赛事规则

### 赛事识别

赛事是题库内的预置基础数据。首版固定包含国赛、美赛和项目官方的 LeetModel 力模数学建模竞赛。每个赛事具有不受展示名称变化影响的稳定编码。

预置赛事由 Flyway 迁移统一初始化。题目保存赛事标识，不在业务代码中通过条件分支将赛事编码转换为数字标识。

### 生命周期边界

- 系统不维护即将开始、进行中和已结束等真实比赛生命周期状态。
- 全部预置赛事均可用于题目归属和公开题库筛选。
- 首版不提供赛事删除能力。

### 题目归属

- 每道题目必须归属一个已存在的赛事。
- 题目只保存赛事标识，不复制赛事名称和编码作为题目主数据。
- 赛事与题目的引用完整性由 problem-service 校验和维护。
