## 文件资产管理

### 功能目标

文件资产管理为手动素材和各业务正式文件提供稳定 fileId、技术元数据、逻辑分组、访问策略、引用保护与存储生命周期，并通过 MinIO 保存二进制内容。

### 范围

- 管理文件资产、逻辑命名空间和分组。
- 支持后台小文件代理上传和大文件预签名直传。
- 动态生成有界时效的访问地址。
- 消费业务绑定事件并维护引用投影。
- 支持逻辑删除、延迟物理清理、失败重试和存储对账。
- 渐进接管现有题目附件、头像和正式论文文件。

### 非目标

- 不拥有题目附件、用户头像选择和论文提交等业务关系。
- 不统一接管首期论文上传分片。
- 不保存预签名 URL 或文件 BLOB。
- 不处理静态资源动态替换和 Markdown 外链本地化。
- 不在第一阶段开放任意对象强制物理删除。
