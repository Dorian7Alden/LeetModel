## 知识库存储与管理

> 功能定位：负责 LeetModel 知识库物理事实源的存储解耦、元数据生命周期管理、Markdown 结构化解析分块以及 Elasticsearch 派生索引的构建与事件驱动增量同步。

### 目标与范围

- 将知识内容资产从代码仓库中彻底解耦，统一迁移托管至高可用分布式对象存储（MinIO）；
- 建立规范的关系型元数据表，支持文档的“草稿、发布、归档”完整生命周期与多版本哈希追踪；
- 针对原子 Markdown 文档构建 AST 语法树解析器，自动提取 YAML Frontmatter，并在切块时注入全局目录面包屑；
- 管理 Elasticsearch 物理索引生命周期，保障全量构建蓝绿原子切换，并基于 RocketMQ 领域事件驱动增量更新。

### 非目标

- 不负责在线问答与业务检索流转（归属于【检索流程与召回】模块）；
- 不在存储层直接生成业务答案或解析论文提交；
- 本期不建设在线可视化富文本编辑器，内容更新通过管理 API 或受控同步任务完成。
