## 版本与快照

### 检索工作流版本

`retrievalWorkflowVersion` 是知识检索能力的工作流版本引用，属于统一 `workflowVersion` 类型。它固定策略、步骤、过滤、预算、组合、失败和输出语义。目标候选包括：

| 版本示例 | 定位 |
|----------|------|
| `VECTOR_RAG_V1` | 单路 Query Embedding 与 Elasticsearch 向量召回 |
| `AI_DIRECTORY_V1` | AI 读取受控轻量目录并选择有限文档 |
| `HYBRID_RETRIEVAL_V1` | 按固定预算组合向量召回与受控 AI 选文 |

上表是已确认的目标命名与语义；只有实现、验收并进入版本目录后，它们才成为运行事实。

### 相关版本

| 标识 | 说明 |
|------|------|
| `retrievalWorkflowVersion` | 检索步骤和业务输出语义 |
| `ragIndexVersion` | 向量工作流使用的物理知识索引快照 |
| `manifestVersion` | AI 选文看到的轻量目录结构与成员快照 |
| `sourceVersion` | 受控 Markdown 文件集合的内容快照 |
| `promptVersion` | AI 目录选择器使用的不可变 Prompt |
| `modelExecutionConfigVersion` | Embedding 或目录选择步骤的精确模型与参数绑定 |

不是所有工作流都使用全部标识。纯向量检索不需要选择 Prompt，纯目录选文可以不使用向量索引；不适用时明确为空，不能借用另一个版本字段填充。

### 不可变规则

已发布并被运行引用的检索工作流、索引、目录、Prompt 和模型执行配置不得原地修改。默认指针切换只影响新运行；在途与历史运行继续使用自身快照。

调用方必须保存 `retrievalRunId` 和实际版本引用。检索服务必须能通过运行标识解释当时执行的策略和来源，不得根据当前生产配置反推历史运行。
