## 资料适用性

知识命中不代表资料可以用于当前问题。服务在相关度排序之后执行来源层级和适用范围校验。

### 来源层级

| 层级 | 资料类型 | 使用规则 |
|------|----------|----------|
| L1 | 当前赛事、年份、题号完全匹配的官方评分细则或讲评 | 可以支持题目专属得分点和方法判断 |
| L2 | 同赛事官方通用规范、提交要求和评审说明 | 可以支持格式、完整性和通用评审要求 |
| L3 | 受控整理的数学建模评审方法和论文板块规范 | 可以支持假设、建模、求解、检验和写作建议 |
| L4 | 与当前题型或模型族匹配的方法资料 | 可以支持具体建模、求解和验证动作 |
| L5 | 案例、经验和社区资料 | 只能作为辅助启发，不能单独支持高影响正确性判断 |

### 题目专属资料

只有赛事编码、年份、题号和必要语言全部匹配时，L1 资料才可以进入结果。其他题目的评分细则、参考答案或讲评即使语义相似，也必须排除，不能降级成通用规则使用。

缺少完整适用元数据的题目专属资料按不适用处理。系统宁可少返回，也不能因为标题或模型名相似就把另一道题的答案当作当前建议依据。

### 多来源支撑

高优先级建议优先使用 L1 至 L4。L5 可以补充操作经验，但必须同时存在更高层级来源。多个来源矛盾时优先使用精确匹配的官方资料，并把冲突事实返回调用方，不由检索模型擅自调和。

### 内容要求

进入正式索引的知识文档需要稳定来源标识、标题、类型、权威层级、适用赛事、年份、题号、题型或模型标签和内容版本。现有知识库缺失的元数据必须在实施阶段补齐或保守分类，不能根据文件路径猜测官方级别。
