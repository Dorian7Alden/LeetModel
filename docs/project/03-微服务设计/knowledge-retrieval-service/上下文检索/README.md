## 上下文检索

上下文检索接收业务服务提供的最小查询和过滤条件，在锁定的知识与检索版本中返回来源化片段。它不生成最终业务答案。

### 范围

- 支持向量 RAG、受控 AI 选文及明确发布的组合工作流。
- 返回可被业务结果引用的稳定来源信息。
- 对题目专属资料执行严格适用性校验。
- 检索不足时返回明确空结果或失败，不补造知识。

### 非目标

- 不允许调用方提交任意文件路径。
- 不让模型自行遍历文件系统或访问开放互联网。
- 不读取完整论文或替调用方生成建议。
