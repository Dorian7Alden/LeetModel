## 检索流程与召回

> 功能定位：负责接收上游业务服务的结构化检索请求，在不可变版本约束下执行 Dense 向量检索、受控 AI 目录与标签选文、Dense+BM25 混合检索，提供两级缓存、重排融合、权威校验与防注入上下文裁剪。

### 目标与范围

- 对外发布不可变的检索工作流版本（`AI_DIRECTORY_V1`、`VECTOR_RAG_V1`、`HYBRID_RETRIEVAL_V1`、`SUGGESTION_DEEP_RETRIEVAL_V1`）；
- 落地“目录与标签 AI 智能选拔（`AI_DIRECTORY_V1`）”工作流，针对开放性探索任务以轻量 Flash 模型实现代表性去重与原子文档整篇装配；
- 构筑低价大模型的服务端 4 道确定性安全防线（白名单校验、数量硬截断、防御性解析、优雅降级）；
- 实现高效混合检索（Dense 向量 + BM25 标题加权倒排），基于 RRF 融合与条件式 Cross-Encoder 精排；
- 建立 Redis 任务语义缓存与精确结果缓存，结合元数据前置过滤减枝，降低模型开销与检索延迟；
- 严格执行 L1 至 L5 资料权威层级校验与题目专属规则过滤，组装带防注入边界的 `KnowledgeCitationDTO` 上下文。

### 非目标

- 不生成客服回答、论文评分或修改建议报告正文（由上游业务大模型完成）；
- 不允许调用方提交任意磁盘绝对路径或执行开放式互联网抓取；
- 不读取业务数据库中的用户论文正文或个人敏感隐私。
