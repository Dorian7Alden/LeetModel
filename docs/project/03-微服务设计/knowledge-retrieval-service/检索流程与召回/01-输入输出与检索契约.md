## 输入输出与检索契约

### 内部 HTTP 接口契约

- **请求方式**：`POST /internal/knowledge-retrieval/runs`
- **通信协议**：Spring Cloud OpenFeign（内部微服务通信）
- **网关策略**：禁止公网直连，仅允许注册中心内受信微服务调用。

### 请求对象（KnowledgeRetrievalRequestDTO）

调用方必须显式指定不可变工作流版本，并提供结构化查询与边界约束：

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| `workflowVersion` | String | 是 | 检索工作流版本（如 `VECTOR_RAG_V1`、`SUGGESTION_DEEP_RETRIEVAL_V1`） |
| `scene` | String | 否 | 业务调用场景（如 `PAPER_SUGGESTION_DEEP`、`ASSISTANT_KNOWLEDGE`） |
| `query` | String | 是 | 结构化检索意图（禁止整篇论文全文灌入，限长 500 字符） |
| `category` | String | 否 | 知识分类目录前置过滤（如 `题型方法/优化模型`） |
| `requiredIndexVersion` | String | 否 | 锁定查询的物理 ES 索引版本号（未填时默认使用稳定读别名） |
| `topK` | Integer | 否 | 目标返回片段上限（默认 4，最大 16） |
| `tokenBudget` | Integer | 否 | 结果 Token 硬性总预算（默认 2500） |

### 响应对象（KnowledgeRetrievalResultDTO）

响应必须返回确定性运行标识与来源切片：

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `retrievalRunId` | String | 检索唯一运行 ID（UUID，供调用方审计与持久化依据链） |
| `workflowVersion` | String | 实际执行的工作流版本号 |
| `branch` | String | 实际执行分支（如 `VECTOR`、`DIRECTORY`、`VECTOR+BM25_RRF`） |
| `indexVersion` | String | 实际命中的物理 ES 索引快照版本 |
| `status` | String | 检索结果状态：`COMPLETED`（正常召回）、`NO_CONTEXT`（无满足条件内容） |
| `citations` | List | 来源切片列表（`KnowledgeCitationDTO`） |

### 来源切片契约（KnowledgeCitationDTO）

每个切片提供用于下游依据链绑定的元数据：
- `citationId`：全局稳定引用标识（如 `KC-7a8f9b0c`）；
- `documentId` / `chunkId`：所属文档与具体分块标识；
- `title` / `sourcePath`：文档标题与受控相对路径；
- `authorityLevel`：资料权威等级（`L1` 至 `L5`）；
- `relevanceScore`：融合相关度分数（仅用于排序，不代表事实正确性）；
- `content`：清洗截断后的只读知识正文。

### 空结果（NO_CONTEXT）语义

当所有召回切片均低于相关度阈值或被适用性规则过滤时，服务返回 `status = "NO_CONTEXT"` 且 `citations = []`。
严禁虚构伪造事实。下游业务根据自身策略决定：客服允许优雅降级为无 RAG 回答，而高风险的论文改错建议则触发业务阻断。
