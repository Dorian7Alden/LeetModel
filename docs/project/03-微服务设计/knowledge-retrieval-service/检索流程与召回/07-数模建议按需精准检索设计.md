## 数模建议按需精准检索设计

> 本文档规范针对 AI 论文建议 V3（`GROUNDED_SUGGESTION_V3`）子任务的按需精准知识检索工作流（`SUGGESTION_DEEP_RETRIEVAL_V1`）与场景协议。

### 设计背景与痛点解决

历史版本仅支持单次全篇粗粒度检索（如仅用题名加 8 条缺陷简述拼接进行单一向量查询），导致召回内容多为宽泛的评审套话，无法针对具体小题提供深入的算法模型与统计检验方法。

在建议 V3 的动态子任务编排下，各个子任务根据其负责的题型、缺陷与升华需求，分别发起**按需精准检索**：
- 结构规范审查子任务：定向检索官方格式、摘要要素与符号说明表规范；
- 优化类小题子任务：定向检索松弛化技巧、求解器收敛判据与 Pareto 前沿方法；
- 预测类小题子任务：定向检索时间序列平稳性检验、残差自相关检验与基准模型对比；
- 检验与敏感性专项子任务：定向检索扰动步长设计、敏感性指标度量与正交试验方法。

### 工作流与场景契约

- **工作流版本**：`SUGGESTION_DEEP_RETRIEVAL_V1`
- **适用场景代码**：`scene: "PAPER_SUGGESTION_DEEP"`
- **检索技术方案**：向量 + BM25 倒数秩融合（RRF）
  为了保证数学建模专有名词（如“Ljung-Box”、“Durbin-Watson”、“Pareto”、“分枝定界”、“TOPSIS”、“信息熵”）能被精准命中，同时保证语义相关文档被召回，工作流采用混合检索策略：
  1. 稠密向量分支（Vector）：Top-K 候选召回，捕获复杂数学表述与语义意图；
  2. 稀疏 BM25 分支：针对专用术语和缩写进行关键词高权加权（`title^3, content^1`）；
  3. RRF 融合重排：公式 $RRF\_Score = \sum \frac{1}{60 + rank_i}$，输出综合排序最高的高质量知识切片。

### 题型与板块定向映射表

调用方构造 `query` 时，根据子任务类型携带题型引导前缀，确保检索能精准锁定目标板块：

| 子任务类型 | 建议题型类别 | 目标知识库主要路径 | 核心召回知识资产 |
|:---|:---|:---|:---|
| **全篇结构与学术规范审查** | `STRUCTURAL` | `数学建模/论文评审/评审板块/`、`官方规范与讲评/` | 摘要四要素、符号说明表国际量纲规范、三线表排版 |
| **运筹优化建模推演** | `OPTIMIZATION` | `数学建模/模型方法/优化模型与算法分类.md`、`常用模型速查-优化类.md` | 整数规划线性化、松弛技巧、分支定界、Pareto 多目标 |
| **预测与统计推演** | `PREDICTION` | `数学建模/模型方法/常用模型速查-预测类.md` | ARIMA、残差自相关 Ljung-Box、MAPE/RMSE 基准对比 |
| **综合评价推演** | `EVALUATION` | `数学建模/模型方法/常用模型速查-评价类.md` | AHP 一致性检验、TOPSIS 距离度量、熵权客观赋权 |
| **机理与微分推演** | `MECHANISM` | `数学建模/模型方法/常用模型速查-统计与机理类.md` | 守恒定律建立、ODE 动力学系统稳定性、相轨迹 |
| **检验与敏感性专项** | `VALIDATION_SENSITIVITY` | `数学建模/论文评审/评审板块/敏感性分析评审要点.md` | 参数正负扰动步长、单参数与多参数响应曲面、稳健性判据 |

### 权威层级与防伪造约束

检索服务严格保证来源安全与不可变性：
1. **L3/L4/L5 权威层级**：
   - `L3`：官方讲评与评审板块核心规范；
   - `L4`：题型与模型方法速查；
   - `L5`：其他通用辅助资料；
   - 建议 V3 硬性要求：**P0 与 P1 级别的改错建议不能仅由 L5 辅助资料支撑**，必须具备 L3 或 L4 级权威知识支撑。
2. **不可变快照**：每次检索分配唯一 `retrievalRunId`，返回带有 `contentHash` 与 `citationId` 的不可变快照，供建议报告持久化归档。
