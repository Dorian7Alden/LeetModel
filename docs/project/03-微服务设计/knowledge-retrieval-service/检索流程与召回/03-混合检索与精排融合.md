## 混合检索与精排融合

### 为什么必须采用混合检索

在数学建模知识体系中，纯向量检索与纯关键词检索各自存在明显短板：
- **纯向量局限**：对长尾专业算法、缩写和专有名词（如“Ljung-Box 检验”、“Durbin-Watson 统计量”、“TOPSIS 欧氏距离”、“分支定界”）存在语义平滑，容易召回无关但字面宏大的泛化段落；
- **纯 BM25 局限**：对口语化表述、同义词（如“怎么求最优规划”匹配“单纯形法”）无法泛化。

混合检索采用**双轨并发召回**与**融合打分**策略，兼顾查全率与查准率。

### BM25 权重倾斜策略

在原子 Markdown 知识库中，文档标题（`title`）的信息纯度远高于正文。BM25 多字段匹配规则采用非对称加权：
```json
{
  "multi_match": {
    "query": "${query}",
    "fields": ["title^3", "content^1"]
  }
}
```
当用户提问命中算法标题时，BM25 评分呈数量级提升，保证核心原子文档直接脱颖而出。

### RRF 倒数排名融合算法（Reciprocal Rank Fusion）

向量得分（余弦距离）与 BM25 得分（TF-IDF 衍生分）量纲不一致，直接加权求和极易失真。系统采用无参数、高稳健性的 RRF 融合公式：

$$RRF\_Score(d) = \sum_{m \in \{Dense, BM25\}} \frac{1}{k + rank_m(d)}$$

- 其中常数 $k = 60$（工业界成熟基准）；
- $rank_m(d)$ 为切片 $d$ 在分支 $m$ 中的名次（从 1 开始）；
- 若某切片同时在向量与 BM25 中排名前列，其 $RRF\_Score$ 将显著拉开与其他单路候选的差距。

### 条件式 Cross-Encoder 重排演进（Target Design）

为进一步提高关键任务（如 P0 级修改建议）的准确率，设计条件式两阶段精排扩展：
1. **初筛阶段**：Dense + BM25 召回前 20 条切片候选；
2. **触发判断**：若 Top 1 分数显著高于第二名（置信度高），直接跳过重排；
3. **精排阶段**：若候选分值胶着，调用轻量级 Cross-Encoder（如 `bge-reranker-v2-m3`），对 `[Query, Chunk]` 交叉注意力计算打分，收敛输出最终 Top 3~5。
