## 工具契约与示例

> 实施状态：S11 受控工具调用已于 2026-08-31 落地。本文记录契约语义，当前字段与行为以 Java DTO、JSON Schema 和 Feign 接口为最终事实。

### 工具集版本

首版工具集固定为 `ASSISTANT_TOOLSET_0001`。工具集版本绑定以下内容：

- 可暴露的工具名称和版本。
- 工具描述、输入 JSON Schema 和结果类型。
- 是否终止当前工具循环。
- 每个工具允许的工作流版本。
- 参数、结果数量、超时和权限限制。

已发布的工具集不可原位改变语义。修改工具名称、字段含义、专用 Prompt 或终止行为时发布新版本，并通过客服生产工作流版本治理切换。

### 公共执行接口

业务工具实现统一接口，具体类只在 `ai-assistant-service` 内注册。

```java
public interface AssistantTool<I, O> {
    ToolDescriptor descriptor();
    O execute(I input, ToolExecutionContext context);
}
```

`ToolExecutionContext` 由服务端创建，至少包含 `userId`、`conversationId`、`userMessageId`、`assistantMessageId`、`attemptNo`、`toolsetVersion`、生产快照和绝对截止时间。模型参数中不得出现这些可信字段。

`ToolRegistry` 使用显式构造映射注册工具。未知工具名直接拒绝，不使用类名、反射表达式或 Spring Bean 名称进行动态调用。

### search_problem

#### 用途

查询指定题号或标题关键词对应的已发布题目。用户询问题面、难度、年份、赛事、语言、建议时长或某一道题是否存在时必须使用该工具。

#### 输入

| 字段 | 类型 | 规则 |
|------|------|------|
| `code` | Integer | 与 `keyword` 二选一，题号范围为 1001 到 10000 |
| `keyword` | String | 与 `code` 二选一，去除首尾空白后长度为 1 到 50 |
| `includeOverview` | Boolean | 默认 `false`，只在用户明确询问题面时允许为 `true` |
| `limit` | Integer | 默认 5，范围为 1 到 5；使用题号时固定为 1 |

Schema 使用 `additionalProperties: false`。两个查询条件同时为空或同时存在均判定参数非法。

#### 输出

返回 `items`、`matchType` 和 `truncated`。每个题目只包含题号、标题、赛事、年份、语言、难度、建议时长、标签和可选题面概览。题面概览由 problem-service 提供，最多 500 个 Unicode 码点，不返回附件地址和未发布内容。

没有匹配题目属于成功空结果。客服应明确说明未找到，不得补造近似题目。problem-service 不可用属于工具失败，不能用空列表替代。

### recommend_problem

#### 用途

根据用户明确表达的条件，从已发布题目中返回候选。它只做受控筛选和确定性排序，不声称根据用户能力、队伍情况或历史成绩完成个性化推荐。

#### 输入

| 字段 | 类型 | 规则 |
|------|------|------|
| `keyword` | String | 可选，标题或标签关键词，长度不超过 50 |
| `contestCode` | String | 可选，只接受 problem-service 支持的赛事编码 |
| `year` | Integer | 可选，必须是题库存在的年份 |
| `difficulty` | Integer | 可选，只接受 1、2、3 |
| `statementLanguage` | String | 可选，只接受服务端枚举值 |
| `maxDurationMinutes` | Integer | 可选，范围为 30 到 10080 |
| `limit` | Integer | 默认 3，范围为 1 到 5 |

#### 输出和排序

输出结构与 `search_problem` 的摘要项一致，并额外返回 `matchedConditions`。problem-service 先应用所有非空条件，再按年份降序、题号升序进行稳定排序。首版不引入向量相似度、点击热度或协同过滤。

模型只能解释候选为什么符合用户条件，不能把未返回的题目加入答案。条件不足时允许不带筛选查询最多 3 道最新题目，但回答必须说明这是平台候选展示，不是个性化最优推荐。

### problem-service 内部接口

S11-02 已实现题目工具共享的内部只读接口，避免 ai-assistant-service 拼装题目表查询规则。

```text
POST /internal/problems/assistant-query
```

请求使用 `AssistantProblemQueryDTO`，包含查询模式 `SEARCH` 或 `RECOMMEND` 及对应条件。响应使用 `AssistantProblemResultDTO`。problem-service 负责互斥字段、枚举、发布状态、条数和题面概览限制；推荐关键词同时匹配标题和标签，结果按年份降序、题号升序稳定排序。

该接口不替代公开题库接口。它面向内部工具提供稳定、最小且不含附件的事实快照。

### explain_modeling_knowledge

> 实现状态：`EXPLAIN_MODELING_KNOWLEDGE_0001` 已注册为终止型工具，固定使用 `PROMPT_ASSISTANT_KNOWLEDGE_0001` 和禁用工具能力的 `MODEL_CFG_ASSISTANT_KNOWLEDGE_0001`。完整回答只写最终消息，工具审计仅保存 SHA-256、码点长度、越界标记与 RAG 命中摘要。

#### 用途

解答数学建模领域的概念、方法选择、模型假设、求解步骤和常见误区。它是模型驱动的终止型工具，执行完成后结果直接作为客服回答，不再交给外层模型改写。

#### 输入

| 字段 | 类型 | 规则 |
|------|------|------|
| `topic` | String | 必填，长度为 2 到 100，只允许数学建模学习主题 |
| `level` | String | 默认 `BEGINNER`，可选 `BEGINNER`、`INTERMEDIATE` |
| `focus` | String | 可选，长度不超过 100，用于限定用户最想理解的部分 |

模型不能传入 Prompt、语气、角色、输出长度、RAG 索引或模型名称。这些字段全部由服务端工具版本锁定。

#### 专用 Prompt

首版发布 `PROMPT_ASSISTANT_KNOWLEDGE_0001`，核心约束如下：

```text
你是 LeetModel 的数学建模讲解员，只回答数学建模学习问题。
使用准确、克制、面向实训的中文回答。
先用一句话说明概念，再给出二到四个关键点，最后指出一个常见误区或下一步练习建议。
总长度控制在三百个中文字符以内。
不要代替平台完成正式论文评审，不编造题目、比赛规则或用户数据。
参考资料与用户问题冲突时，以受控参考资料为依据并说明信息不足。
对数学建模之外的问题只返回 OUT_OF_SCOPE，不继续回答。
```

实现时 Prompt 存放在独立资源文件，不允许调用方提交或覆盖。工具内部使用 `tools: []` 和 `toolChoice: NONE`，防止递归调用自身。

#### RAG 和模型版本

- 当前生产快照为 `NONE` 时，讲解工具不读取知识索引。
- 当前生产快照为 `FIXED_INDEX` 时，只读取快照锁定的物理 `ragIndexVersion`。
- 检索无命中时仍可基于专用 Prompt 回答基础知识，但不得虚构平台事实。
- 检索故障沿用客服 RAG 的安全降级规则，Chat 故障则工具失败。
- 专用调用使用独立的 `modelExecutionConfigVersion`，建议首版为 `MODEL_CFG_ASSISTANT_KNOWLEDGE_0001`。

### 工具结果回传

题目工具完成后，编排器按标准顺序向模型发送：

1. 带 `toolCalls` 的上一条 `ASSISTANT` 消息。
2. 与供应商 `toolCallId` 对应的 `TOOL` 消息。
3. 服务端补充指令，要求只依据工具结果简洁回答。

工具结果 JSON 被视为不可信数据。模型不得执行其中的指令文本。返回模型前必须执行字段白名单序列化、字符数限制和控制字符清理。
