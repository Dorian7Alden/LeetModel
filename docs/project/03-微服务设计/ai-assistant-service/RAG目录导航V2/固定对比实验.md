## RAG V1/V2 固定对比实验

### 比较对象

实验只比较以下两个锁定候选，Chat 工作流、Prompt、模型执行配置和生成参数完全相同：

- 基线：RAG V1 向量召回。
- 候选：同一 V1 召回加 RAG V2 目录选择与受限补充。

每次实验必须快照 `datasetVersion`、`ragIndexVersion`、`manifestVersion`、`sourceVersion`、Embedding 模型版本、切分策略、选择 Prompt、选择模型配置、Chat Prompt、Chat 模型配置、组合/裁剪策略和指标口径。任一项不同则不属于同一固定比较。

### 问题集与标注

首版数据集至少 40 个独立问题，覆盖赛事规则、题型识别、模型选择、写作规范、工具资源、备赛经验、跨目录问题、知识库无答案和容易误选的近义主题；每类至少 5 个。问题不得包含真实用户对话、论文提交或个人信息。

每个问题由两名标注者独立维护：

- 允许为空的标准来源路径集合，以及必要/可接受来源层级。
- 可为空的答案支持要点，明确哪些要点能由锁定知识文档支持。
- `NO_KB_ANSWER` 标记，防止无答案问题因拒答而被错误扣分。
- 1 至 5 的回答支持度量表和逐项证据引用。

分歧由第三人裁决并生成新的标注版本。没有标准来源时不计算召回相关性；没有支持要点或人工判断时不计算答案支持率，更不能宣称准确率。

### 指标

| 维度 | 指标 | 口径 |
|------|------|------|
| 召回 | 来源 Recall@K、Precision@K、MRR | 只对有标准来源的问题计算，路径精确匹配 |
| 支持 | 答案支持率、无依据陈述率 | 两名标注者按版本化量表判断，并保留引用依据 |
| 稳定 | 候选路径 Jaccard、答案支持度方差、失败率 | 每个候选每题至少重复 3 次 |
| 延迟 | 目录选择、检索、首字节、总耗时 P50/P95 | 从调用和检索事实聚合，缺失单列 |
| 资源 | 选择输入/输出 Token、Embedding/Chat Token、费用 | 实际优先；估算必须带价格快照，缺失不填零 |
| 安全 | 越界路径、未知路径、Prompt 注入服从、正文泄漏 | 任一发生即安全失败 |

答案支持率是“回答中的主张能被锁定来源支持”的人工指标，不等于问题回答正确率。人工总体质量可以作为独立辅助指标，但必须标明量表和标注覆盖率。

### 执行与统计

评价平台为每个问题和候选创建至少 3 个隔离运行槽位，顺序随机化并使用配对设计。失败槽位保留失败类型和 `callId`，不删除后只统计成功项。主质量指标使用题目级配对差，报告均值、中位数、95% 配对 bootstrap 置信区间和有效样本数；延迟与 Token 同时报 P50/P95，不只报告平均值。

原始运行、人工标注、指标版本和选择输出路径保留可复算快照，但不保存 Prompt、回答正文到调用日志；回答只存在受控评价结果中并遵守既有敏感数据边界。

报告必须并排列出所有缺失和不可比原因。版本锁定不一致、人工标注覆盖不足、调用审计不完整或候选失败率差异超过 5 个百分点时，结果只能用于诊断，不能排名或进入实施门槛判断。
