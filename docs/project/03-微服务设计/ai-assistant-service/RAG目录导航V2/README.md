## RAG 目录导航 V2

RAG V2 是 ai-assistant-service 在向量 RAG V1 之上的候选增强方案：模型只读取受控知识目录的轻量元数据并选择有限文档，服务端校验后加载和裁剪内容，再与 V1 召回结果组合。当前阶段仅完成设计和固定实验方案，不新增运行时代码、配置、数据库或接口。

### 范围

- 设计轻量 manifest、版本、发布失败和路径白名单。
- 设计受限选文、加载、二次裁剪、超时和 V1 降级。
- 设计锁定数据、索引、目录和人工标注的 V1/V2 对比实验。
- 规定只有实验产生可信增益后才允许评估实现。

不建设在线知识管理、独立 RAG 服务、开放 Agent 文件访问、论文评审知识检索或任意路径读取。
