## RAG 目录导航 V2

RAG 目录导航 V2 是当前向量 RAG V1 之上的候选增强方案：模型只读取受控知识目录的轻量元数据并选择有限文档，服务端校验后加载和裁剪内容。原方案面向 ai-assistant-service；现因出现论文建议这一第二消费者，目标实现归属调整为 `knowledge-retrieval-service` 的 `AI_DIRECTORY_V1`，检索算法设计保留，不覆盖客服历史工作流。

S12 已在 knowledge-retrieval-service 完成受控目录选择、路径校验、加载和预算裁剪的实验实现，但尚未完成本目录规定的固定对比实验，因此不进入任何正式建议或客服工作流。

### 范围

- 实现轻量 manifest、版本摘要和路径白名单。
- 实现受限选文、加载、预算裁剪及显式失败。
- 设计锁定数据、索引、目录和人工标注的 V1/V2 对比实验。
- 规定只有实验产生可信增益后才允许生产发布。

不建设在线知识管理、开放 Agent 文件访问、论文评审打分知识检索或任意路径读取。论文建议可通过独立服务调用该受控检索版本。
