## 生产工作流版本治理

本目录记录 AI 客服生产工作流的版本所有权、安全激活、运行快照、审计和管理端操作。S10 只在 `ai-assistant-service` 落地第一个真实闭环，验证稳定共性后再决定其他 AI 功能是否复用；不建立中央版本数据库。
