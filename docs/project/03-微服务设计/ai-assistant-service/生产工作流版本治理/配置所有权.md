## 生产版本配置所有权

### 任务卡

目标：管理员能够查看 AI 客服由哪个不可变工作流配置提供生产服务，所有变更由业务 owner 保存和审计，评价服务与管理服务不能越权修改生产数据。

入口：`admin-service` 的管理员专用代理调用 `ai-assistant-service` 内部生产配置接口；正式客服发送消息时只从本服务读取当前生效项。

主流程：业务服务发布版本目录和默认配置，管理员发起带原因的变更，业务服务完成预检查和条件更新，新客服回复任务锁定新配置，已经开始的任务继续使用原快照。

完成标准：所有者、版本字段、默认值、操作者/确认方式、审计数据和跨服务调用方向唯一明确；工作流切换不改变 new-api 渠道；evaluation 没有生产写入口。

修改范围：AI 客服生产配置设计及其文档索引。

非目标：本任务不实现接口、数据库、页面、自动选优、跨 AI 功能公共库或 REST API 版本化。

### 选择首个功能

首个落地点是 `ASSISTANT`。它已有正式客服入口、业务 owner、隔离实验和两个可发现候选：`ASSISTANT_NO_RAG_V1` 与 `ASSISTANT_RAG_V1`。无 RAG 版本可以作为安全默认值；RAG 版本只有绑定已构建的物理 `ragIndexVersion` 后才具备生产激活资格。旧正式标识 `ASSISTANT_CHAT_V1` 仅用于解释迁移前调用，不继续作为可激活版本，因为它把是否读取别名 RAG 留给运行时配置，无法形成完整快照。

### 参与者与职责

| 参与者 | 拥有 | 不拥有 |
|--------|------|--------|
| `ai-assistant-service` | 工作流目录、Prompt 引用、生产配置、当前指针、变更请求、历史审计和任务快照 | new-api 渠道、供应商密钥、评价排名 |
| `admin-service` | 管理员角色校验、当前操作者注入、命令代理 | 版本表、当前生产指针、切换事务 |
| `ai-evaluation-service` | 隔离实验、原始指标、权重和版本选择指数 | 生产配置写权限、自动激活权限 |
| `ai-gateway-service` | `modelExecutionConfigVersion` 定义、内部调度和调用事实 | 业务工作流默认值、new-api 渠道选择 |
| new-api | 渠道、上游模型映射、供应商凭据、额度和渠道重试 | LeetModel 工作流、Prompt、生产审批和评价结果 |

调用方向固定为 `管理页 → admin-service → ai-assistant-service`。admin 不能直接连接 `lm_ai_assistant`，evaluation 只能把候选实验事实交给人判断，不能调用激活接口。工作流激活仍通过同一个 `modelExecutionConfigVersion` 请求 AI 网关；它不切换或覆盖 new-api 中的渠道配置。

### 不可变定义与生效配置

工作流目录中的发布项至少固定以下字段：

- `workflowVersion`、展示名、状态、输入/输出 schema 和兼容说明。
- `promptVersion` 与 `modelExecutionConfigVersion`。
- RAG 模式 `NONE` 或 `FIXED_INDEX`，以及影响范围说明。

工具版发布项必须绑定已确认的不可变 `toolsetVersion`。S11 已发布两个固定绑定 `ASSISTANT_TOOLSET_0001` 的工具版工作流；旧无工具工作流使用空值表达不适用。消息创建时持久化该快照，不能从当前 Spring Bean 或运行时注册表反推历史值。

生产配置是对发布项的一次不可变绑定，额外锁定可空的 `ragIndexVersion`，并获得唯一 `productionConfigVersion`。当前指针只保存活动配置和单调递增的 `revision`；切换只移动指针，不修改旧配置。一次运行必须同时保存工作流、Prompt、模型执行配置、生产配置及适用时的 RAG 索引版本。

配置、当前指针、变更请求和审计均归 `lm_ai_assistant`。不在 admin、evaluation 或中央数据库复制这些表。其他 AI 功能在出现真实切换需求前继续使用自己的当前实现，不提前抽取公共持久化模块。

### 默认版本与迁移

首次迁移创建 `ASSISTANT_NO_RAG_V1` 和 `ASSISTANT_RAG_V1` 两个发布项，默认生产配置固定为前者、Prompt `PROMPT_ASSISTANT_CHAT_0001`、模型配置 `MODEL_CFG_ASSISTANT_TEXT_0001`，RAG 索引为空。该默认值与当前 `ASSISTANT_RAG_ENABLED=false` 的安全行为一致，部署后不依赖未构建索引。

迁移前消息没有完整生产快照。只对其补记明确的 bootstrap 配置用于历史展示；旧失败回复再次执行时沿用补记的无 RAG 快照，不根据切换时的当前值猜测历史配置。迁移不修改已完成回答正文、模型名或 `aiCallId`。

### 操作者、确认与审计

当前项目由单人维护，首版不伪造第二审批人。授权由三层证据组成：管理员角色、服务端生成且绑定操作者/目标/revision/原因的短时变更请求、页面上的第二次确认。变更原因必填，不能由 admin 代填固定文本。

每次实际生效变更记录动作类型、来源和目标配置、变更前后 revision、操作者、原因、变更请求及时间。并发或预检查失败没有生产状态变化，必须返回明确结果，但不得写成成功审计。审计和被引用配置不删除、不覆盖。

### 版本边界

- 工作流步骤、RAG 分支或输出语义变化才创建新的 `workflowVersion`。
- Prompt 内容变化创建新的 `promptVersion`，不改写工作流标识。
- 物理模型、参数或能力绑定变化由 AI 网关创建新的 `modelExecutionConfigVersion`。
- 知识、切分、Embedding 或索引 schema 变化创建新的 `ragIndexVersion`。
- 工具名称、输入 Schema、单工具版本、终止行为或执行限制变化创建新的 `toolsetVersion`。
- REST 路径兼容问题使用独立 `apiVersion` 评估，绝不以 `/v1`、`/v2` 代替上述字段。

页面上的“实验候选”只表示可在评价平台运行；“生产生效”只表示当前指针引用。候选不会因选择指数较高而自动获得生产状态。
