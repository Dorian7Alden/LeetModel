## 前端工具结果渲染协议

> 实施状态：已落地。定义 AI 客服助手消息中附带的工具调用上下文（`toolContextJson`）在前端的解析规则与卡片渲染协议。

### 背景与目标

当 AI 客服调用只读题目检索工具（如 `search_problem`、`recommend_problems`）时，后端将题目事实以受控快照写入 `assistant_message.tool_context_json`。
前端需要将结构化题目事实解析为富有交互感的富文本卡片，向用户清晰展示题号、标题、年份、难度及标签，并支持一键直达对应题面详情页。

### `toolContextJson` 数据契约

#### 1. 标准受控工具格式（`ASSISTANT_TOOLS_*` 工作流）

```json
[
  {
    "name": "search_problem",
    "version": "1.0.0",
    "result": {
      "items": [
        {
          "code": 1001,
          "title": "电力系统短期负荷预测模型",
          "contestCode": "MCM",
          "contestName": "美国大学生数学建模竞赛",
          "year": 2024,
          "statementLanguage": "ZH",
          "difficulty": 2,
          "durationMinutes": 240,
          "tagNames": ["时间序列", "机器学习", "回归分析"]
        }
      ],
      "matchType": "EXACT_CODE",
      "truncated": false,
      "matchedConditions": ["题号: 1001"]
    }
  }
]
```

#### 2. 关键词预取兼容格式（旧工作流）

```json
[
  {
    "code": 1001,
    "title": "电力系统短期负荷预测模型",
    "contestCode": "MCM",

    "tagNames": ["时间序列"]
  }

```

### 前端归一化 Schema

前端统一提取为 `ProblemCard` 数组：

```typescript
interface ProblemCard {
  code: number;            // 题号，如 1001
  title: string;           // 题目标题
  contestName?: string;    // 所属赛事名称
  year?: number;           // 题目年份
  difficulty?: number;     // 难度：1=简单, 2=中等, 3=困难
  tagNames: string[];      // 标签数组（最多展示前2个）
}
```

### 视觉与交互规范

1. **卡片布局**：置于回复气泡正文下方，使用边框与微阴影与气泡自然区隔，最大宽度适配气泡宽度。
2. **题号徽章**：采用 `P1001` 或 `#1001` 徽章前缀，突出数学建模题库特征。
3. **难度映射**：
   - 难度 1（简单）：绿色 `success` 浅色 Tag
   - 难度 2（中等）：黄色/橙色 `warning` 浅色 Tag
   - 难度 3（困难）：红色 `danger` 浅色 Tag
4. **路由直达**：点击卡片通过 Vue Router 跳转至 `/problem/${card.code}`，题目服务公开详情接口同时支持根据主键 ID 与业务题号 Code 寻址，保障直达无阻断。
