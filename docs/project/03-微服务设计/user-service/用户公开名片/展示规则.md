## 用户公开名片展示规则

### 名片内容

简约个人名片展示头像和昵称。用户处于队伍场景时，可以附加展示其在当前队伍中的队长或成员身份，以及建模、编程和论文职责。

头像和昵称来自 user-service 的公开摘要。队伍身份和专业职责来自 team-service 的当前队伍结果。前端只组合展示，不把团队职责写回 user-service。

没有头像时使用昵称首字作为占位。没有昵称时使用不暴露用户名和邮箱的通用用户称呼。任一公开资料不可用时保留名片结构并明确显示资料暂不可用。

### 点击暗示

队伍广场卡片和队伍详情中的真实成员头像都可以点击。空成员位置和招募占位图标不可点击，也不显示点击反馈。

鼠标悬浮可点击头像时，头像框高亮并显示手型光标。键盘聚焦时提供同等明显的焦点框，按回车键或空格键可以打开名片。高亮不能仅依赖颜色变化，还应有边框或外圈变化。

点击头像只打开名片，不能同时触发队伍卡片进入详情。头像交互必须阻止点击事件冒泡。

### 弹窗动画

打开名片时，弹窗从屏幕顶部之外向下移动到可视位置，同时渐显。关闭名片时执行相反方向的运动，从当前位置向上移动并从屏幕顶部消失，同时渐隐。

遮罩与名片动画同步。用户点击关闭按钮、点击遮罩或按退出键时使用相同关闭动画，动画完成后再销毁弹窗内容。

用户系统启用减少动态效果时，保留淡入淡出并取消大幅位移，避免动画造成不适。重复点击同一头像不能叠加多个名片弹窗。

### 数据与失败边界

队伍查询已经返回公开摘要时直接复用，不因每次点击头像再逐个调用 user-service。只有名片未来需要列表未携带的新公开字段时，才增加按用户标识查询的公开名片契约。

批量公开摘要聚合失败时，调用方明确显示用户资料暂不可用，不使用空昵称或默认头像伪装一次成功查询。
