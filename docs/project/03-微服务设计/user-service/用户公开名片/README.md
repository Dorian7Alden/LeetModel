## 用户公开名片

### 功能目标

允许登录用户在队伍等公开协作场景点击成员头像，通过轻量弹窗识别对方，同时限制公开资料范围。

### 范围

- 用户头像和昵称的公开展示。
- 队伍场景中的头像点击暗示、名片弹窗和进出动画。
- user-service 公开摘要与 team-service 队伍职责信息的组合展示。

### 非目标

- 不展示用户名、邮箱、账号状态、角色权限或其他敏感账号资料。
- 不提供私信、关注、好友、举报或跳转到完整主页的能力。
- 不由 user-service 保存用户在队伍中的职责和成员身份。
