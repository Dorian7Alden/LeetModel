## 数据归属

PDF 解析归属 ai-review-service，解析产物也由该服务拥有。

原始 PDF 与提交事实属于 submission-service。ai-review-service 保存提交标识、文件摘要、必要对象路由引用、解析任务和解析产物，不把原始 PDF 复制为自己的主数据。

评审任务保存具体解析产物引用。ai-suggestion-service 可以通过 ai-review-service 的内部只读契约取得所选评审允许使用的解析上下文，但不直接读取 lm_review，也不在自己的数据库复制完整解析产物。

解析产物包含用户论文内容，访问必须继承论文所属队伍权限和内部服务身份。应用日志、AI 网关调用审计、管理列表和知识索引不得记录或索引论文正文。

具体存储方式以 Flyway SQL 和实现代码为准。
