## 评审任务与生命周期

本目录维护所有评审版本共享的任务接入、任务控制表驱动、有界 Worker 调度、租约控制、生命周期状态机与数据模型。

当前 `BASIC_REVIEW_V1`（基础评审）与 `EVIDENCE_REVIEW_V2`（证据化评审）均已实现，各自作为独立功能目录维护。所有已发布版本均不可变，AI 功能步骤、依赖或输出语义变化时发布新版本，不覆盖历史实现。
