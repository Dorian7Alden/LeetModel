## 数据边界

ai-review-service 拥有评审版本定义、公共任务状态、任务执行日志、最终评分以及版本专属结果和中间产物。

submission-service 拥有提交记录和原始 PDF，problem-service 拥有题目，ai-gateway-service 拥有模型调用与资源记录。

稳定性实验任务、重复运行记录、方差和标准差属于 ai-evaluation-service。ai-review-service 只提供隔离实验结果和必要关联标识，不复制稳定性统计结果。

公共控制信息与版本业务数据必须分离：版本总表、公共任务表和公共任务日志表支撑统一创建与查询；每个评审版本使用自己的结果表及必要的中间表。V1 的结果不能与 V2、V3 结果混在同一张业务结果表中。

具体字段、索引和约束最终以 Flyway SQL 与代码为准。
