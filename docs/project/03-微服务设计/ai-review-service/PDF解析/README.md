## PDF 解析

PDF 解析将原始论文转换为带物理页码、章节、内容块和质量信息的结构化产物。

当前 `BASIC_REVIEW_V1` 不使用解析产物，仍按历史语义读取 PDF 页面图像。已发布的 `EVIDENCE_REVIEW_V2` 必须先完成 `PAPER_PARSE_V1`，再进入题目覆盖、证据映射和评分。解析步骤、依赖或产物语义发生变化时发布新解析工作流版本，绝不覆盖历史产物。

解析归 ai-review-service，解析产物可以被所选评审以及该评审下游的 AI 建议读取。对没有解析产物的历史 V1 论文，建议服务可以请求 ai-review-service 按锁定版本补齐解析；建议服务不自行解析或保存第二份解析事实。

S12 的 `PAPER_DOCUMENT_V1` 使用 PDFBox 按从 1 开始的物理页提取文本，生成稳定 `P{page}-B1` 内容块、基础章节、空白/扫描页风险和截断信息。当前版本不隐式 OCR、不伪造公式语义或坐标；完全没有可提取文本时明确失败。产物及文件 SHA-256 保存到新增的 `paper_parse_artifact`，同一不可变提交与解析版本可复用成功产物。
