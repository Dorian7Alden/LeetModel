## 执行流程

1. 根据公共任务取得已锁定的提交摘要和 Prompt 快照。
2. 下载提交 PDF，校验文件可打开且页数处于 V1 支持范围。
3. 按原始页序渲染为文字可辨认的 JPEG，并校验单图和请求总体积。
4. 组装一个用户消息：先放评审提示词，再按页序放置所有页面图像。
5. 通过 common-ai 调用 ai-gateway-service，由网关使用 `deepseek-v4-flash-vision-exp` 发起一次请求。
6. 将模型回答解析为 V1 JSON，校验必需字段并提取统一最终 `score`。
7. 保存 V1 独立结果，完成公共任务；任一步骤失败则追加日志并将任务置为失败。

“一次调用”指一个任务只产生一次模型推理请求。若页数或渲染体积超过供应商限制，V1 明确失败，不隐式升级为分段工作流。
