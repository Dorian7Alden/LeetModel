## 版本与解析依赖

### 版本关系

`EVIDENCE_REVIEW_V2` 是新的评审 `workflowVersion`，不会修改或覆盖 `BASIC_REVIEW_V1`。它声明兼容的解析产物 schema，并在任务创建时锁定一个 `paperParsingWorkflowVersion`。

解析工作流也是统一工作流版本类型，但在评审任务和接口中使用带领域前缀的字段名，避免与评审版本混淆。解析策略、步骤、依赖或产物语义变化时发布新解析版本；只替换某一步模型时更新该步骤的 `modelExecutionConfigVersion`。

### 产物复用

相同提交、文件摘要、解析工作流版本和产物 schema 可以复用同一不可变解析产物。以下任一项不同都必须产生新解析任务或新产物：

- 原始文件摘要不同。
- `paperParsingWorkflowVersion` 不同。
- 解析输出 schema 不兼容。
- 已有产物失败、损坏或被明确判定不可用于所选评审版本。

评审任务保存具体 `parseArtifactId`，不能只保存“当前解析版本”后在运行时重新查询默认产物。

### V2 解析质量门

`EVIDENCE_REVIEW_V2` 对 `PAPER_DOCUMENT_V1` 使用以下确定性门槛：

| 检查 | 通过条件 | 失败含义 |
|------|----------|----------|
| 文件一致性 | 产物的提交标识和原文件摘要与评审快照完全一致 | 源数据冲突，不得评审 |
| 页码完整性 | 页记录数等于 PDF 物理页数，从 1 开始连续，无重复与缺号 | 无法可靠引用页码 |
| 逐页可用表示 | 每页至少保留可校验的页面图像引用；有文字的页面同时有文本、OCR 或多模态内容块 | 存在完全无法检查的页面 |
| 可读页比例 | 非空页中至少 90% 页面有可用文本或置信度不低于 `0.60` 的 OCR / 多模态块，且不存在连续 2 页不可读 | 论文覆盖不足，评分不可信 |
| 最小内容 | 除空白页外至少存在 2 个可用页面且总可用文本不少于 500 个 Unicode 字符 | 文件可能不是完整论文或提取严重失败 |

上述门槛通过后，公式、表格、图形或阅读顺序的局部低置信可以作为质量风险继续，但对应判断必须输出 `UNVERIFIABLE` 或限制说明，不得把低置信内容当作确定事实。任何门槛或置信度语义的变化都必须发布新评审工作流版本。

### 新旧版本

V1 历史任务继续使用原页面图像流程和 V1 结果契约。实现 V2 后，新任务默认切换必须经过生产版本治理和真实验收；切换只影响此后创建的任务。

停用 V1 只禁止创建新正式任务或实验，不删除历史结果。历史论文需要新式评分说明时，创建新的 V2 评审任务和必要解析产物，不能升级或重算覆盖原 V1 任务。
