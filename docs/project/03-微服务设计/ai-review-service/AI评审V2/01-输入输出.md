## 输入输出

### 输入

V2 评审任务必须锁定：

- 提交标识、队伍标识、题目标识和原始文件摘要。
- problem-service 提供的完整题面、题目元数据和可用附件说明。
- 已完成或部分完成且达到 V2 质量门槛的 PDF 解析产物。
- `paperParsingWorkflowVersion`、解析产物标识和产物 schema。
- `EVIDENCE_REVIEW_V2` 工作流、各步骤 Prompt 和模型执行配置。
- V2 内置的平台训练评分规则快照。

V2 不把用户可编辑 Prompt 当作输入，也不根据当前默认配置替换任务已经锁定的版本。

### 统一结果

V2 继续产生所有评审版本共享的 `[0,100]` `score`。排行榜只消费统一总分，不依赖 V2 专属结构。

### V2 专属结果

V2 结果至少包含：

- 总分和整体评分说明。
- 本次使用的评分规则名称、规则说明和各项满分。
- 题目要求清单，以及每项要求的完成、部分完成、缺失或无法判断状态。
- 各评分项的得分、得分理由、扣分理由和关联发现。
- 结构化优点与问题发现。
- 可被发现和题目覆盖项复用的论文证据集合。
- 对解析质量和证据充分性的限制说明。

评审发现说明“论文有什么表现以及为何影响评分”，不展开成完整修改教程。后续 `GROUNDED_SUGGESTION_V2` 根据发现编号检索资料并生成行动。

### 论文证据

每条证据使用物理 PDF 页码，从 1 开始，并可以包含章节、解析块标识、事实观察和短摘录。证据只能来自任务锁定的解析产物。

“论文未提供足够证据”也是合法结论，但必须关联已经检查的要求或论文范围，不能让模型用这句话掩盖未阅读内容。
