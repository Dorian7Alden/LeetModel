## AI评审V3

### 概述

AI评审V3（工作流版本规划为 `DEEP_EVIDENCE_REVIEW_V3`）是紧密围绕**数学建模竞赛真实评阅规律**与**第二代高保真结构化解析产物（`PAPER_DOCUMENT_V2`）**构建的第三代 AI 论文评审系统。

在继承 V2“证据化溯源、服务端确定性算术校验、题目覆盖核对”的严密工程防线基础上，V3 针对数模科学评阅的本质规律进行系统性跃迁：
1. **深度消费 `PAPER_DOCUMENT_V2` 全量高保真资产**：全面利用原生 LaTeX 数学公式、原生 HTML `<table>` 表格、整块缩进程序源码、插图长描述与排版美观度量化指标，彻底终结历史版本中“公式乱码、图表全盲、代码失真”的致命缺陷；
2. **多阶段漏斗式评审流水线（Multi-stage Pipeline）**：告别单次大 Prompt 的长上下文注意力涣散与 Output 截断风险，模拟真实专家阅卷习惯，拆解为“合规与摘要速审 -> 分问题模型推导与算法核验 -> 数值结果与灵敏度真伪鉴定 -> 细粒度量表扣分裁决”的多阶段流水线；
3. **细粒度扣分项（Deduction Rubric）与锚点定位**：将感性打分转化为基于事实证据的细分增扣分阶梯，配合细粒度 `blockId` 实现对原文段落、公式行号与表格单元的精准批注；
4. **致命硬伤一票否决与安全熔断**：针对违规泄密、全篇伪建模、结果荒谬反常识等严重硬伤建立判定熔断机制。
