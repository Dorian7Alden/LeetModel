## PDF解析V2


### 概述

PDF解析V2（工作流版本 `PAPER_PARSE_V2`，产物 Schema `PAPER_DOCUMENT_V2`）是面向通用学术与数学建模论文的第二代 PDF 结构化解析能力。

针对单双栏排版、非标标题、复杂表格（合并单元格/斜线表头）、代码缩进、公式标号、多类型图表与全局排版美观度，V2 解析彻底摆脱繁杂的几何坐标微观计算，将重点聚焦于两项工程使命：
1. **双页滑窗提取与要素结构保真**：以连续两页（1-2, 2-3...）为滑窗输入，注入前文参考上下文，由视觉大模型自主平铺消除分栏，忽略外框与页眉页脚，输出 HTML 表格、整块缩进代码、LaTeX 公式标号、插图长描述与美观前置评分；
2. **重叠页冲突仲裁与全局连贯平铺**：中间重叠页经两次解析做一致性验证；出现明显冲突时引入 PDFBox 本地文本为客观参考，由仲裁 AI 决断取舍；解析结果全局平铺连贯，标注大致物理页号，跨页元素首现归属。


---


### 原则与边界

1. **AI 视觉真值与能力信任**：相信 AI 视觉模型的空间感知与排版能力，代码缩进由 AI 保持，标题层级由 AI 自主维护，不手写死板规则。
2. **双页滑窗与重叠仲裁**：一次解析两页，步长为一页；重叠页若分歧，引入本地文本作为参考由仲裁 AI 裁决。
3. **复杂表格直接转 HTML**：统一转为 HTML 原生 `<table>` 标签，原生支持 colspan/rowspan 及斜线表头。
4. **大致物理页号定位**：统一使用真实物理页数（从 1 递增），不做行号精确定位；跨页元素首次出现在哪页就算哪页，重点保证内容连贯。
5. **外框页眉页脚前置忽略**：在 Prompt 中明确要求 AI 忽略外框、页眉、页脚及页码，从源头剔除噪点。
6. **图表长描述与美观前置评分**：插图放宽描述长度，前置产出插图美观分与全篇排版紧凑度分，供只读文本的下游评审消费。
7. **忠实呈现非校验原则**：不对引用关系做强制拦截，保留原文跳号与断链瑕疵供下游评审。
