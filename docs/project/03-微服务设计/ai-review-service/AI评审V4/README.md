## AI评审V4

> 设计状态：已完成实现并经验收。
> 确认日期：2026 年 9 月 16 日。

`DEEP_EVIDENCE_REVIEW_V4` 在 V3 高保真解析和双阶段评审基础上，增加面向用户的专业 Markdown
报告、真实原文摘录、优点与问题双向评价、服务端确定性优先级排序和可见知识依据。


### 设计原则

1. 评分结论必须同时说明“是什么、为什么、影响什么、依据在哪里”。
2. 优点与问题都必须有真实论文证据，不把“没有发现问题”等同于优点。
3. 原文摘录只能由服务端从锁定解析块生成，模型不得自行转述为原文。
4. 问题排序由服务端权威规则决定，前端不按模型返回顺序展示。
5. 所有长文本使用 Markdown，公式使用 KaTeX 兼容语法。
6. V4 不生成完整修改路径，改进方向继续交给建议服务。
