## AI 评审

AI 评审接收用户某次提交对应的唯一 PDF，按锁定的评审版本执行处理，最终产生 `[0,100]` 评分和该版本定义的评审内容。

当前 `BASIC_REVIEW_V1` 已实现；`EVIDENCE_REVIEW_V2` 已完成设计但尚未实现。所有已发布版本均不可变，AI 功能步骤、依赖或输出语义变化时发布新版本，不覆盖历史实现。
