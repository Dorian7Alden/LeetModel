## 提示词与输出

V1 Prompt 参考 `/home/dorian/Desktop/rag_kb/数学建模/论文评审/` 中的评审总览、评审板块和阅卷人视角资料。参考资料只用于提炼稳定规则，不在运行时加载，不恢复 RAG。

评审应覆盖假设合理性、建模创造性、结果正确性和表达清晰性。完整性优先于模型炫技；漏答、缺少模型检验、摘要没有关键结果、正文前后不一致均属于高影响问题。评审只能依据 PDF 中可见内容，证据不足时不得猜测。

Prompt 由 V1 资源文件维护，创建任务时保存快照。它包含角色、评审原则、四维度定义、证据约束和 JSON 结构。语义发生实质变化时建立新版本，不能覆盖 V1 历史任务。

模型只允许返回 JSON。V1 输出包含统一的 `score`，以及 `summary`、四个维度的分数与评语、`strengths`、`weaknesses` 和 `suggestions`。四个维度和最终得分都必须位于 `[0,100]`；数组元素必须是非空文本。V1 补充字段不属于跨版本公共契约。

实现优先使用 LangChain4j 的 Prompt 抽象组织模板，但外部模型调用仍只能经过 ai-gateway-service。供应商协议差异只允许在网关适配器中处理。
