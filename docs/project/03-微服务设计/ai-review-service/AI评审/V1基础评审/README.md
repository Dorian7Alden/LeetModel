## V1 基础 AI 评审

`BASIC_REVIEW_V1` 是最低复杂度的可运行评审版本：接收任务锁定的提示词和一份提交 PDF，将页面转换为有序图像，通过一次多模态模型调用直接得到最终得分和基础评语。

### 范围

- 使用 `deepseek-v4-flash-vision-exp` 实验模型完成一次多模态评审。
- 产出所有版本统一的 `[0,100]` `score`，以及 V1 专属的总结、四维度评价和建议。
- 独立维护 V1 的工作流代码、提示词资源、结果校验和结果表。

### 非目标

- 不执行 OCR、PDF 文本提取、章节识别或 RAG。
- 不拆分页面并行评审，不进行多轮追问、复核或仲裁。
- 不自动形成排行榜，不建设管理端、质量评价和成本监控。
