## 版本划分

评审版本代表一套完整工作流，不只代表模型名称或 Prompt。

| 版本 | 定位 | 设计目标 |
|------|------|----------|
| v1 | 粗略评审 | 提示词与 PDF 页面图像一次性交给多模态模型，直接产生最终得分和 V1 评语 |
| v2 | 适中评审 | 平衡质量、稳定性、成本和响应时间，目标是综合指标最优 |
| v3 | 过度评审 | 使用更完整流程追求最高质量，接受最高成本和最长响应时间 |

所有版本共享相同公共输入，并在结束时产生同名、同类型和同语义的 `score`。版本专属过程 JSON 不要求一致，版本差异可以体现在 PDF 预处理、模型调用次数、小任务拆分、多轮对话、步骤编排、校验和仲裁等中间流程。

v1 不执行文本提取、章节拆分或独立 PDF 解析，只把 PDF 渲染为模型支持的有序页面图像。页面渲染是输入协议适配，不产生可复用的解析产物。v2 和 v3 可以按工作流需要使用 PDF 解析。

版本特征只是设计目标，最终表现必须使用相同测试集重复运行，并以 ai-evaluation-service 的评价结果为准。
