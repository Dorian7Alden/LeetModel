## 文件规则

当前论文输入只接受 PDF，单个论文 PDF 最大为 20MB。该限制是 submission-service 的论文提交业务规则，不得作为题目附件或其他文件上传的公共限制。

论文 PDF 使用分片上传，文件完成后保存到对象存储，数据库只保存可迁移的对象路由，不保存临时访问地址。

当前阶段不提供文件去重和秒传。相同文件再次提交仍建立独立上传与提交事实，避免内容相同但归属或版本不同的业务记录被错误合并。

分片大小和对象路径格式属于实现配置，以当前代码为准。论文 PDF 的 20MB 上限属于已确认的业务规则，调整时必须同步前端校验、submission-service 校验和上传配置。
