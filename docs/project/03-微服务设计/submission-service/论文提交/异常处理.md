## 异常处理

- 题目不存在、队伍无效或用户无上传权限时，不创建上传任务。
- 文件不是有效 PDF、超过 20MB、分片缺失、分片大小不符或摘要不一致时，不创建成功提交记录。
- 合并或最终文件校验失败时，会话恢复为 `UPLOADING`，保留已确认分片供重试。
- 重复完成请求必须保持幂等，不生成多份提交。
- 队伍权限在上传过程中发生变化时，已上传分片可保留至会话过期，但完成阶段必须重新校验权限、练习状态和截止时间。
- 对象存储暂时不可用时保留可恢复状态，不使用不存在的文件引用触发评审。
- 评审任务创建暂时失败时，上传会话保留已创建的提交关联。重复完成请求只补偿触发评审，不再合并文件或创建提交。
- 24 小时内未完成的会话进入 `EXPIRED`，定时任务清理其临时分片。仍在正常合并租约内的会话不被中途过期。
