### 维护边界

- 本目录记录前端用户体验和交互契约，不替代 `docs/project/02-架构设计/` 中的跨服务职责与数据边界设计。
- 设计文档必须区分当前接口能力、前端目标体验和需要后端补充的契约，不能把目标交互描述成已交付功能。
- 进入实现前，先由用户确认本目录中对应模块的 P0 范围；确认后再更新 TODO 并修改代码。
