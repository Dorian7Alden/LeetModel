## 前端设计与 UI/UX 规范

> 本目录是 LeetModel 前端重构的设计文档中心，集中管理产品定位、信息架构、设计系统规范与各业务模块的交互体验设计文档。

---

### 目录职责

1. **集中归档**：所有前端 UI/UX 重构相关的分析、设计、规范与图解均在本文档目录下独立维护，与后端微服务设计隔离。
2. **分步演进**：文档严格按照阶段推进，经用户讨论与确认后逐篇沉淀，不提前生成未确认的内容。
3. **单一事实来源**：作为前端代码重构、CSS Design Token 定义与组件开发的唯一设计依据。
