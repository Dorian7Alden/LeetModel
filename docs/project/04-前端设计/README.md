### 设计基本原则

1. **严肃专业的实训沉浸感**：数学建模是一门重推导、重逻辑、重协作的学术竞赛，UI 设计必须保持严肃、克制、整洁的工具与实训平台基调，避免营销化浮夸装饰，注重高信息密度的合理排版与可读性。
2. **高保真的学术与科学排版**：题面、论文评审建议与 AI 助手回答广泛包含 LaTeX 数学公式、多行代码块、统计图表与学术论文结构，全链路保障 KaTeX 渲染精度与舒适的行高字距。
3. **强化三人协作与时限感知**：建模、编程、论文三职责分工是数学建模的核心机制，限时倒计时、分片上传进度与评审状态流转必须具备清晰的视觉反馈与确定性心理预期。
4. **小步演进与模块隔离**：所有页面重构严格按照单一功能模块推进，通用 Design Token 集中收敛于全局样式，各模块拥有独立私有组件与样式包，降低耦合度。
