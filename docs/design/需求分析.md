## 需求分析文档

本文档详细定义 LeetModel 平台的所有业务模块及其功能列表，用于指导开发并确保模块间的解耦。

说明：

- 该项目的提交内容审核没有通过与不通过的说法，只有评分高低的说法，

---

## 用户角色定义

| 角色 | 说明 | 权限范围 |
|------|------|----------|
| 游客 | 未注册用户 | 仅可浏览首页、题库概览、平台介绍 |
| 注册用户 | 已登录用户 | 可使用全量前台功能：题库、训练、AI评阅、赛事、组队、社区等 |
| 平台管理员 | 后台管理人员 | 题目审核/上架、内容管理、用户管理、数据统计等 |

## 模块详细定义

### 01-认证管理模块 (Auth)

**模块说明**：处理用户身份认证相关功能，所有接口无需携带 Token。

**功能列表**：

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|----------|----------|----------|--------|
| AUTH-001 | 用户注册 | 邮箱+密码注册，支持初始角色偏好选择，原始角色可多选 | P0 |
| AUTH-002 | 用户登录 | 邮箱+密码登录，返回 JWT Token | P0 |
| AUTH-003 | 发送验证码 | 注册/找回密码时发送邮箱验证码 | P0 |
| AUTH-004 | 找回密码 | 通过验证码重置密码 | P1 |
| AUTH-005 | 退出登录 | 清除登录状态（可选 Token 黑名单） | P0 |
| AUTH-006 | Token 刷新 | 自动续期 JWT Token | P1 |



---

### 02-用户管理模块 (User)

**模块说明**：管理注册用户的基本信息、角色切换和个人设置。

**功能列表**：

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|----------|----------|----------|--------|
| USER-001 | 查询用户信息 | 获取当前登录用户详细信息 | P0 |
| USER-002 | 更新用户信息 | 修改用户名、头像、学校等基础信息 | P0 |
| USER-003 | 切换备赛角色 | 在建模手/编程手/论文手之间切换，身份标识，达到一定水平，“全干” | P0 |
| USER-004 | 修改密码 | 验证旧密码后修改新密码 | P1 |
| USER-005 | 绑定/换绑邮箱 | 更换登录邮箱，验证机制：完成验证后，发起换绑的后一天，再次验证方可换绑 | P1 |
| USER-006 | 注销账号 | 永久删除用户账号及关联数据 | P2 |

### 03-题库管理模块 (Problem)

**模块说明**：核心内容模块，管理所有训练题目资源。

**功能列表**：

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|----------|----------|----------|--------|
| PROB-001 | 获取题目列表 | 分页查询，支持多维度筛选（关键字、标签、难度、类型、来源等） | P0 |
| PROB-002 | 获取题目详情 | 查看题目完整描述、附件下载 | P0 |
| PROB-003 | 获取推荐题目 | 基于用户角色和能力推荐题目 | P1 |
| PROB-004 | 获取题目标签 | 获取所有可用标签分类 | P0 |
| PROB-005 | 收藏题目 | 用户收藏感兴趣的题目 | P1 |

**题目类型定义**：

| 题目类型      | 说明       | 已知                         | 输出     |
| ------------- | ---------- | ---------------------------- | -------- |
| `modeling`    | 建模手题目 | 题目背景                     | 数学模型 |
| `programming` | 编程手题目 | 题目背景、数学建模           | 代码实现 |
| `paper`       | 论文手题目 | 题目背景、数学建模、代码实现 | 论文写作 |
| `full`        | 完整套题   | 题目背景                     | 综合训练 |

### 04-标签管理模块 (Tag)

**模块说明**：管理题目的多维度标签体系。

**功能列表**：

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|----------|----------|----------|--------|
| TAG-001 | 获取标签列表 | 获取所有标签，支持按类型分组 | P0 |
| TAG-002 | 获取热门标签 | 获取使用频率最高的标签 | P1 |
| TAG-003 | 创建标签 | 管理员创建新标签 | P1 |
| TAG-004 | 更新标签 | 管理员修改标签信息 | P1 |
| TAG-005 | 删除标签 | 管理员删除标签 | P1 |

**标签类型定义**：

- `model_type` - 模型类型（优化规划类模型、评价决策类模型、预测预报类模型、机理建模类模型、数据挖掘类模型等）

- `source` - 赛事来源（国赛、美赛、AI生成、用户上传等）
- `difficulty` - 难度等级（简单、中等、困难）

### 05-专项训练模块 (Training)

**模块说明**：分角色的阶梯式专项训练，支持多格式成果提交。

**功能列表**：

| 功能编号 | 功能名称 | 功能描述 | 优先级 |
|----------|----------|----------|--------|
| TRAIN-001 | 获取训练入口 | 根据当前角色显示对应训练内容 | P0 |

| TRAIN-003 | 提交训练成果 | 支持代码/文档/图片多格式提交 | P0 |

| TRAIN-005 | 获取提交详情 | 查看单次提交的详细内容 | P0 |
| TRAIN-006 | 重新提交 | 对题目重新提交答案 | P0 |
| TRAIN-007 | 获取训练统计 | 个人训练数据统计展示 | P1 |

## 开发优先级规划

### P0 - 核心功能（MVP必备）

1. **认证管理模块**：注册、登录、验证码
2. **用户管理模块**：用户信息管理、角色切换
3. **题库管理模块**：题目列表（含筛选、搜索）、详情
4. **标签管理模块**：标签列表获取
5. **专项训练模块**：训练入口、提交成果、查看记录
6. **AI评审模块**：提交评审、获取结果
7. **赛事模拟模块**：赛事列表、报名、参赛、提交
8. **组队匹配模块**：创建队伍、招募列表、申请加入
9. **社区交流模块**：帖子列表、发布、评论
10. **平台管理模块**：用户管理、题目审核、内容审核

### P1 - 重要功能（增强体验）

1. 找回密码、Token刷新
2. 收藏题目、题目推荐
3. 能力雷达图、成长轨迹（成长体系模块）
4. 赛事排名、参赛记录
5. 队伍管理（转让队长、移除队员）
6. 帖子搜索、热门推荐
7. 成长头衔、成就系统（成长体系模块）
8. 数据统计看板

### P2 - 扩展功能（锦上添花）

1. 账号注销、邮箱换绑
2. 智能推荐、AI对话
3. 智能匹配推荐队友
4. 排行榜、学习日历（成长体系模块）
5. AI评审配置
6. 图片压缩优化
