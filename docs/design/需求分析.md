#### 注册用户

执行流程：
1. 用户点击注册按钮，跳转到注册页面
2. 显示注册表单，通过邮箱完成注册
3. 用户完成表单填写
   - 表单内容：
        1. 注册邮箱
        2. 密码
        3. 再次输入密码
4. 点击发送验证码，进行邮箱验证
5. 用户填写验证码
