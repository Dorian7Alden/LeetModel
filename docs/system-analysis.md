## 系统分析



### 明确需求

---

**项目背景：**

- 现在数学建模赛事的参与热度逐年走高，国赛、美赛年参赛队伍达数十万支，从零基础入门的萌新，到冲刺奖项的备赛团队，都有着强烈的全流程备赛训练需求。

- 但目前市面上没有像 LeetCode 那样专门针对数学建模的标准化实训平台。大家备赛能用到的，大多是零散的往届赛题、资料包，或是通用的编程刷题工具，既没法满足建模手、编程手、论文手的分角色专项训练，也缺少全真赛事模拟、便捷组队这些备赛刚需功能，存在明显的供给空白。

- 我们的项目精准瞄准学生群体的真实痛点，填补了这个垂直领域的缺口，完全贴合学生备赛的使用需求。

---

**用户画像：**

数学建模赛事备赛团队，1-3 人成队，部分赛事可跨校组队，有明确的建模手 / 编程手 / 论文手角色定位，以国赛、美赛等主流赛事获奖为核心目标。核心需求聚焦分角色专项训练、体系化阶梯题库、作品专业评审优化、全真赛事模拟、高效组队匹配、学习经验交流六大类。

---



### 功能描述

> 目前描述得暂不详细，要具体到每一个选项。前期阶段先搭建框架，再后续补充实际内容。

---

**分角色专项训练：**

- 针对建模手、编程手、论文手三类核心参赛角色，拆分赛事全流程分工，设置独立专属训练板块。
- 针对不同角色的能力要求定制阶梯式练习清单，匹配差异化训练模式与成果提交形式（支持文档、代码、图片等多格式提交），实现定向能力提升。

---

**体系化训练题库：**

- 题库覆盖主流赛事往届原题、AI 生成专项模拟题、用户自主上传题目三大类；
- 所有题目均配置多维度标签（含模型类型、题型、行业背景、赛事来源等）与难度评级，支持精准筛选；
- 同时提供完整赛事套题、单模块专项练习题两类题型，适配不同训练需求。

---

**AI 专业作品评审优化：**

- 参考主流赛事官方评审标准，搭建适配国赛、美赛等不同赛事类型的专属 AI 评审机制；
- 可针对论文、模型、代码等不同形式的作品，从建模合理性、代码准确性、论文规范性、图表呈现等多个维度量化打分；
- 输出综合得分、完整评审报告及针对性优化建议。

---

**全真赛事模拟：**

- 1:1 还原国赛、美赛等主流赛事的官方流程与作答环境，支持两种训练模式：
- 一是全流程赛事模拟，完整复刻赛事时长与提交规则，限时完成全流程作品提交；
- 二是分阶段专项模拟，还原真实团队协作场景，限时完成指定环节任务，支持模拟用户的实时沟通协作场景。

---

**高效组队匹配：**

- 支持用户发布组队招募信息，可自定义组队赛事、角色需求、能力要求、招募说明等核心信息；
- 同时可设置校内 / 跨校的组队范围限制，结合用户历史训练情况，帮助备赛用户快速匹配契合的参赛伙伴，补齐团队角色缺口。

---

**学习交流：**

- 设置开放交流板块，支持用户发布备赛经验、学习心得、问题探讨等相关帖子；
- 支持按最新发布、最高热度等维度筛选内容；
- 同时平台配套发布体系化备赛学习指导内容，覆盖建模方法、写作技巧、代码实践等干货内容，辅助用户完成理论知识积累。

---

**个人成长体系：**（扩展功能，优先级低）

- 联动平台全训练模块，围绕用户备赛全周期搭建 “数据追踪 - 能力评估 - 正向激励” 的完整成长体系。

- 系统自动记录用户分角色专项训练、题库练习、全真赛事模拟、AI 评审结果等全场景练习数据，留存可追溯的学习成长轨迹；
- 基于不同参赛角色的评价模型，生成多维度可视化能力评价报告，量化用户能力水平，同步给出针对性提升方向；
- 配套阶梯式成长激励机制，结合用户各种表现，解锁专属成长头衔与特色成就，配套能力排行榜，打造正向学习闭环。

---







平台角色：

- 游客：未注册用户，仅可浏览首页、题库概览、平台介绍，不可使用训练、评阅、组队等核心功能
- 注册用户：已完成注册登录，可切换「建模手 / 编程手 / 论文手」角色，使用题库、专项训练、AI 评阅、赛事模拟、个人成长、组队等全量前台功能
- 平台管理员：负责题目上架与审核、内容管理、用户管理、社区内容审核、平台数据统计等后台操作



2. 先给流程分级，避免混乱

不要把所有操作揉在一个流程里，按「主流程→子流程」分级，一个文档 / 章节只描述一个流程：

- **主流程**：用户全生命周期核心链路，比如「新用户从注册到完成首次专项训练的全流程」
- **子流程**：主流程里的闭环功能节点，比如「分角色专项训练流程」「AI 智能评阅流程」「赛事模拟全流程」「组队匹配流程」等







### 业务流程

---

用户系统：







1. 需求深化与技术选型（1-3 天）
   1. **需求细化**：在现有计划基础上，拆解核心功能的业务流程（如 “用户如何完成一道建模题”“AI 评阅的交互逻辑”），明确优先级（标注「P0 必须做」「P1 后续做」）。
   2. **技术选型**：根据你的技能栈，选择开发效率高的技术（一个人不建议用太复杂的技术栈）。
      前端、后端、数据库、AI 大模型
2. 产品原型设计（2-4 天）
   1. 页面结构设计
   2. 高保真原型
3. 数据库设计（1-2 天）
   1. **ER 图设计**：梳理核心实体（用户、题目、训练记录、AI 评阅结果等）及关系。
   2. **建表 SQL**：编写数据库建表语句，定义字段类型、索引、外键（如需要）。
4. 后端核心功能开发（10-15 天）
   1. **用户系统**：注册 / 登录（建议用 JWT）、个人信息管理。
   2. **题库系统**：题目列表（支持标签筛选）、题目详情（含题目描述、数据下载）。
   3. **训练系统**：分角色训练入口、提交答案（文本 / 文件上传）、AI 评阅（调用第三方 API 生成评阅结果）。
   4. **成长体系**：训练记录存储、能力数据统计。
5. 前端核心页面开发（10-15 天）
   1. **登录 / 注册页**表单验证、JWT 存储、登录状态保持。
   2. **首页 / 题库页**题目列表展示、标签筛选功能、题目卡片点击跳转。
   3. **题目详情 / 训练页**题目内容展示、数据下载、答案提交（文本编辑器 / 文件上传）、AI 评阅结果展示。
   4. **个人中心**训练记录列表、能力数据可视化（用 ECharts 画图表）。





## 所有模块



#### 1. 用户管理模块

- 核心功能：账号注册 / 登录（JWT 认证）、退出登录、个人信息管理
- 权限与角色：游客 / 注册用户 / 平台管理员权限管控、注册用户角色切换（建模手 / 编程手 / 论文手）

#### 2. 题库管理模块

- 题目资源：往届赛事原题、AI 生成专项模拟题、用户自主上传题目（管理员审核 / 上架）
- 题目检索：多维度标签筛选（模型类型、题型、行业背景、赛事来源）、难度评级筛选
- 题目呈现：题库概览展示、题目详情查看、题目数据下载
- 题型支撑：完整赛事套题、单模块专项练习题管理

#### 3. 分角色专项训练模块

- 训练内容：建模手 / 编程手 / 论文手专属阶梯式练习清单
- 训练交互：角色匹配训练入口、多格式成果提交（文档 / 代码 / 图片）
- 训练记录：专项训练过程及结果数据留存

#### 4. AI 评审优化模块

- 评审配置：适配国赛 / 美赛等不同赛事的专属评审机制
- 评审交互：论文 / 模型 / 代码类作品提交、多维度量化打分
- 评审输出：综合得分、完整评审报告、针对性优化建议生成

#### 5. 全真赛事模拟模块

- 赛事配置：1:1 还原国赛 / 美赛流程、时长、提交规则
- 模拟模式：全流程赛事模拟、分阶段专项模拟
- 模拟交互：限时作答、团队协作场景模拟、模拟作品提交

#### 6. 组队匹配模块

- 招募管理：组队招募信息发布（自定义赛事、角色 / 能力要求、组队范围）
- 匹配机制：基于用户历史训练数据的伙伴匹配
- 交互流程：招募信息查看、组队申请、组队结果确认

#### 7. 学习交流模块

- 社区内容：备赛经验 / 学习心得 / 问题探讨类帖子发布、按最新 / 最热维度筛选内容
- 官方内容：体系化备赛指导内容（建模方法、写作技巧、代码实践）发布与展示
- 内容管控：管理员对社区内容的审核管理

#### 8. 个人成长体系模块（扩展功能）

- 数据追踪：全场景练习数据记录（专项训练、题库练习、赛事模拟、AI 评审）
- 能力评估：多维度可视化能力评价报告、针对性提升方向建议
- 激励机制：成长头衔 / 成就解锁、能力排行榜

#### 9. 平台管理模块（管理员端）

- 内容管理：题目审核 / 上架、社区内容审核
- 用户管理：用户账号管控、权限调整
- 数据管理：平台全维度运营数据统计分析
