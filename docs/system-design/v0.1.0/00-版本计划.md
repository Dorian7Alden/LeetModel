## v0.1.0 版本计划

### 版本目标

该版本聚焦一项核心目标：

- 建立完整可用的鉴权基础能力

该版本只负责注册、登录、退出、JWT 身份认证与 RBAC 授权收口，为后续用户管理、文件管理、标签管理和题目管理提供统一安全底座。


### 功能范围

#### 鉴权管理（Auth）

- 用户注册
- 用户登录
- 用户退出登录
- JWT 认证，完成身份验证与授权
- 权限控制：普通用户仅可访问个人数据，管理员可访问全量数据
- 令牌失效控制：同一账号再次登录时旧令牌失效；主动退出后当前令牌失效


### 非目标

- 不包含用户自助管理能力（个人资料编辑、重置密码）
- 不包含管理员用户管理能力（列表、详情、状态、角色）
- 不包含文件管理、标签管理、题目管理
