## v0.3.0 版本计划



### 版本目标



该版本聚焦文件管理能力建设，目标是提供稳定的文件上传与链接持久化能力，作为题目管理的前置基础。



### 功能范围



#### 文件管理（File）

- 接入 OSS 存储文件
- 支持文件上传
- 文件链接持久化存储
- 基础文件元信息记录（文件名、大小、类型、上传人、上传时间）



### 非目标



- 不包含标签管理
- 不包含题目新增与编辑



### 依赖关系



- 依赖 v0.1.0 的鉴权能力（上传鉴权、访问控制）



### 开发顺序（版本内）



1. OSS 接入与上传链路打通
2. 文件元信息持久化
3. 文件查询与可视化展示
4. 前后端联调与稳定性验证
