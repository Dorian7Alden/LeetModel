
# 题目管理模块设计

## 1. 概述
题目管理支持上传竞赛题目，并以标签进行多维分类。题目主体文件（PDF、数据包等）通过远程链接引用，不直接存储于服务器；题目简介采用 Markdown 文件上传至阿里云 OSS，以链接形式存储。标签采用独立数据表实现多对多关联。

## 2. 数据模型

### 2.1 核心实体关系
- `competition`（赛事） 1 : N `problem`（题目）
- `problem` 1 : N `problem_link`（题目附件链接）
- `problem` M : N `tag`（标签），通过 `problem_tag` 关联
- `tag_category`（标签分类） 1 : N `tag`

### 2.2 建表语句（优化后）

```sql
-- 赛事表
CREATE TABLE `competition` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '赛事ID',
    `name` VARCHAR(100) NOT NULL COMMENT '赛事名称',
    `description` VARCHAR(500) DEFAULT NULL COMMENT '赛事描述',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='赛事表';

-- 题目表（仅保留核心字段，标签通过关联表实现）
CREATE TABLE `problem` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '题目ID',
    `title` VARCHAR(255) NOT NULL COMMENT '题目标题',
    `competition_id` BIGINT NOT NULL COMMENT '所属赛事ID',
    `markdown_url` VARCHAR(500) DEFAULT NULL COMMENT '题目简介Markdown文件OSS链接',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_competition_id (`competition_id`),
    CONSTRAINT fk_problem_competition FOREIGN KEY (`competition_id`) REFERENCES `competition`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目表';

-- 题目附件链接表（一个题目可包含多个链接，如PDF、数据ZIP等）
CREATE TABLE `problem_link` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '链接ID',
    `problem_id` BIGINT NOT NULL COMMENT '所属题目ID',
    `link_title` VARCHAR(200) NOT NULL COMMENT '链接标题（如“赛题PDF”“附件数据”）',
    `link_url` VARCHAR(500) NOT NULL COMMENT '链接地址',
    `display_priority` INT DEFAULT 0 COMMENT '展示排序',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_problem_id (`problem_id`),
    CONSTRAINT fk_link_problem FOREIGN KEY (`problem_id`) REFERENCES `problem`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目链接表';

-- 标签分类表
CREATE TABLE `tag_category` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `name` VARCHAR(50) NOT NULL COMMENT '分类名称（如难度、年份）',
    `code` VARCHAR(50) NOT NULL COMMENT '分类编码',
    `sort_order` INT DEFAULT 0
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='标签分类表';

-- 标签表
CREATE TABLE `tag` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `category_id` BIGINT NOT NULL COMMENT '所属分类ID',
    `name` VARCHAR(50) NOT NULL COMMENT '标签名称',
    `color` VARCHAR(20) DEFAULT NULL COMMENT '展示颜色',
    `description` VARCHAR(200) DEFAULT NULL,
    `sort_order` INT DEFAULT 0,
    `usage_count` INT DEFAULT 0 COMMENT '使用次数',
    `status` TINYINT DEFAULT 1 COMMENT '是否启用',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_tag_category FOREIGN KEY (`category_id`) REFERENCES `tag_category`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='标签表';

-- 题目-标签关联表（多对多）
CREATE TABLE `problem_tag` (
    `problem_id` BIGINT NOT NULL,
    `tag_id` BIGINT NOT NULL,
    PRIMARY KEY (`problem_id`, `tag_id`),
    CONSTRAINT fk_pt_problem FOREIGN KEY (`problem_id`) REFERENCES `problem`(`id`) ON DELETE CASCADE,
    CONSTRAINT fk_pt_tag FOREIGN KEY (`tag_id`) REFERENCES `tag`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目标签关联表';
```

## 3. 功能设计

### 3.1 上传题目

**功能描述**：用户上传竞赛题目信息，包含 Markdown 简介文件、选择赛事和标签，并可添加多个外部链接（如 PDF、数据包）。

**业务流程**：
1. 用户输入题目标题。
2. 选择所属赛事。
3. 选择标签（年份、难度、题型、涉及模型、行业领域、数据特征等）。
4. 上传题目简介文件（Markdown 格式，系统后续将其上传至阿里云 OSS 并获取外链）。
5. （可选）添加附件链接：输入链接标题与链接地址，点击“添加”可增加多个。
6. 提交后，后端在事务中完成：
   - 将 Markdown 文件上传 OSS，得到链接；
   - 插入 `problem` 记录；
   - MyBatis 自动回填题目 ID；
   - 批量插入 `problem_tag` 关联；
   - 插入 `problem_link` 附件记录。

**前端表单设计**：
- 题目标题：文本输入框
- 题目简介：文件上传（仅允许 .md）
- 所属赛事：下拉单选（数据源来自赛事列表）
- 年份、难度、数据特征、行业领域：下拉单选（动态获取对应 tag_category 下的标签）
- 涉及模型、题型：多选下拉框，支持搜索关键词，已选项以标签形式预览
- 附件区域（动态添加）：
  - 附件标题：文本框
  - 附件链接：文本框
  - “添加附件”按钮可重复增加行

### 3.2 后端处理逻辑（事务伪代码）

```
@Transactional
void uploadProblem(ProblemUploadRequest req) {
    // 1. 上传 Markdown 文件至 OSS，获得外链
    String markdownUrl = ossService.upload(req.getMarkdownFile());
    
    // 2. 插入题目记录
    Problem problem = new Problem();
    problem.setTitle(req.getTitle());
    problem.setCompetitionId(req.getCompetitionId());
    problem.setMarkdownUrl(markdownUrl);
    problemMapper.insert(problem);  // 主键自动回填至 problem.id
    
    // 3. 批量插入标签关联
    if (req.getTagIds() != null) {
        problemTagMapper.batchInsert(problem.getId(), req.getTagIds());
    }
    
    // 4. 插入附件链接
    if (req.getLinks() != null) {
        for (LinkItem link : req.getLinks()) {
            problemLinkMapper.insert(problem.getId(), link.getTitle(), link.getUrl());
        }
    }
}
```

## 4. API 接口说明

Base URL：`http://localhost:8080/api/v1`

### 4.1 获取分类下标签列表
用于填充各类下拉框。

**请求**：`GET /tags/category/{categoryId}`

示例 categoryId 对应关系：
- 1：难度
- 3：赛事（实际赛事应从 /competitions 接口获取，标签分类中可仅作备用）
- 4：年份
- 5：题型
- 6：涉及模型
- 7：行业领域
- 8：数据特征

**响应示例**（categoryId=1）：
```json
[
    {
        "tagId": 1010001,
        "categoryId": 1,
        "name": "入门",
        "color": "#4CAF50",
        "description": "零基础可做，熟悉建模流程",
        "sortOrder": 1,
        "usageCount": 0,
        "status": true
    }
    // ...
]
```

### 4.2 上传题目
**请求**：`POST /problems`  
`Content-Type: multipart/form-data`

参数：
- `title`：题目标题
- `competitionId`：赛事ID
- `markdownFile`：题目简介文件（.md）
- `tagIds`：标签ID数组，如 `[1010001, 1010002]`（可重复传参或使用JSON字符串）
- `links`：附件链接数组，格式为 JSON 字符串，示例：
```json
[
  {"title": "赛题PDF", "url": "https://example.com/problem.pdf"},
  {"title": "附件数据", "url": "https://example.com/data.zip"}
]
```

**响应**：返回新建题目的 ID 与基本信息。

## 5. 存储方案说明
- 题目原始 PDF、数据压缩包及各类附件均通过链接形式引用，不存入服务器本地。
- 用户手动输入的附件链接直接存入 `problem_link` 表，由前端自行验证链接有效性。
- 题目简介 Markdown 文件由用户本地上传，后端将其转存至阿里云 OSS，并将返回的公开访问链接存入 `problem.markdown_url`。
- 所有静态资源均依赖 OSS 的高可用与低延迟访问能力，减轻服务器负担。
