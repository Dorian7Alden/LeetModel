## v0.2.0 版本计划



### 版本目标



该版本聚焦管理员用户管理能力，目标是支持管理员在后台完成用户可视化管理与状态治理。



### 功能范围



#### 管理员用户管理（Admin User）

- 用户列表可视化
- 用户详情查看
- 用户状态管理（启用 / 禁用）
- 用户角色管理（普通用户 / 管理员）



### 非目标



- 不包含个人中心资料编辑和改密流程
- 不包含文件、标签、题目管理



### 依赖关系



- 依赖 v0.1.0 的鉴权与角色权限能力
- 建议复用 v0.1.1 的用户基础信息字段定义



### 开发顺序（版本内）



1. 用户列表与详情
2. 用户状态管理
3. 用户角色管理
4. 后台权限收口与联调
