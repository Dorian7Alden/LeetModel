## 题目管理

题目管理包括上传题目，

### 题目说明

题目一般主要是以 pdf 的格式存储，但是也有题目会携带数据文件，可能是 zip 压缩包。

美赛的题目内容还可能包含官方给出的论文模板，相关说明文档，包含：docx、tex、pdf 等格式的文件。

国赛的题目内容甚至可能含有 mp3、png、jpg 等文件，附件数据比较丰富，csv、xlsx 等。


题目会有特征，可以对其进行打标签分类，但是一个题目对应多个标签，标签也可以对应多个题目，所有，把标签单独抽离出来，因此，在 problem 表中不直接存储有关标签的字段，而是通过 problem_tag 表来实现题目和标签的多对多关系。


题目表依赖于赛事表，应该先对赛事进行管理，设计，再来设计题目表

### 存储题目



#### 存储形式

考虑到国赛跟美赛两大主流赛事都有对应的官网可以直接下载到历年的完整竞赛题目，因此不考虑将题目内容保存到服务器中，而是通过链接的形式存储，以及题目的Markdown格式简介，用来展示题目的主要内容以及相关文件。

存储内容：题目链接，题目 mardown 简介。

需要注意的是，一个题目可能包含多个链接，一个 pdf 链接，一个 zip 数据链接。应该是一对多的关系，一个题目，对应多个链接。

存储载体：MySQL 数据库。



### 上传题目

题目内容：
- 题目标题
- 所属赛事选择
- 题目文件（markdown）
- 标签
- *附件标题
- *附件链接


执行过程：
1. 用户：输入题目标题
2. 用户：选择所属赛事
3. 用户：选择标签（年份、难度、题目类型、涉及模型、行业领域、数据特征）
4. 用户：上传题目文件（markdown格式）
5. 【可选】用户：输入附件标题，输入附件链接
6. 用户：点击提交，完成题目上传
7. 系统：将题目文件上传到阿里云 OSS，获取文件的外链地址
8. 系统：存储题目的数据
9. 系统：存储题目关联的附件数据

后续实现：
直接在上传题目的时候，就同步设置对应的标签


表单设计：
- 题目标题（文本框）
- 题目简介（上传文件）
- 所属赛事选择（单选）（下拉框）
- 年份选择（单选）（下拉框）
- 难度选择（单选）（下拉框）
- 数据特征（单选）（下拉框）
- 行业领域（单选）（下拉框）
- 涉及的模型（多选）（下拉框，多选框，支持所搜关键词，点击添加，预览已经添加了的选项）
- 题型（多选）（下拉框，多选框，支持所搜关键词，点击添加，预览已经添加了的选项）
- 附件：
  - 附件标题（文本框）
  - 附件链接（文本框）
  - 添加附件按钮（点击后可以添加多个附件输入框）

你可以将以下 SQL 语句用于创建数据库表：

#### 建表 sql 

```sql

CREATE TABLE `problem` (
  `id` bigint(20) DEFAULT NULL COMMENT '旧id，暂时保留，后续用新id平替',
  `title` varchar(255) DEFAULT NULL,
  `content` longtext,
  `difficulty` varchar(20) DEFAULT NULL,
  `source` varchar(20) DEFAULT NULL,
  `status` varchar(20) DEFAULT NULL,
  `language` varchar(10) DEFAULT NULL,
  `data_url` varchar(500) DEFAULT NULL,
  `creator_id` bigint(20) DEFAULT NULL,
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime NOT NULL,
  `ave_score` int(11) NOT NULL COMMENT '平均分',
  `content_url` varchar(255) DEFAULT NULL COMMENT '题目简介链接'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE `problem_link` (
  `problem_link_id` BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT '题目链接ID',

  `problem_id` BIGINT NOT NULL COMMENT '所属题目ID',

  `link_title` VARCHAR(200) NOT NULL COMMENT '链接标题',
  `link_url` VARCHAR(500) NOT NULL COMMENT '远程存储链接地址',

  `display_priority` INT DEFAULT 0 COMMENT '链接展示优先级',

  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',

  CONSTRAINT fk_problem_link_problem
  FOREIGN KEY (`problem_id`) 
  REFERENCES `problem`(`id`)
  ON DELETE CASCADE 
  ON UPDATE CASCADE,

  INDEX idx_problem_id (`problem_id`)

) ENGINE=InnoDB 
DEFAULT CHARSET=utf8mb4 
COLLATE=utf8mb4_unicode_ci 
COMMENT='题目相关链接表';

```
