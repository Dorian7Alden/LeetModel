## v0.5.0 版本计划



### 版本目标



该版本聚焦管理员端题目管理闭环，目标是完成题目从创建到编辑的完整流程，并稳定关联文件与标签。



### 功能范围



#### 题目管理（Problem）

- 题目列表可视化
- 新增题目（关联文件与标签）
- 编辑题目



### 非目标



- 不扩展新的鉴权模型
- 不新增用户管理子模块



### 依赖关系



- 依赖 v0.1.0 鉴权能力
- 依赖 v0.3.0 文件管理能力
- 依赖 v0.4.0 标签管理能力



### 开发顺序（版本内）



1. 题目数据模型与管理端列表
2. 新增题目并关联文件与标签
3. 编辑题目
4. 端到端联调与回归验证
