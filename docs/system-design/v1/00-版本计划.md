## v1 版本计划

### 版本目标

v1 版本聚焦两项核心目标：

- 建立完整的用户权限管理能力
- 支撑管理员端的题目管理流程

由于题目管理依赖文件与标签能力，v1 需同步建设文件管理和标签管理模块，作为题目管理的基础支撑。


### 功能范围

除用户权限管理外，用户管理、文件管理、标签管理、题目管理均在 v1 中建设后台管理端功能。

#### 鉴权管理（Auth）

- 用户注册
- 用户登录
- JWT 认证，完成身份验证与授权
- 权限控制：普通用户仅可访问个人数据，管理员可访问全量数据


#### 用户管理（User）

- 用户列表可视化
- 用户详情查看
- 用户状态管理（启用 / 禁用）
- 用户角色管理（普通用户 / 管理员）


#### 文件管理（File）

- 使用 OSS 存储文件
- 支持文件上传并持久化文件链接


#### 标签管理（Tag）

- 标签列表可视化
- 新增标签
- 编辑标签
- 删除标签


#### 题目管理（Problem）

- 题目列表可视化
- 新增题目（关联文件与标签）
- 编辑题目


### 开发顺序（按依赖关系）

1. 权限管理
2. 用户管理
3. 文件管理
4. 标签管理
5. 题目管理

该顺序可优先打通认证与鉴权，再补齐题目管理依赖的文件和标签能力，最后完成管理员端题目全流程，降低返工风险。
