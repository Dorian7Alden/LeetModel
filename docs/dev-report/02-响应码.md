# LeetModel 响应状态码设计规范 (全业务场景版)

为了支撑 LeetModel（对标 LeetCode 的数学建模垂直实训平台）的复杂业务流，本文档基于系统分析文档中的九大模块，设计了一套**高内聚、易扩展、单一职责**的 `5 位数业务状态码体系`。

**核心原则：**
1. **单一职责**：每个状态码有且仅有一种明确的业务含义，并与唯一的枚举值绑定。绝不出现含糊不清的“操作失败”兜底，通过 code 可以直达错误发生的方法和场景。
2. **先通用后定制**：从全局级别（00）、模块通用级别到具体场景级别递进。

---

## 1. 响应数据标准格式
后端接口应统一返回 `HTTP Status 200`，真实的业务执行结果和错误类型由 JSON 体中的 `code` 字段表示。

```json
{
  "code": 20000,        // 5位数标准业务状态码
  "msg": "操作成功",      // 面向用户的友好提示
  "data": { ... },      // 成功时的核心数据承载（失败时可为 null）
  "timestamp": 1713500000000 // 请求发生的时间戳
}
```

---

## 2. 状态码设计原则 (A-BB-CC)
所有的业务 `code` 由 **5 位数字** 组成，分段定义如下：

* **第 1 位 (A)**：错误大类级别
  * `2`：请求与业务执行成功
  * `4`：客户端错误、参数错误、业务逻辑阻断（用户侧原因）
  * `5`：服务端内部异常、第三方服务调用失败（系统侧原因）
* **第 2~3 位 (BB)**：业务模块标识
  * `00`：全局通用（网络、系统、通用参数等）
  * `01`：用户与认证模块（注册/登录/角色切换）
  * `02`：题库与专项训练模块（题目/标签/解答提交）
  * `03`：赛事模拟模块（报名/赛事流程/提交）
  * `04`：组队匹配模块（建队/招募/申请）
  * `05`：社区与学习交流模块（发帖/评论）
  * `06`：AI评审与第三方服务（大模型/OSS/邮件）
  * `07`：平台管理模块（后台审核/上架下架）
* **第 4~5 位 (CC)**：具体错误编号，从 `01` 开始递增。

## 3. 详细状态码清单 (附带枚举定义)

### 3.1 成功状态 (2xxxx)
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 |
| --- | --- | --- |
| **20000** | `SUCCESS` | **请求成功**（接口正常处理完毕） |

### 3.2 全局通用错误 (400xx / 500xx)
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40000** | `CLIENT_ERROR_COMMON` | **通用请求错误** | 无法归类到特定场景的客户端阻断。 |
| **40001** | `PARAM_VALIDATION_ERROR` | **参数校验不通过** | `@Valid` 拦截，缺少必填参数或格式不符。 |
| **40002** | `RESOURCE_NOT_FOUND` | **请求资源不存在** | 通用的查询为空（如接口路径不存在）。 |
| **40003** | `FILE_SIZE_EXCEEDED` | **文件大小超限** | 上传的图片/文档/代码文件超过系统设定阈值。 |
| **40004** | `FILE_TYPE_UNSUPPORTED` | **不支持的文件类型** | 上传了不允许的扩展名（如非 doc/pdf/py/m 文件）。 |
| **50000** | `SYSTEM_INTERNAL_ERROR` | **服务器内部异常** | 系统级崩溃（NullPointerException、数据库连不上等）。 |

### 3.3 用户与认证模块 (401xx)
**涵盖注册、登录、角色（建模手/编程手/论文手）管理**
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40100** | `UNAUTHORIZED_TOKEN_MISSING` | **Token 缺失** | 请求未携带 Token 凭证，需重新登录。 |
| **40101** | `UNAUTHORIZED_TOKEN_INVALID` | **Token 失效/被篡改** | Token 已经过期或签名不合法。 |
| **40102** | `PERMISSION_DENIED` | **权限不足** | 游客尝试访问注册用户功能，或越权访问后台接口。 |
| **40103** | `USER_NOT_FOUND` | **用户不存在** | 登录或查询时，该邮箱/账号不存在。 |
| **40104** | `PASSWORD_INCORRECT` | **密码错误** | 登录密码校验失败。 |
| **40105** | `USER_ALREADY_EXISTS` | **账号已存在** | 注册时邮箱已被占用。 |
| **40106** | `VERIFICATION_CODE_INCORRECT`| **验证码错误或已过期** | 注册/重置密码时验证码不匹配。 |
| **40107** | `VERIFICATION_CODE_FREQUENT` | **验证码获取过于频繁** | 距上次发送验证码的时间过短。 |
| **40108** | `USER_ROLE_NOT_SET` | **未设置备赛角色** | 用户未选择建模手/编程手/论文手，无法开启专属训练。 |
| **40109** | `USER_ACCOUNT_BANNED` | **账号已被封禁** | 账号因违规被平台管理员冻结。 |

### 3.4 题库与专项训练模块 (402xx)
**涵盖题库检索、标签分类、阶梯式练习**
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40201** | `PROBLEM_NOT_FOUND` | **题目不存在** | 访问的题目ID无效或已被删除。 |
| **40202** | `PROBLEM_OFFLINE` | **题目已下架** | 题目未审核通过或已被管理员下架，不可训练。 |
| **40203** | `PROBLEM_ROLE_MISMATCH` | **训练角色不匹配** | 如论文手尝试进入仅限编程手的专项训练任务。 |
| **40204** | `SUBMISSION_CONTENT_BLANK` | **提交内容为空** | 点击提交答案，但未编写代码或上传文档。 |
| **40205** | `UNSUPPORTED_PROGRAM_LANG` | **不支持的编程语言** | 提交的代码语言系统无法支持。 |
| **40206** | `PROBLEM_ALREADY_SOLVED` | **题目已解答** | 已通过该题目，不可重复提交（视业务需求而定）。 |

### 3.5 全真赛事模拟模块 (403xx)
**涵盖1:1还原环境、限时组队参赛**
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40301** | `COMPETITION_NOT_FOUND` | **赛事不存在** | 赛事记录无效或被删除。 |
| **40302** | `COMPETITION_ENROLL_CLOSED` | **报名已截止或满员** | 尝试在报名时间结束后加入赛事。 |
| **40303** | `COMPETITION_NOT_STARTED` | **赛事尚未开始** | 尝试提前获取赛题或提交作品。 |
| **40304** | `COMPETITION_ALREADY_ENDED`| **赛事已结束** | 比赛倒计时结束，不再接受作品提交。 |
| **40305** | `USER_NOT_ENROLLED` | **未报名该赛事** | 用户未报名，无法进入比赛模拟环境。 |
| **40306** | `COMPETITION_REQUIRE_TEAM` | **必须以团队形式参赛**| 该赛事仅限团队（不能以单人）参加。 |

### 3.6 组队匹配模块 (404xx)
**涵盖发布招募、角色匹配、组队申请**
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40401** | `TEAM_NOT_FOUND` | **团队不存在** | 该团队已被解散或ID无效。 |
| **40402** | `TEAM_ALREADY_FULL` | **团队人数已满** | 团队已达到赛事规定的人数上限（如3人）。 |
| **40403** | `USER_ALREADY_IN_TEAM` | **用户已在团队中** | 用户已经加入了当前赛事的其他团队，不可重复加入。 |
| **40404** | `USER_NOT_IN_TEAM` | **用户不在团队中** | 尝试执行仅限队内成员的操作（如访问团队协作空间）。 |
| **40405** | `TEAM_LEADER_REQUIRED` | **仅限队长操作** | 尝试解散团队、踢出成员或修改招募信息（非队长）。 |
| **40406** | `RECRUIT_ROLE_MISMATCH` | **招募角色不匹配** | 团队招募“编程手”，而申请者角色是“论文手”。 |
| **40407** | `TEAM_APPLY_PENDING` | **入队申请审核中** | 已经发送过申请，请勿重复投递。 |

### 3.7 社区与学习交流模块 (405xx)
**涵盖经验交流、互动发帖**
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40501** | `POST_NOT_FOUND` | **帖子不存在** | 帖子已被作者或管理员删除。 |
| **40502** | `COMMENT_NOT_FOUND` | **评论不存在** | 尝试回复或点赞一个已被删除的评论。 |
| **40503** | `CONTENT_SENSITIVE` | **包含敏感词汇** | 发帖或评论的内容未通过违规词检测。 |
| **40504** | `ACTION_TOO_FREQUENT` | **操作过于频繁** | 刷帖、刷评论、恶意点赞触发系统防刷限制。 |
| **40505** | `POST_AUTHOR_REQUIRED` | **仅限原作者操作** | 尝试编辑或删除不属于自己的帖子。 |

### 3.8 AI评审与第三方服务 (406xx / 506xx)
**涵盖火山Ark大模型、邮箱、OSS**
| 状态码 (`code`) | 枚举名 (`Enum Name`) | 含义 | 说明 / 常见场景 |
| --- | --- | --- | --- |
| **40601** | `AI_INPUT_TOO_LONG` | **AI评审文本超长** | 提交的论文或代码字符数超出了大模型的 Token 限制。 |
| **40602** | `AI_QUOTA_EXCEEDED` | **AI评阅次数耗尽** | 用户的单日/单月 AI 使用额度已用完。 |
| **50601** | `EMAIL_SEND_FAILED` | **邮件发送失败** | SMTP 服务器异常或网络超时。 |
| **50602** | `AI_MODEL_CALL_FAILED` | **AI 大模型调用失败** | 请求火山引擎 Ark 接口超时、无响应或服务端拒绝。 |
| **50603** | `AI_RESPONSE_PARSE_ERROR` | **AI 审核解析异常** | 大模型返回的内容格式错误，无法解析出多维度评分。 |
| **50604** | `OSS_UPLOAD_FAILED` | **云存储上传失败** | 第三方对象存储（OSS/COS）服务不可用，文件保存失败。 |

| --- | --- | --- | --- |

| **40702** | `REVIEW_STATE_INVALID` | **审核状态不合法** | 题目/帖子已经被审核过，不可重复执行审核操作。 |
| **40703** | `SYSTEM_CONFIG_INVALID` | **系统配置参数无效** | 管理员修改的运营参数不符合要求。 |

## 4. 落地建议
请在后端 `com.senior.leetmodelbackend.entity.enums.ErrorCode` 中将上述枚举逐一翻译为 Java 代码，如下所示：

```java
public enum ErrorCode {
    SUCCESS(20000, "操作成功"),
    CLIENT_ERROR_COMMON(40000, "通用客户端错误"),
    PARAM_VALIDATION_ERROR(40001, "参数校验不通过"),
    
    // ...用户模块
    UNAUTHORIZED_TOKEN_MISSING(40100, "未登录或Token缺失"),
    USER_NOT_FOUND(40103, "用户不存在"),
    USER_ROLE_NOT_SET(40108, "未设置备赛角色"),
    
    // ...AI模块
    AI_INPUT_TOO_LONG(40601, "AI评审内容超出长度限制"),
    AI_MODEL_CALL_FAILED(50602, "AI 大模型调用失败");

    // 补全代码...
}
```
