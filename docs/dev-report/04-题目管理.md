## 题目管理

题目管理包括上传题目，

### 题目说明

题目一般主要是以 pdf 的格式存储，但是也有题目会携带数据文件，可能是 zip 压缩包。

美赛的题目内容还可能包含官方给出的论文模板，相关说明文档，包含：docx、tex、pdf 等格式的文件。

国赛的题目内容甚至可能含有 mp3、png、jpg 等文件，附件数据比较丰富，csv、xlsx 等。


题目会有特征，可以对其进行打标签分类，但是一个题目对应多个标签，标签也可以对应多个题目，所有，把标签单独抽离出来，因此，在 problem 表中不直接存储有关标签的字段，而是通过 problem_tag 表来实现题目和标签的多对多关系。


题目表依赖于赛事表，应该先对赛事进行管理，设计，再来设计题目表

### 存储题目



#### 存储形式

考虑到国赛跟美赛两大主流赛事都有对应的官网可以直接下载到历年的完整竞赛题目，因此不考虑将题目内容保存到服务器中，而是通过链接的形式存储，以及题目的Markdown格式简介，用来展示题目的主要内容以及相关文件。

存储内容：题目链接，题目 mardown 简介。

需要注意的是，一个题目可能包含多个链接，一个 pdf 链接，一个 zip 数据链接。应该是一对多的关系，一个题目，对应多个链接。

存储载体：MySQL 数据库。

#### 建表 sql 

```sql

CREATE TABLE `problem` (
  `problem_id` INT AUTO_INCREMENT PRIMARY KEY COMMENT '题目ID',
  `problem_title` VARCHAR(255) NOT NULL COMMENT '题目标题',
--   `publish_year` INT NOT NULL COMMENT '发布年份',
--   `problem_type` VARCHAR(50) COMMENT '题目类型（MCM/ICM/国赛）',
--   `problem_number` VARCHAR(20) DEFAULT '' COMMENT '题号(如A题、B题、C题)',
  `problem_markdown` LONGTEXT COMMENT '题目的Markdown格式简介',
  `competition_id` INT NOT NULL COMMENT '所属赛事ID',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  FOREIGN KEY (`competition_id`) REFERENCES `competition`(`competition_id`) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='题目主表';

CREATE TABLE `problem_link` (
  `problem_link_id` INT AUTO_INCREMENT PRIMARY KEY COMMENT '题目链接ID',
  `problem_id` INT NOT NULL COMMENT '所属题目ID',
  `link_title` VARCHAR(200) NOT NULL COMMENT '链接标题',
  `link_type` VARCHAR(50) NOT NULL COMMENT '链接类型(如 pdf, zip, docx 等)',
  `link_url` VARCHAR(500) NOT NULL COMMENT '远程存储链接地址',
  `display_priority` INT DEFAULT 0 COMMENT '链接展示优先级',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  FOREIGN KEY (`problem_id`) REFERENCES `problem`(`problem_id`) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='题目外部链接表';
```
