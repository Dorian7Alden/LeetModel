### 问题描述

Java 后端启动的时候，控制台打印输出显示：数据库连接池报错了。

但是这个报错信息非常长，直接把终端占满了，原始的服务器启动信息都看不到了，达到了上限，加载不出来了，导致最原始、最关键的那条报错信息看不到，似乎是连接池中的数据库连接同时报错一样，终端的缓冲区一下就被冲爆了。

配置中使用了自定义的 阿里巴巴的 数据库连接池

```yaml
  datasource:
    url: ${LM_MYSQL_URL} # mysql的数据库地址
    username: ${LM_MYSQL_USER} # 数据库用户名
    password: ${LM_MYSQL_PASSWORD} # 数据库密码
    driver-class-name: com.mysql.cj.jdbc.Driver
    type: com.alibaba.druid.pool.DruidDataSource
```



### 解决过程

取消自定义的连接池，换成默认的，报错信息就没那么多了，非常干净，才知道原来是数据库连接出现了问题。

最终发现：环境变量的数据库连接的 URL 有问题，没有写数据库的协议前缀，直接就是 ip 开头。 `jdbc:mysql://`
