## knowledge-base

> 数学建模论文评审 RAG 知识库。按标签目录组织原子笔记,每篇笔记聚焦一个知识点,文首元数据区的摘要字段是检索初筛的内容依据。评审 AI 以目录实时扫描为准检索笔记,README 索引仅辅助人工浏览。

| 标签目录 | 含义与收录范围 |
|---------|--------------|
| review-standard/ | 评审标准与定档方法,含国赛与美赛的评分维度、权重与各维度评审要点 |
| modeling-methods/ | 建模方法的适用场景与评审核查点,按优化求解与评价检验分组 |
| common-pitfalls/ | 常见建模误区,收录评审中高频扣分点的识别特征与判定方法 |
| writing-quality/ | 论文写作规范,含章节结构、摘要、图表、公式、参考文献与英文写作 |
