## 五档锚点定档方法

> 次标签:无
> 摘要:五档锚点表与先定档再档内微调的两步给分法,优秀 90 至 100、良好 75 至 89、合格 60 至 74、欠缺 40 至 59、不合格 0 至 39,用于压制 LLM 打分波动、保证多轮评审一致性。
> 来源:评审标准设计文档
> 权威度:S
> 版本:v1
> 状态:active

每个评分维度统一使用五档锚点。评审时禁止直接给出一个开放式分数,必须执行两步操作:第一步,对照档位特征描述,判定该维度落在哪一档;第二步,在该档的得分区间内,依据瑕疵数量与严重程度微调出最终整数分。

### 五档锚点表

| 档位 | 得分区间 | 通用特征描述 |
|------|---------|-------------|
| 优秀 | 90 至 100 | 该维度所有评审要点均高质量达成,可作为范例 |
| 良好 | 75 至 89 | 要点基本达成,存在少量非关键瑕疵 |
| 合格 | 60 至 74 | 核心要点达成但质量平庸,或有明显短板 |
| 欠缺 | 40 至 59 | 关键要点缺失或存在实质性错误 |
| 不合格 | 0 至 39 | 该维度基本缺失或严重错误 |

### 定档操作要求

定档判断的依据是维度评审要点的达成情况,不是整体印象。定档时先问三个问题:核心要点是否全部达成、达成质量是范例级还是平庸级、是否存在实质性错误或关键缺失。三个问题的答案组合直接映射到档位,再在档内微调。

各维度在通用特征之外还有专属档位判据,由 prompt 模板携带,例如摘要维度的优秀档要求逐问给出方法与量化结果。专属判据与通用锚点冲突时,以专属判据为准。

### 设计意图

先定档再给分,把开放式打分收敛为分类问题。分类判断的稳定性远高于开放式数值输出,是压制 LLM 打分波动、保证同一论文多轮评审得分一致的主要收敛手段。多轮评审的维度得分取中位数聚合,定档一致性直接决定中位数的可信度。
