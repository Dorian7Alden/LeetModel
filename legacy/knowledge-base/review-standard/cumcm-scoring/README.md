## cumcm-scoring

> 本目录收录国赛 CUMCM 评分口径笔记:维度与权重总览、各维度评审要点、硬性检查项与创新加分机制。评审 AI 评国赛论文时检索本目录取用打分依据,核心口径为摘要定生死、模型与求解定档次、规范性是底线。

| 笔记 | 摘要 |
|------|------|
| 国赛评分维度与权重总览.md | 九个评分维度的代码、名称与权重完整表,ABSTRACT 25、MODELING 22、SOLUTION 15、VALIDATION 12 |
| 国赛摘要维度评审要点.md | ABSTRACT 权重 25 的评审判据,四要素覆盖、逐问方法名与量化结果、空话套话识别 |
| 国赛模型建立与求解评审要点.md | MODELING 权重 22 与 SOLUTION 权重 15 的评审判据,模型与问题匹配度、推导严谨性、求解可复现性 |
| 国赛检验与评价维度评审要点.md | VALIDATION 权重 12 与 EVALUATION 权重 5 的评审判据,灵敏度、误差、稳定性检验与诚实评价 |
| 国赛硬性检查项.md | 打分前五项合规检查,摘要独立成页、队伍信息泄露、参考文献、AI 使用说明、页数超限 |
| 国赛创新加分评定.md | 创新性不设独立权重,在建模与求解维度内评估,聚合阶段以附加分形式加 0 至 3 分 |
