## review-standard

> 本标签收录评审标准类笔记:评分维度与权重、各维度的评审判据、定档与给分方法。评审 AI 检索本目录,用于确定按什么维度打分、各维度看什么、如何定档。国赛与美赛口径分列于子目录,通用定档方法置于本层。

| 内容 | 说明 |
|------|------|
| 五档锚点定档方法.md | 五档锚点表与先定档再档内微调的两步给分法,用于压制打分波动、保证多轮评审一致性 |
| cumcm-scoring/ | 国赛 CUMCM 评分维度、权重与各维度评审要点 |
| mcm-scoring/ | 美赛 MCM 与 ICM 评分维度、权重与各维度评审要点 |
