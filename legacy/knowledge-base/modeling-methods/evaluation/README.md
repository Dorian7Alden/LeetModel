## evaluation

> 本目录收录评价与检验类方法笔记,覆盖多准则赋权评价、拟合优度、灵敏度分析与误差稳定性检验。评审 AI 检索本目录,用于判断论文的评价方法使用是否规范、该做的检验是否做了、检验结论是否量化。

| 笔记 | 摘要 |
|------|------|
| 层次分析法使用与评审要点.md | AHP 判断矩阵是否给出、一致性比率 CR 是否报告且小于 0.1、主观性是否讨论 |
| 熵权法与TOPSIS组合评价.md | 指标正负向处理与量纲归一化方式是否交代、权重结果是否合理 |
| 拟合优度的评价方法.md | R 方与调整 R 方的适用边界,只报 R 方不做残差分析是拟合类论文的典型缺陷 |
| 灵敏度分析的常用方法.md | 扰动对象与幅度是否明确、结论是否量化而非仅称模型稳定 |
| 误差分析与稳定性检验方法.md | 误差来源分类与交叉验证、扰动重算手段,检验是否针对模型关键假设 |
| 模型检验的常见手段对照.md | 四类检验手段与模型类型的对照关系,供判断论文该做哪种检验而没做 |
