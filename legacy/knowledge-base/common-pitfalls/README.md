## common-pitfalls

> 本标签收录数学建模论文的常见建模误区,即评审中的高频扣分点。每篇笔记聚焦一个误区,给出可操作的识别特征与评审处置口径,含影响维度与定档规则。评审 AI 检索本目录,用于在论文中定位这些扣分模式并映射到对应评分维度。收录范围限于跨题型通用的误区,特定方法的使用缺陷归入 modeling-methods 各目录,单纯的格式规范问题归入 writing-quality。

| 笔记 | 摘要 |
|------|------|
| 摘要空话套话.md | 摘要无方法名、无数值结论、四要素缺失,国赛摘要权重最大,此误区代价最高 |
| 假设回避核心难点.md | 用假设消解题目核心矛盾且无必要性论证,假设与模型建立两维度同步降档 |
| 滥用高级方法.md | 方法复杂度远超问题需要、无对比论证、与数据规模失配,模型建立不加分反扣分 |
| 结果缺乏检验.md | 无灵敏度、误差、稳定性检验,随机算法只跑一次,美赛此维度单列权重更高 |
| 抄题式问题重述.md | 重述与题面高度重合、无转述无思路脉络,权重小但作为理解深度的先验信号 |
| 图表公式与正文脱节.md | 孤儿图表、公式无编号无引用、结果图无分析,写作规范与求解双维度扣分 |
