## writing-quality

> 本标签收录论文写作规范类笔记,覆盖章节结构、摘要写作、图表公式规范、参考文献与美赛英文写作。评审 AI 检索本目录,用于核查写作规范维度的各项判据,规范性是底线,结构缺失与格式硬伤直接扣分。

| 笔记 | 摘要 |
|------|------|
| 建模论文标准章节结构.md | 九段式标准章节结构,章节缺失本身即扣分依据,结构完整性是规范性底线 |
| 摘要写作的四要素.md | 摘要须含问题、方法、结果、结论四要素,逐问写明模型名与量化结果 |
| 图表规范与正文呼应.md | 图表统一编号、标题与坐标轴标注完整、正文必须引用,孤儿图表是典型扣分特征 |
| 公式与符号规范.md | 公式统一编号且被引用,符号先定义后使用,量纲一致,符号冲突是核心扣分特征 |
| 参考文献与引用规范.md | 格式统一且正文有标注,列而不引、格式混乱、凑数文献是三大扣分特征 |
| 美赛英文写作评审要点.md | 以清晰准确达意为标准,机翻痕迹与影响理解的中式直译是扣分判定点 |
