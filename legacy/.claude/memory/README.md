# .claude/memory

> 用户行为习惯与偏好的持久化存储。减少重复沟通成本，让 AI 协作更高效。

---

## 机制说明

### 记录时机

对话中出现以下信号时，应将内容沉淀到本目录：
- **"因为..."** — 用户解释了选择的原因
- **"不是...而是..."** — 用户纠正了 AI 的理解
- **"要..."、"不要..."** — 用户明确表达偏好
- **"我习惯..."、"我喜欢..."** — 用户描述行为模式
- **"每次都..."、"以后..."** — 用户设定持续性规则

### 记录格式

每条记录包含：
- **内容**：用户说了什么
- **原因**：为什么这么做
- **适用场景**：什么时候应用

### 使用原则

1. 每次对话开始时加载本目录，获取用户偏好上下文
2. 执行任务时遵循已记录的偏好
3. 若有明显更优方案，仍应提出供用户参考（用户有认知边界，欢迎更好建议）

## 文件说明

| 文件 | 内容 |
|------|------|
| [preferences.md](preferences.md) | 用户的通用偏好（命名风格、工作方式、工具使用等） |
| [behaviors.md](behaviors.md) | 行为习惯（对话中反复出现的模式和倾向） |
| [decisions.md](decisions.md) | 关键决策记录（用户做出的重要选择及其原因） |
