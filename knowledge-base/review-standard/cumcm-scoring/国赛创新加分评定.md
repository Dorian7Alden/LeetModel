## 国赛创新加分评定

> 次标签:modeling-methods
> 摘要:INNOVATION 不设独立权重的设计与操作,创新性在 MODELING 与 SOLUTION 维度内评估方法组合与视角新颖性,聚合阶段以 innovationBonus 字段加 0 至 3 分附加分,总分上限截断 100。
> 来源:项目评分标准 CUMCM v1
> 权威度:S
> 版本:v1
> 状态:active

INNOVATION 在国赛标准中不设独立权重,不作为单独打分维度,而是加分调节项。

### 不设独立权重的原因

本科竞赛论文的创新多体现为方法组合与验证手段,而非原创理论。对这类创新独立打分缺乏可锚定证据,极易沦为主观虚分。将创新评估融入 MODELING 与 SOLUTION 维度,评审判断可以锚定在具体的建模与求解内容上,更可控。此为已记录的设计决策:创新性单列权重的方案被明确不采纳。

### 评估位置与内容

评估创新性时,在 MODELING 与 SOLUTION 两个维度的评审过程中识别以下特征:

第一,方法组合的新颖性。多种方法的组合方式是否针对本题结构有独到设计,而非常规流水线拼接。

第二,视角的新颖性。对问题的抽象角度或验证手段是否超出该类题目的常见套路。

识别到的创新点必须能指向论文中的具体内容,说不出具体位置与具体做法的"感觉有创新",不计入加分证据。注意与滥用高级方法区分:堆砌与问题无关的高级方法是 MODELING 维度的负向判据,不是创新。

### 加分操作

聚合计算阶段,依据评审中识别的创新证据给出 0 至 3 分附加分,由 innovationBonus 字段单独承载,不混入任何维度分。总分计算方式:各维度得分按权重加权求和,加上创新附加分,上限截断 100,保留一位小数。无创新证据时附加分为 0,0 分是常态而非惩罚。

### 与维度定档的关系

创新评估不改变 MODELING 与 SOLUTION 自身的定档结果。同一篇论文可以维度定档平庸但存在局部创新点,也可以维度定档优秀但无附加分。两者独立,避免创新印象污染维度打分。维度评审要点见 [[国赛模型建立与求解评审要点]]。
