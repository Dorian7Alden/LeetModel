## mcm-scoring

> 本目录收录美赛 MCM 与 ICM 评分口径笔记:维度与权重总览、Summary Sheet 与假设辩护等美赛特有维度的评审要点、硬性检查项。评审 AI 评美赛论文时检索本目录,核心口径为 Summary Sheet 权重高于国赛摘要、灵敏度单列、强调假设辩护与诚实讨论。

| 笔记 | 摘要 |
|------|------|
| 美赛评分维度与权重总览.md | 九个评分维度的代码、名称与权重完整表,SUMMARY 28 为最高权重 |
| 美赛SummarySheet评审要点.md | SUMMARY 权重 28 的评审判据,评委只读 Summary 即可理解全文贡献的独立可读性标准 |
| 美赛假设辩护评审要点.md | ASSUMPTION 权重 10,每条假设须附 justification,无辩护理由按缺失处理 |
| 美赛灵敏度与优缺点评审要点.md | SENSITIVITY 权重 10 与 STRENGTHS 权重 5,灵敏度单列且要求高于国赛 |
| 美赛特定文书评审要点.md | REQUIRED_DOC 按题激活,题目要求 Letter、Memo 等文书时从 WRITING 划出 5 分单独评估 |
| 美赛硬性检查项.md | 打分前六项合规检查,Summary Sheet、控制号、页数、英文撰写、AI 使用报告、特定文书 |
