## optimization

| 笔记 | 摘要 |
|------|------|
| 线性规划与整数规划适用场景.md | 规划模型三要素完整性核查,识别线性假设不成立与整数约束被错误松弛 |
| 遗传算法使用与评审要点.md | 编码与参数是否交代、收敛证据是否给出、小规模问题是否滥用启发式 |
| 模拟退火使用与评审要点.md | 温度调度参数是否交代、是否报告多次运行统计、是否与确定性算法交叉验证 |

| 图论与网络流模型适用场景.md | 最短路、最小生成树、最大流的建模场景,构图方式与复杂度可行性核查 |
